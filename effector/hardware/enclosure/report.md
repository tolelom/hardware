# 기구 검사 보고

초안. 미측정 값을 자리표시 값으로 채웠다.

실패 3건, 통과 332건. 통과는 검사별로 여유가 가장 작은 것만 적는다

| 검사 | 결과 | 내용 |
|---|---|---|
| 가장자리 여유 | 실패 | 미터 8 여유 -1.0mm |
| 패널 안쪽 간섭 | 실패 | IN-USB |
| 패널 안쪽 간섭 | 실패 | OUT-DC |
| 패널 바깥 간섭 | 통과 | Input-Ratio 여유 6.1mm (기준 6.1) |
| 가장자리 여유 | 통과 | 미터 7 여유 3.0mm |
| 패널 안쪽 간섭 | 통과 | Input-Ratio |
| 높이 스택 | 통과 | Seed3 소켓 스택 바닥 위 0.0mm |
