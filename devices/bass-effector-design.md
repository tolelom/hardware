# 베이스 컴프레서 페달 설계서

계획서: [bass-effector.md](bass-effector.md)
최종 갱신: 2026-09-14

---

## 1. 목표와 범위

패시브·액티브 베이스를 모두 받는 컴프레서 페달 1대를 만든다. 슬랩 연주의 피크와 18V 프리앰프
베이스까지 입력으로 받고, 앰프 입력에 바로 연결해 연습에 쓴다.

범위에 포함:
- 디지털 코어(Teensy 4.1, SGTL5000 코덱)와 아날로그 입출력단
- 컴프레서 알고리즘 자체 구현
- 릴레이 트루 바이패스와 DSP 경로 버퍼드 바이패스
- 기성 다이캐스트 케이스 가공과 조립

범위에서 제외:
- 멀티밴드, 모드 전환(1176·옵토 스타일 등), 프리셋, 설정 앱, 스테레오
- 사이드체인 HPF 노브(펌웨어 고정값으로 시작)
- AD/DA를 거치지 않는 아날로그 버퍼드 바이패스
- 드라이브·EQ·옥타버·딜레이·루퍼. 같은 하드웨어에서 펌웨어로 늘릴 수 있게 코덱 경로를 유지하지만
  1호 범위는 아니다

|---|---|---|---|---|---|---|
| MXR M87 | 아날로그 | 9V | 입력 +14dBV, 출력 +9.2dBV. 노이즈 플로어 -95dBV | 없음 | LED | 트루 |
| Aguilar TLC | 아날로그 | 9V | 출력 +6dBu | 없음 | 없음 | 배터리 방전 시 통과 |
| Origin Effects Cali76 Bass | 아날로그 | 내부 24V | 표기 없음 | Dry 노브 | LED 10칸 | 버퍼드 |
| UAFX 1176 Studio Compressor | 디지털 | 공개 안 됨 | 입출력 +12.2dBu | Parallel 스위치 | LED 색 | 트루/버퍼드 선택 |

## 3. 요구 사항

### 3.1 신호

| 항목 | 요구 | 근거 |
|---|---|---|
| 입력 임피던스 | 1MΩ | 레퍼런스 공통 |
| 최대 입력 | 약 +17dBu (Input 노브 최소 위치) | M87 +16.2dBu 환산, Ampeg -15dB 패드, Cali76 24V. 18V 프리앰프의 이론 상한은 약 +18.3dBu다(±9V 사인) |
| 최대 출력 | 약 +17dBu | 입력 상한과 같아야 블렌드·약한 압축에서 유니티가 유지된다 |
| 아날로그 경로 스윙 | 입력 버퍼, 패드, 출력단 전 구간이 +17dBu를 통과 | |
| 유니티 | 바이패스 볼륨 = 입력. Input 위치와 무관하게 압축이 걸리지 않은 신호는 Output 12시에서 유니티 | UAFX 1176, Cali76 매뉴얼 |
| 주파수 응답 | 20Hz~20kHz ±1dB | M87, UAFX 1176 사양. 5현 B현 기음은 약 31Hz |

보유 패시브 재즈 베이스의 핑거·슬랩 피크(M1)로 Input 노브의 PGA 상한을 정한다.

### 3.2 컨트롤

노브 5개, 토글 없음.

| 컨트롤 | 동작 |
|---|---|
| Input | 고정 패드 뒤 코덱 아날로그 게인(0~+22.5dB)과 디지털 드라이브로 입력을 고정 스레숄드에 민다. 압축 전 레벨은 Input 위치와 무관하게 유지된다 |
| Ratio | 연속 가변 |
| Att/Rel | 한 노브. 반시계 끝 = 빠른 어택·느린 릴리즈, 시계 끝 = 느린 어택·빠른 릴리즈 |
| Output | 마스터. 12시 = 0dB |
| Blend | 드라이/웻 믹스 |

사이드체인 HPF는 펌웨어 고정값이다.

### 3.3 표시

- 감쇠량 LED 8칸, 이펙트 온 LED 1개
- 입력 클립: ADC 샘플이 풀스케일 근처에 닿으면 미터 전체 점멸

### 3.4 바이패스

- K1(논래칭 DPDT 릴레이): 코일이 꺼져 있으면 입력 잭과 출력 잭을 직결한다. 전원 투입 중·차단 시·MCU
  리셋 중에는 항상 트루 바이패스
- 모드는 둘이다. 트루 바이패스는 K1을 끈다. 버퍼드 바이패스는 K1을 켠 채 DSP가 드라이 신호만 유니티로
  내보낸다
- 부팅 시 풋스위치를 누르고 있으면 모드가 바뀌고 EEPROM에 저장된다

### 3.5 전원

- 정전압 9V, 센터 마이너스 2.1mm, 500mA 이상
- 역극성 보호는 P-MOSFET으로 한다. 직렬 다이오드 강하가 아날로그 레일 여유를 먹는다(4.2절)
- 과전압 차단: 입력이 약 12.7V를 넘으면 12V 제너와 NPN이 P-MOSFET 게이트를 소스로 당겨 전원을 끊는다.
  18V 어댑터를 잘못 꽂아도 LT1054 절대 최대 16V에 닿지 않고 소모되는 부품이 없다. P-MOSFET은 Vgs 정격
  ±20V 이상이거나 게이트에 보호 제너와 직렬 R을 둔다
- 전원 투입 시 출력 과도음 없음: 트루 모드는 K1이 꺼져 있어 성립한다. 버퍼드 모드는 부팅 완료 시 K1 전환이
  1회 있고 그 과도는 T11 기준으로 판정한다
- 전원 차단 시 출력 과도음 없음: 두 경로가 있다
  - 감시 경로: 9V 입력을 분압해 오디오 블록 주기(0.73ms)로 읽고 이동 평균한다. 부팅 시 잰 어댑터 전압에서
    1V 내려간 값을 임계로 두고, 넘어서면 K1을 끄고 재부팅 전까지 다시 켜지 않는다. 벌크 C 1000µF, 부하 약
    230mA면 9V에서 7805 드롭아웃(7V)까지 약 8.7ms라 감지와 K1 릴리즈(2ms)가 그 안에 끝난다
  - 리셋 경로: 감시가 실패해도 7805 드롭아웃으로 MCU가 리셋되고 구동 트랜지스터 풀다운으로 K1이 풀린다.
    레일 C는 더블러 다이오드가 역류를 막아 자기 부하로만 방전되므로 9V 노드보다 늦게 무너진다
  - 분압비는 3.3/16 이하로 하고 ADC 핀 앞에 직렬 R과 소용량 C를 둔다. Teensy 아날로그 핀은 3.3V를 넘으면
    안 된다(PJRC, 문서 기준)

### 3.6 펌웨어 업데이트

- 케이스를 열지 않고 USB에 접근
- Teensy의 VIN·VUSB 패드를 끊어 9V 동작 중 USB 연결을 허용한다. 끊은 뒤에는 펌웨어를 올릴 때도 9V가
  연결돼 있어야 한다

## 4. 시스템 구성

### 4.1 블록도

```
K1: 논래칭 DPDT. 코일 꺼짐 = NC
  극 1  IN 잭 ─┬─ NC ─────────────────────────────────── 극 2 NC
               └─ NO ─┬─ R_pd ─ GND
                      └─ 직렬 R ─ 커플링 C ─┬─ R_bias ─ Vbias
                                            └─ [버퍼 ×1, OPA2992 A] ─ 커플링 C ─ [패드 -15dB] ─ 코덱 LINEIN
  극 2  OUT 잭 ─┬─ NC ─ 극 1 NC
                └─ NO ─┬─ 방전 R ─ GND
                       └─ 출력 직렬 R ─ 커플링 C ─ [출력단 +15.5dB, OPA2992 B, Vbias 기준] ─ 커플링 C ─ 코덱 LINEOUT

9V DC ─ P-MOSFET(역극성 보호, 과전압 차단: 12V 제너 + NPN) ─ 벌크 C ─┬─ LT1054 더블러(쇼트키 ×2) ─ 레일 필터 ─ 아날로그 레일(레일 C)
                                                                     │     └─ Vbias(레일 1/2, 분압과 대용량 C)
                                                                     ├─ K1 코일(9V, 플라이백 다이오드, NPN 구동)
                                                                     ├─ 분압(3.3/16 이하) ─ 직렬 R·소용량 C ─ Teensy ADC(전원 감시)
                                                                     └─ 7805 ─ 5V ─ Teensy VIN
                                                                                    └─ Teensy 3.3V ─ 코덱, 노브, LED, K1 구동 신호
```

- R_pd와 방전 R은 K1 NO 접점의 회로 쪽에 둔다. 트루 바이패스 중에도 커플링 C의 접점 쪽 극판이 0V로 유지돼
  K1을 켤 때 팝이 나지 않는다
- 입력 임피던스는 교류에서 R_pd와 R_bias의 병렬이다. 2.2MΩ ∥ 1.8MΩ ≈ 1MΩ처럼 병렬 합을 약 1MΩ으로 맞춘다.
  R_pd를 크게 두면 커플링 C 충전 시정수가 길어져(4.7MΩ과 1.27MΩ, 100nF에서 약 0.6초) 빠르게 껐다 켤 때
  팝이 남는다
- 입력 커플링 C는 R_bias와 함께 차단 주파수 10Hz 이하가 되게 정한다
- 입력 직렬 R은 OPA2992 입력 클램프 다이오드로 흐르는 전류를 제한한다
- 출력 직렬 R은 케이블 용량 부하에서 op-amp 안정을 위한 것이다
- K1 구동 트랜지스터는 베이스 저항과 풀다운을 둔다
- 부품 값은 회로도에서 정한다

### 4.2 헤드룸 체인

문서 기준.

| 구간 | 값 | 비고 |
|---|---|---|
| 코덱 LINEIN 최대 | 2.83Vpp (+2.2dBu) | SGTL5000 데이터시트, VDDA 3.3V. Audio Shield Rev D는 VDDA가 3.3V(PJRC 회로도) |
| 입력 풀스케일 | +17.2dBu (PGA 0dB) | 패드 -15dB |
| 코덱 LINEOUT 0dBFS | 2.53 / 2.61 / 3.11Vpp (최소 / 통상 / 최대), 통상 +1.5dBu | SGTL5000 데이터시트, 10kΩ 부하. 개체 편차는 T4의 유니티 트림으로 흡수 |
| 출력단 게인 | +15.5dB | 출력 최대 약 +17dBu |
| 아날로그 레일 | 16.1V 이상 필요 | ±7.77V(+17dBu) 피크에 op-amp 출력 여유 0.3V를 더한 값 |

- 레일 전압: 더블러 출력은 입력 전압의 2배에서 LT1054 손실(10mA에서 0.35V 통상, 0.55V 최대)과 외부
  쇼트키 다이오드 강하 2개를 뺀 값이다. 입력 9.0V, 쇼트키 0.3V면 통상 약 17.05V, 최대 손실에서 약 16.85V다.
  P-MOSFET R_DS(on) 강하도 2배로 빠진다. 역극성 보호를 직렬 다이오드로 하면 16.1V 요구에 여유가 없어져
  P-MOSFET으로 한다(3.5절)
- op-amp: OPA2992. 입력 공통모드 범위가 레일 끝까지, 출력은 레일에서 220~300mV(40V, 2kΩ),
  7nV/√Hz, 앰프당 2.4mA 통상·2.8mA 최대. SOIC·VSSOP·TSSOP·WSON·SOT-23-THIN이 있고 DIP은 없다
- 차지 펌프: LT1054. 입력 3.5~15V(절대 최대 16V), 발진 15~35kHz(통상 25kHz)
- 패드 출력 임피던스는 LINEIN 입력 임피던스(29kΩ)보다 충분히 작게, 출력단 입력 임피던스는 LINEOUT 최소
  부하(10kΩ) 이상으로 한다

### 4.3 디지털

- Teensy 4.1과 Audio Shield Rev D를 옆으로 나란히 배치하고 I2S·I2C를 배선한다. MCLK·BCLK·LRCLK·TX·RX
  배선은 짧게 한다(PJRC 권고, 문서 기준)
- 노브 5개: A10~A13(핀 24~27), A14(핀 38). 전원 감시: A15(핀 39). Shield가 쓰는 핀(6, 7, 8, 10~13, 15,
  18~21, 23)과 겹치지 않는다
- 풋스위치, LED 9개, K1 구동: 남는 GPIO
- 코덱 교체 경계: I2S, I2C, 라인인·라인아웃, 3.3V. Teensy 오디오 라이브러리가 지원하는 코덱은 SGTL5000,
  WM8731, TLV320AIC3206, AK4558, CS4272, CS42448이다

### 4.4 노이즈 기대치

[OpenAudio 블로그](http://openaudio.blogspot.com/2017/03/) 측정(문서 기준)에서 Teensy 3.6과 당시 오디오
보드의 다이내믹 레인지는 약 81dB(125~8000Hz, ADC HPF 끔)이고 입력 게인과 거의 무관했다. 같은 글에서
TLV320AIC3206은 92.4~94.6dB였다. Teensy 4.1과 Rev D 조합의 측정치는 없다.

81dB를 적용하면 입력 기준 바닥 노이즈는 입력 풀스케일에서 81dB를 뺀 값이다.

| PGA | 입력 풀스케일 | 바닥 노이즈 |
|---|---|---|
| 0dB | +17.2dBu | 약 -64dBu |
| +9dB | +8.2dBu | 약 -73dBu |
| +18dB | -0.8dBu | 약 -82dBu |

패시브 베이스에서 쓸 수 있는 PGA 상한은 슬랩 피크가 풀스케일을 넘지 않는 곳이라 M1 결과로 정해진다.
M87의 노이즈 플로어는 -95dBV(약 -92.8dBu)다. T7이 이 표를 확인하고, 기대치보다 크게 나쁘면 코덱 교체
경계(4.3절)를 쓴다.

## 5. 기구

### 5.1 케이스

1590BB 클론. 페달파츠 표기 외형 95 × 120 × 34mm. Hammond 문서 기준으로 1590BB는 높이 30mm, 1590BB2는
33.8mm이고 사용 면적은 약 104 × 79mm라, 구매할 케이스의 높이는 확인 필요.

125B(드릴 면 63.6 × 119.3mm, 사용 면적 52.1 × 107.8mm)에 노브 5개를 3개·2개 두 줄로 놓으면, 3개 줄을
20.3mm 간격에 지름 18.9mm 노브로 채울 때 드릴 면 가장자리 여유가 약 2mm라 모듈과 만능 기판 구성에는
쓰지 않는다. UAFX 1176과 Cali76 Bass는 이 크기지만 전용 기판이다.

### 5.2 패널 배치

노브는 3개·2개 두 줄, 간격 25mm. 한 줄 5개를 22mm 간격으로 놓으면 바깥 포텐셔미터 몸체(지름 16mm)가
중심에서 52mm까지 나가 사용 면적 폭(약 104mm)의 절반과 같아진다.

```
 ┌───────────────── 윗면: DC 잭, USB ──────────────────┐
 │     (Input)       (Ratio)       (Att/Rel)            │
OUT│                                                     │IN
 │     (Blend)       (Output)      ● ● ● ● ● ● ● ●  ○ 온  │
 │                      [풋스위치]                      │
 └──────────────────────────────────────────────────────┘
```

| 부품 | 치수 |
|---|---|
| 포텐셔미터 | Alpha 16mm 솔더 러그, 널링 축, 케이스 홀 7.5mm |
| 노브 | 푸시핏, 지름 18.9mm |
| 풋스위치 | 모멘터리, 홀 12mm. 패널 아래 깊이 확인 필요 |
| LED | 3mm 9개 |
| IN, OUT 잭 | 박스형 1/4" 잭, 홀 9.5mm, 몸체 16 × 16mm |
| DC 잭 | 홀 12mm |
| USB | 패널 장착 Micro-B 연장 케이블, M3 고정 귀 간격 17.3mm |

좌표는 케이스와 풋스위치 치수를 잰 뒤 도면으로 정한다. LED 일렬 타공은 페달파츠 사용자 지정 홀가공으로
맡길 수 있다.

### 5.3 내부 배치

- Audio Shield는 Teensy 위에 쌓지 않는다. 소켓 적층은 높이가 34mm 케이스에 맞지 않는다
- 아날로그 기판(버퍼, 패드, 출력단, 전원 보호, LT1054, 7805, K1)과 Teensy·Shield 기판을 풋스위치 좌우로
  나눈다
- 차지 펌프는 입력 네트워크에서 가장 먼 쪽, K1도 1MΩ 입력단에서 떨어뜨린다
- 접지는 스타 결선. 차지 펌프 리플 전류와 디지털 리턴이 입력단 접지를 지나지 않게 한다

### 5.4 방열과 전류

7805 탭을 절연 패드를 끼워 케이스 벽에 고정한다. MC7805 TO-220의 방열판 없는 접합-공기 열저항은
65°C/W, 접합-케이스는 5°C/W다(문서 기준).

K1은 9V 코일품이라 코일 전류가 7805를 지나지 않는다. TQ2-9V는 코일 579Ω, 약 15.5mA, 릴리즈 시간 2ms다
(문서 기준).
9V 전류는 Teensy 약 100mA(PJRC, 600MHz)에 코덱, LED, K1 코일, LT1054와 아날로그단을 더해 어댑터 요구를
500mA로 둔다. Fluke 101로는 전류를 재지 않으므로 전류는 계산값으로만 기록한다. 열이 문제되면 Teensy
클럭을 낮추는 선택지가 있다.

## 6. 펌웨어

### 6.1 출발점

문서 기준.

| 블록 | 구성 |
|---|---|
| OpenAudio `AudioEffectCompressor_F32` | RMS 검출(제곱, 저역통과, dB), 스레숄드, 레시오, 어택/릴리즈, 프리게인. HPF(20Hz)는 오디오 경로 전체에 걸리고 검출기는 필터된 신호를 본다. 니·메이크업 없음 |
| HexeFX `AudioEffectCompressorStereo_F32` (MIT) | 위에 포스트게인, 사이드체인 L+R 모드, `getCurrentGain_dB()`, 바이패스 추가. 사이드체인 전용 HPF·니 없음 |

컴프레서 블록은 직접 구현한다.

### 6.2 오디오 그래프

```
I2S_F32 in ─ [DC 제거] ─ [입력 보상 -PGA] ─┬─ [프리게인] ─ [컴프레서: 검출기 앞 사이드체인 HPF] ─ [-프리게인] ─┐
                                          └────────────────────────── 드라이 ─────────────────────────────────┴─ [Blend] ─ [Output] ─ [유니티 트림] ─ [마스터 램프] ─ I2S_F32 out
```

- 44.1kHz, 블록 32샘플. `AudioSettings_F32`로 지정하고 128 이하여야 한다(문서 기준)
- DC 제거는 드라이·웻 분기 전에 1개. 1차 필터면 차단 주파수 10Hz 이하로 해야 20Hz에서 -1dB 이내다. 라이브러리
  컴프레서의 20Hz HPF는 쓰지 않는다
- 웻 경로의 -프리게인이 Input의 디지털 드라이브를 되돌려, 압축이 걸리지 않은 웻과 드라이 레벨이 같다
- 드라이와 웻은 같은 블록에서 나와 시간이 맞는다
- 코덱 ADC HPF는 끈다(`adcHighPassFilterDisable()`). 켜 두면 톤 잡음이 났다([OpenAudio 블로그](http://openaudio.blogspot.com/2017/03/), 문서 기준)
- 코덱 ADC 제로 크로스는 끈다. 켜 두면 아날로그 게인이 바뀌는 시점을 알 수 없어 -PGA 보상을 맞출 수 없다.
  레지스터 쓰기가 protected라 `AudioControlSGTL5000` 상속 클래스에서 설정한다

### 6.3 노브 매핑

| 노브 | 매핑 |
|---|---|
| Input | 전체 입력 게인을 PGA 구간(1.5dB 단계)과 디지털 프리게인으로 나눈다. PGA 게인만큼 입력 보상으로 되돌린다. PGA 상한은 M1로 정한다 |
| Ratio | 연속 |
| Att/Rel | 3.2절 |
| Output | Blend 뒤 마스터 게인. 12시 0dB |
| Blend | 선형 크로스페이드 |

- PGA 변경 규칙
  - 올릴 때: 노브를 돌리는 동안에는 디지털 프리게인만 움직이고, 입력이 조용한 구간에서만 PGA로 넘긴다.
    조용함의 레벨과 지속 시간은 T13에서 정한다
  - 내릴 때: ADC 클립이 감지되면 조용한 구간을 기다리지 않고 즉시 PGA를 내린다
  - -PGA 보상은 I2C 쓰기 뒤 ADC 그룹 지연을 포함한 정렬 오프셋(블록 수)만큼 늦춰 적용한다. 오프셋은 T13에서
    잰다
- 노브는 약 100Hz로 읽어 평활하고, 파라미터 변화는 블록 안에서 램프한다

### 6.4 상태 머신

| 상황 | 순서 |
|---|---|
| 부팅 | K1 꺼짐 → 코덱 초기화 → 아날로그 레일 안정 대기 → 버퍼드 모드면 마스터 램프 0, K1 켬, 동작 시간 대기, 드라이 유니티로 램프 인 |
| 이펙트 켬 (트루 모드) | 마스터 램프 0 → K1 켬 → 동작 시간 대기 → 램프 인 |
| 이펙트 끔 (트루 모드) | 마스터 램프 아웃 → K1 끔 |
| 이펙트 켬·끔 (버퍼드 모드) | K1은 켠 채. 웻과 드라이 사이를 램프로 전환 |
| 모드 변경 | 부팅 시 풋스위치 누름 → 모드 전환, EEPROM 저장 |
| 전원 감시 | 오디오 블록마다 9V 감시값 이동 평균. 부팅 시 어댑터 전압 -1V 아래면 즉시 K1 끔, 재부팅 전까지 재투입 안 함(3.5절) |
| MCU 멈춤 | WDT_T4 워치독 리셋. 구동 트랜지스터 베이스 풀다운으로 K1 해제 |

미터는 `getCurrentGain_dB` 값을 8칸으로 나눈다.

### 6.5 코드 단위

| 단위 | 역할 | 검증 |
|---|---|---|
| `Compressor` | F32 블록. 검출기, 사이드체인 HPF, 게인 계산 | PC 네이티브 테스트, HexeFX 블록 대조 |
| `ParamMapper` | 노브 → 파라미터, PGA 분할·보상·전환 규칙, 유니티 트림 | 네이티브 테스트 |
| `BypassController` | K1·램프 상태 머신, 모드, 전원 감시 | 네이티브 테스트 |
| `Controls` | ADC 평활, 풋스위치 디바운스 | 네이티브 테스트 |
| `Meter` | 감쇠량 → LED, 클립 점멸 | 네이티브 테스트 |
| 그래프 결선 | 위 단위 연결 | 실기기 |

빌드는 PlatformIO로 네이티브 테스트 환경과 Teensy 환경을 한 프로젝트에 둔다. OpenAudio PlatformIO
패키지의 빌드 여부는 확인 필요.

## 7. 테스트와 판정 기준

### 7.1 측정 환경

- 스칼렛 솔로 3세대와 PC, Fluke 101 멀티미터. 오실로스코프·온도계 없음
- 스칼렛 라인아웃 최대 +15.5dBu, 라인 입력 최대 +22dBu, INST 입력 최대 +12.5dBu(문서 기준). 라인아웃은
  전자식 밸런스라 TS로 연결하면 절반인 약 +9.5dBu까지 나올 것으로 보고 M2에서 확인한다
- 입력 +17dBu 헤드룸은 직접 쏘지 않고 T5 외삽과 T6(같은 op-amp·레일인 출력단)으로 판정한다
- Teensy 내부 온도 센서(tempmon)를 케이스 안 발열의 대리 지표로 쓴다

### 7.2 대조군

| 대조군 | 테스트 |
|---|---|
| 스칼렛 루프백 케이블 | T3, T4, T7, T8 |
| 트루 바이패스 경로 | T4 |
| HexeFX 컴프레서 블록 | T9 |
| 한 번 녹음한 재즈 베이스 DI 트랙 | T10, T16 |

### 7.3 항목

T4, T5, T6, T7, T9, T11의 판정 기준은 근거 문서 없이 정한 값이라 [계획서](bass-effector.md#단계)의 1단계 결과를 보고 조정한다.

| # | 항목 | 방법 | 판정 기준 |
|---|---|---|---|
| M1 | 보유 베이스 피크 | 스칼렛 INST 입력, 게인 최소에서 핑거·슬랩을 녹음해 피크 dBFS 기록. 0dBFS = +12.5dBu 사인 기준(피크 약 4.62V)으로 환산. 클립하면 라인 모드(+22dBu)로 다시 잰다. 베이스 볼륨·톤과 줄 상태를 함께 기록 | 기록. 패시브 PGA 상한과 4.4절 표의 사용 구간을 정한다 |
| M2 | 스칼렛 교정 | 100Hz 사인을 TS 출력으로 내보내 Fluke 101 AC 전압으로 재고, 루프백으로 입력 스케일 확정 | dBFS와 dBu 환산 상수 기록. Fluke 101 AC 측정 대역 40~500Hz(문서 기준) 안이다 |
| T0 | 첫 전원 전 점검 | 멀티미터로 DC 극성, 레일·5V·3.3V 단락 여부 | 극성 일치, 단락 없음 |
| T1 | 아날로그 레일 | 전 부하 상태 전압과 어댑터 실제 출력 | 16.1V 이상 |
| T2 | 발열 | 케이스 닫고 1시간 연속 동작, tempmon 로그 | 열 차단(출력 끊김) 없음. 7805 온도는 측정 수단이 없어 미판정 |
| T3 | 주파수 응답 | 스윕. 트루, 버퍼드, 이펙트(레시오 1:1) | 루프백 대비 20Hz~20kHz ±1dB |
| T4 | 유니티 | 1kHz -10dBu. 루프백으로 스칼렛 자체 레벨을 먼저 잰 뒤 트루 바이패스 대비 버퍼드와 이펙트(압축 없음, Output 12시, Blend 전 구간) | 유니티 트림 상수를 정한 뒤 ±0.5dB |
| T5 | 입력 풀스케일과 PGA 계단 | PGA 단계별로 ADC 0dBFS에 닿는 입력 레벨 | PGA +9dB에서 코덱 단독 -6.8dBu, 패드 포함 +8.2dBu, 각 ±1dB. 계단당 1.5 ±0.2dB |
| T6 | 출력 헤드룸 | T4 유니티 트림을 적용한 뒤 DSP 내부 사인 레벨을 올려 가며 스칼렛 라인 입력으로 THD+N 1%에 닿는 출력을 찾는다 | +16.5dBu 이상 |
| T7 | PGA별 바닥 노이즈 | 스칼렛 게인을 올려 자체 바닥을 충분히 낮춘 뒤 루프백으로 그 바닥을 재고 전력으로 뺀다. 입력 단락과 베이스 연결·줄 뮤트 두 조건, PGA 0/+9/+18dB. 125~8000Hz와 20Hz~20kHz 무가중 둘 다, I2S 배선 길이 기록 | 125~8000Hz에서 풀스케일 대비 다이내믹 레인지 75dB 이상. 미달이면 코덱 교체 검토 |
| T8 | 왕복 지연 | 루프백 대비 이펙트 경로 시간차 | ms 기록. 판정은 T16 |
| T9 | 컴프레서 정합 | 계단 레벨 사인, 같은 파라미터로 자체 블록과 HexeFX 블록 | 정적 게인 곡선 차 0.1dB 이하, 어택·릴리즈 시정수 ±10% |
| T10 | 사이드체인 HPF | DI 트랙을 HPF 끔/켬으로 재생, B·E현 저음의 감쇠량과 청음 | 청음 A/B. 기본 차단 주파수를 여기서 정한다 |
| T11 | 릴레이 전환음 | 무음과 지속음에서 K1 전환 녹음. 바이패스를 10초 이상 유지한 뒤 켜는 경우와, 켜자마자 끄고 다시 켜는 경우 | 무음: 출력 과도 피크 -60dBu 이하. 지속음: 케이블을 뽑았다 꽂는 것 대비 추가 팝 없음, 청음 |
| T12 | 전원 투입·차단 | 신호를 넣으며 DC 잭 연결·분리 | 신호 끊김 없음, 과도는 T11 무음 기준. 차단 시 감시 경로와 리셋 경로(감시를 끈 디버그 빌드) 각각에서 K1이 레일보다 먼저 풀린다. 과전압 차단은 18V 전원이 없어 미판정 |
| T13 | PGA 계단 전환 | 지속음에서 Input을 돌리며 녹음, 클리핑 중 하향 전환 포함. 톤을 넣고 PGA를 계단시켜 보상 정렬 오프셋 측정 | 전환 과도 크기(dB) 기록, 청음에서 거슬리지 않음. 조용함 판정 레벨·시간과 정렬 오프셋을 여기서 정한다 |
| T14 | 제어 기능 | 탭 온/오프, 부팅 시 모드 변경과 재부팅 후 유지, 디버그 빌드 강제 정지로 워치독 리셋, 9V 연결 상태 펌웨어 업로드 | 모두 동작. 리셋 중 트루 바이패스 |
| T15 | 입력 클립 표시 | T5에서 0dBFS 도달 시 | 미터 점멸 |
| T16 | 연주 판정 | DI 트랙 재생으로 Input·Blend를 먼저 잡은 뒤 패시브 재즈 베이스, 핑거와 슬랩으로 30분 이상 연습 2회. 앰프 또는 스칼렛 | 연습에 쓴다 |

| 리스크 | 영향 | 대응 |
|---|---|---|
| LT1054 발진 하한 15kHz가 오디오에 섞임 | 고역 휘슬 | 레일 RC/LC 필터, 배치 분리. T3·T7에서 확인 |
