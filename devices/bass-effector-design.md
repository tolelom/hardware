# 베이스 컴프레서 페달 설계서

계획서: [bass-effector.md](bass-effector.md)
최종 갱신: 2026-09-14

---

## 1. 목표와 범위

패시브·액티브 베이스를 모두 받는 컴프레서 페달 1대를 만든다. 슬랩 연주의 피크와 18V 프리앰프
베이스까지 입력으로 받고, 앰프 입력에 바로 연결해 연습에 쓴다.

범위에 포함:
- 디지털 코어(Teensy 4.1, SGTL5000 코덱)와 아날로그 입출력단
- 컴프레서 알고리즘 자체 구현
- 릴레이 바이패스(트루, 버퍼드 선택)
- 기성 다이캐스트 케이스 가공과 조립

범위에서 제외:
- 멀티밴드, 모드 전환(1176·옵토 스타일 등), 프리셋, 설정 앱, 스테레오
- 사이드체인 HPF 노브(펌웨어 고정값으로 시작)
- 드라이브·EQ·옥타버·딜레이·루퍼. 같은 하드웨어에서 펌웨어로 늘릴 수 있게 코덱 경로를 유지하지만
  1호 범위는 아니다

## 2. 레퍼런스

요구 수치의 근거가 된 상용 제품이다. 전부 문서 기준.

| 제품 | 신호 경로 | 헤드룸 확보 | 최대 입출력 | 블렌드 | 감쇠 미터 | 바이패스 |
|---|---|---|---|---|---|---|
| MXR M87 | 아날로그 | 9V | 입력 +14dBV, 출력 +9.2dBV | 없음 | LED | 트루 |
| Aguilar TLC | 아날로그 | 9V | 출력 +6dBu | 없음 | 없음 | 배터리 방전 시 통과 |
| Origin Effects Cali76 Bass | 아날로그 | 내부 24V | 표기 없음 | Dry 노브 | LED 10칸 | 버퍼드 |
| UAFX 1176 Studio Compressor | 디지털 | 공개 안 됨 | 입출력 +12.2dBu | Parallel 스위치 | LED 색 | 트루/버퍼드 선택 |
| Boss BC-1X | 디지털 멀티밴드 | 내부 18V | 공칭 입력 -20dBu | 없음 | 16칸 | 버퍼드 |
| Darkglass Hyper Luminal | 아날로그 VCA, 디지털 사이드체인 | 공개 안 됨 | 표기 없음 | Blend 노브 | 10칸 | 확인 필요 |
| EBS MultiComp Blue Label | 아날로그 | 외부 9~18V, ACTIVE/PASSIVE 스위치 | 공칭 -10/-4dBV | 확인 필요 | 확인 필요 | 릴레이 |

앰프 쪽 입력 스위치 사례: Ampeg BA 시리즈의 -15dB 패드 스위치(출력이 큰 소스 보상용).

## 3. 요구 사항

### 3.1 신호

| 항목 | 요구 | 근거 |
|---|---|---|
| 입력 임피던스 | 1MΩ | 레퍼런스 공통 |
| 최대 입력 | 약 +17dBu (Input 노브 최소 위치) | M87 +16.2dBu 환산, Ampeg -15dB 패드, Cali76 24V. 18V 프리앰프의 이론 상한은 약 +18.3dBu다(±9V 사인) |
| 최대 출력 | 약 +17dBu | 입력 상한과 같아야 블렌드·약한 압축에서 유니티가 유지된다 |
| 아날로그 경로 스윙 | 입력 버퍼, 패드, 출력단 전 구간이 +17dBu를 통과 | |
| 유니티 | 바이패스 볼륨 = 입력. Input 위치와 무관하게 압축이 걸리지 않은 신호는 Output 12시에서 유니티 | UAFX 1176, Cali76 매뉴얼 |
| 주파수 응답 | 20Hz~20kHz ±1dB | M87, UAFX 1176 사양. 5현 B현 기음은 약 31Hz |

### 3.2 컨트롤

노브 5개, 토글 없음.

| 컨트롤 | 동작 |
|---|---|
| Input | 고정 패드 뒤 코덱 아날로그 게인(0~+22.5dB)을 먼저 쓰고, 그 위는 고정 스레숄드로 미는 디지털 드라이브 |
| Ratio | 연속 가변 |
| Att/Rel | 한 노브. 반시계 끝 = 빠른 어택·느린 릴리즈, 시계 끝 = 느린 어택·빠른 릴리즈 |
| Output | 마스터. 12시 = 0dB |
| Blend | 드라이/웻 믹스 |

사이드체인 HPF는 펌웨어 고정값이다.

### 3.3 표시

- 감쇠량 LED 8칸, 이펙트 온 LED 1개
- 입력 클립: ADC 샘플이 풀스케일 근처에 닿으면 미터 전체 점멸

### 3.4 바이패스

- K1(논래칭 DPDT 릴레이): 코일이 꺼져 있으면 입력 잭과 출력 잭을 직결한다. 전원 투입 중·차단 시·MCU
  리셋 중에는 항상 트루 바이패스
- K2(논래칭 릴레이): K1이 켜진 상태에서 출력을 버퍼 경로와 이펙트 경로 중 하나에 연결한다
- 모드: 트루 바이패스 / 버퍼드 바이패스. 부팅 시 풋스위치를 누르고 있으면 전환되고 EEPROM에 저장된다

### 3.5 전원

- 정전압 9V, 센터 마이너스 2.1mm, 300mA 이상
- DC 입력 역극성 보호
- 전원 투입·차단 시 출력에 과도음이 나가지 않음(K1 트루 바이패스로 보장)

### 3.6 펌웨어 업데이트

- 케이스를 열지 않고 USB에 접근
- Teensy의 VIN·VUSB 패드를 끊어 9V 동작 중 USB 연결을 허용한다. 끊은 뒤에는 펌웨어를 올릴 때도 9V가
  연결돼 있어야 한다

## 4. 시스템 구성

### 4.1 블록도

```
            K1 코일 꺼짐: IN 잭 ─────────────────────────────────────────── OUT 잭
            K1 코일 켜짐:
IN ─ 1MΩ ─ [버퍼 ×1] ─┬─ [커플링] ─ [패드 -15dB] ─ 코덱 ADC ─ Teensy ─ 코덱 DAC ─ [출력단 +15.5dB] ─┐
           OPA2992 A  │                            (SGTL5000)  F32 DSP            OPA2992 B          │
                      └──────────────────────────────────────────────── K2 ─────────────────────────┴─ OUT

9V DC ─ 역극성 보호 ─┬─ LT1054 더블러 ─ 레일 필터 ─ 아날로그 레일 ─ 버퍼, 출력단, 바이어스(레일 1/2)
                    └─ 7805 ─ 5V ─ Teensy VIN, 릴레이 구동
                                   └─ Teensy 3.3V ─ 코덱, 노브, LED
```

패드는 버퍼 뒤에 둔다. 버퍼드 바이패스 신호를 패드 앞에서 가져와야 유니티가 된다.

### 4.2 헤드룸 체인

| 구간 | 값 | 비고 |
|---|---|---|
| 코덱 LINEIN 최대 | 2.83Vpp (+2.2dBu) | SGTL5000 데이터시트, VDDA 3.3V. Audio Shield Rev D는 VDDA가 3.3V(PJRC 회로도) |
| 입력 풀스케일 | +17.2dBu (PGA 0dB) | 패드 -15dB |
| 코덱 LINEOUT 0dBFS | 2.61Vpp 통상, 2.53Vpp 최소 (+1.5dBu) | SGTL5000 데이터시트, 10kΩ 부하 |
| 출력단 게인 | +15.5dB | 출력 최대 약 +17dBu |
| 아날로그 레일 | 16.1V 이상 필요 | ±7.77V(+17dBu) 피크에 op-amp 출력 여유 0.3V를 더한 값 |

- op-amp: OPA2992. 입력 공통모드 범위가 레일 끝까지, 출력은 레일에서 220~300mV(40V, 2kΩ),
  7nV/√Hz, 채널당 약 1.2mA. SOIC-8만 있다. 문서 기준
- 차지 펌프: LT1054. 입력 3.5~15V(절대 최대 16V), 발진 15~35kHz(통상 25kHz). 문서 기준.
  무안정 어댑터를 쓰면 레일도 같이 올라가서 3.5절의 정전압 요구가 필요하다
- 패드 출력 임피던스는 LINEIN 입력 임피던스(29kΩ)보다 충분히 작게, 출력단 입력 임피던스는 LINEOUT 최소
  부하(10kΩ) 이상으로 한다

### 4.3 디지털

- Teensy 4.1과 Audio Shield Rev D를 옆으로 나란히 배치하고 I2S·I2C를 배선한다
- 노브 5개: A10~A13(핀 24~27), A14(핀 38). Shield가 쓰는 핀(6, 7, 8, 10~13, 15, 18~21, 23)과 겹치지 않는다
- 풋스위치, LED 9개, 릴레이 구동 2개: 남는 GPIO
- 코덱 교체 경계: I2S, I2C, 라인인·라인아웃, 3.3V. Teensy 오디오 라이브러리가 지원하는 코덱은 SGTL5000,
  WM8731, TLV320AIC3206, AK4558, CS4272, CS42448이다

### 4.4 노이즈 기대치

OpenAudio 블로그 측정에서 Teensy 오디오 보드의 다이내믹 레인지는 약 81dB(125~8000Hz, ADC HPF 끔)이고
입력 게인과 거의 무관했다. 같은 글에서 TLV320AIC3206은 92.4~94.6dB였다. 이 81dB를 적용한 입력 기준
기대치:

| 조건 | PGA | 입력 풀스케일 | 바닥 노이즈 |
|---|---|---|---|
| 출력이 큰 액티브 베이스 | 0dB | +17.2dBu | 약 -64dBu |
| 패시브 베이스, 핑거 | 약 +18dB | 약 -0.8dBu | 약 -82dBu |

7절 T7이 이 표를 확인한다. 기대치보다 크게 나쁘면 코덱 교체 경계(4.3절)를 쓴다.

## 5. 기구

### 5.1 케이스

1590BB 클론. 페달파츠 표기 외형 95 × 120 × 34mm. Hammond 문서 기준으로 1590BB는 높이 30mm, 1590BB2는
33.8mm이고 사용 면적은 약 104 × 79mm라, 받은 케이스의 높이는 확인 필요.

125B(사용 면적 52.1 × 107.8mm)는 노브 5개를 20.3mm 간격으로 놓으면 가장자리 여유가 약 2mm라 모듈과
만능 기판 구성에는 쓰지 않는다. UAFX 1176과 Cali76 Bass는 이 크기지만 전용 기판이다.

### 5.2 패널 배치

```
 ┌──────────────── 윗면: DC 잭, USB ─────────────────┐
 │  (Input)  (Ratio)  (Att/Rel)  (Blend)  (Output)    │
OUT│                                                  │IN
 │         ● ● ● ● ● ● ● ●      ○ 온                  │
 │                     [풋스위치]                     │
 └────────────────────────────────────────────────────┘
```

| 부품 | 치수 |
|---|---|
| 포텐셔미터 | Alpha 16mm 솔더 러그, 널링 축, 케이스 홀 7.5mm |
| 노브 | 푸시핏, 지름 18.9mm. 간격 약 22mm |
| 풋스위치 | 모멘터리, 홀 12mm. 패널 아래 깊이 확인 필요 |
| LED | 3mm 9개 |
| IN, OUT 잭 | 박스형 1/4" 잭, 홀 9.5mm, 몸체 16 × 16mm |
| DC 잭 | 홀 12mm |
| USB | 패널 장착 Micro-B 연장 케이블, M3 고정 귀 간격 17.3mm |

LED 일렬 타공은 페달파츠 사용자 지정 홀가공으로 맡길 수 있다.

### 5.3 내부 배치

- Audio Shield는 Teensy 위에 쌓지 않는다. 소켓 적층은 높이가 34mm 케이스에 맞지 않는다
- 아날로그 기판(버퍼, 패드, 출력단, LT1054, 7805, 릴레이)과 Teensy·Shield 기판을 풋스위치 좌우로 나눈다
- 차지 펌프는 입력 네트워크에서 가장 먼 쪽, 릴레이도 1MΩ 입력단에서 떨어뜨린다
- 접지는 스타 결선. 차지 펌프 리플 전류와 디지털 리턴이 입력단 접지를 지나지 않게 한다

### 5.4 방열

7805 탭을 절연 패드를 끼워 케이스 벽에 고정한다. MC7805 TO-220의 방열판 없는 접합-공기 열저항은
65°C/W, 접합-케이스는 5°C/W다(문서 기준). 릴레이는 9V 코일품을 써서 코일 전류를 7805에서 뺀다.
9V 코일 모델 품번은 확인 필요.

## 6. 펌웨어

### 6.1 출발점

문서 기준.

| 블록 | 구성 |
|---|---|
| OpenAudio `AudioEffectCompressor_F32` | RMS 검출(제곱, 저역통과, dB), 스레숄드, 레시오, 어택/릴리즈, 프리게인. HPF(20Hz)는 오디오 경로 전체에 걸리고 검출기는 필터된 신호를 본다. 니·메이크업 없음 |
| HexeFX `AudioEffectCompressorStereo_F32` (MIT) | 위에 포스트게인, 사이드체인 L+R 모드, `getCurrentGain_dB()`, 바이패스 추가. 사이드체인 전용 HPF·니 없음 |

컴프레서 블록은 직접 구현한다. HexeFX 블록은 같은 입력에 대한 게인 곡선 대조군으로 쓴다.

### 6.2 오디오 그래프

```
I2S_F32 in ─┬─ [입력 보상 -PGA] ─ [프리게인] ─ [컴프레서: 검출기 앞 사이드체인 HPF] ─┐
            └─ [입력 보상 -PGA] ─────────────── 드라이 ────────────────────────────┴─ [Blend] ─ [Output] ─ I2S_F32 out
```

- 44.1kHz, 블록 32샘플. `AudioSettings_F32`로 지정하고 128 이하여야 한다(문서 기준)
- 드라이와 웻은 같은 블록에서 나와 시간이 맞는다
- 코덱 ADC HPF는 끈다(`adcHighPassFilterDisable()`). OpenAudio 측정에서 켜 두면 톤 잡음이 났다.
  DC 제거는 컴프레서 블록에서 한다
- 코덱 ADC 제로 크로스는 레지스터 쓰기가 protected라 `AudioControlSGTL5000` 상속 클래스에서 설정한다

### 6.3 노브 매핑

| 노브 | 매핑 |
|---|---|
| Input | 전체 입력 게인을 PGA 구간(1.5dB 단계, 히스테리시스)과 디지털 프리게인으로 나눈다. PGA 게인만큼 디지털로 되돌려 압축 전 레벨을 유지한다 |
| Ratio | 연속 |
| Att/Rel | 3.2절 |
| Output | Blend 뒤 마스터 게인. 12시 0dB |
| Blend | 선형 크로스페이드. 등전력 곡선과 청음 비교 |

노브는 약 100Hz로 읽어 평활하고, 파라미터 변화는 블록 안에서 램프한다.

### 6.4 상태 머신

| 상황 | 순서 |
|---|---|
| 부팅 | K1 꺼짐 → 코덱 초기화 → 아날로그 레일 안정 대기 → 버퍼드 모드면 K1·K2로 버퍼 경로 연결 |
| 이펙트 켬 | 웻 램프 0 → 릴레이 전환 → 동작 시간 대기 → 웻 램프 인 |
| 이펙트 끔 | 웻 램프 아웃 → 버퍼드 모드면 K2를 버퍼 경로로, 트루 모드면 K1 해제 |
| 모드 변경 | 부팅 시 풋스위치 누름 → 모드 전환, EEPROM 저장 |
| MCU 멈춤 | WDT_T4 워치독 리셋. 릴레이 구동 트랜지스터 베이스 풀다운으로 K1 해제 |

미터는 `getCurrentGain_dB` 값을 8칸으로 나눈다.

### 6.5 코드 단위

| 단위 | 역할 | 검증 |
|---|---|---|
| `Compressor` | F32 블록. 검출기, 사이드체인 HPF, 게인 계산 | PC 네이티브 테스트, HexeFX 블록 대조 |
| `ParamMapper` | 노브 → 파라미터, PGA 분할과 보상 | 네이티브 테스트 |
| `BypassController` | 릴레이·램프 상태 머신 | 네이티브 테스트 |
| `Controls` | ADC 평활, 풋스위치 디바운스 | 네이티브 테스트 |
| `Meter` | 감쇠량 → LED, 클립 점멸 | 네이티브 테스트 |
| 그래프 결선 | 위 단위 연결 | 실기기 |

빌드는 PlatformIO로 네이티브 테스트 환경과 Teensy 환경을 한 프로젝트에 둔다. OpenAudio PlatformIO
패키지의 빌드 여부는 확인 필요.

## 7. 테스트와 판정 기준

### 7.1 측정 환경

- 스칼렛 솔로 3세대와 PC, Fluke 101 멀티미터. 오실로스코프·온도계 없음
- 스칼렛 라인아웃 최대 +15.5dBu는 밸런스 기준이고, TS 연결 시 절반이 되는 원리라 약 +9.5dBu까지
  나온다. 입력 +17dBu 헤드룸은 직접 쏘지 않고 T5 외삽과 T6(같은 op-amp·레일인 출력단)으로 판정한다
- 스칼렛 라인 입력 최대 +22dBu, INST 입력 최대 +12.5dBu(문서 기준)

### 7.2 대조군

| 대조군 | 테스트 |
|---|---|
| 스칼렛 루프백 케이블 | T3, T4, T7, T8 |
| 트루 바이패스 경로 | T4 |
| HexeFX 컴프레서 블록 | T9 |
| 한 번 녹음한 재즈 베이스 DI 트랙 | T10, T16 |

### 7.3 항목

T4, T5, T6, T7, T9, T11의 판정 기준은 근거 문서 없이 정한 값이라 1단계 결과를 보고 조정한다.

| # | 항목 | 방법 | 판정 기준 |
|---|---|---|---|
| T0 | 첫 전원 전 점검 | 멀티미터로 DC 극성, 레일·5V·3.3V 단락 여부 | 극성 일치, 단락 없음 |
| T1 | 아날로그 레일 | 전 부하 상태 전압 | 16.1V 이상 |
| T2 | 7805 발열 | 케이스 닫고 1시간 연속 동작 | 열 차단(출력 끊김) 없음. 온도는 측정 수단이 없어 미판정 |
| T3 | 주파수 응답 | 스윕. 트루, 버퍼드, 이펙트(레시오 1:1) | 루프백 대비 20Hz~20kHz ±1dB |
| T4 | 유니티 | 1kHz -10dBu. 트루·버퍼드 바이패스 대비 이펙트(압축 없음, Output 12시, Blend 전 구간) | ±0.5dB |
| T5 | 입력 풀스케일과 PGA 계단 | PGA 단계별로 ADC 0dBFS에 닿는 입력 레벨 | PGA +9dB에서 +8.2dBu ±1dB, 계단당 1.5 ±0.2dB |
| T6 | 출력 헤드룸 | DSP 내부 사인 0dBFS를 스칼렛 라인 입력으로 | THD+N 1% 이하에서 +16.5dBu 이상 |
| T7 | PGA별 바닥 노이즈 | 입력 단락, 그리고 베이스 연결·줄 뮤트. PGA 0/+9/+18dB | 기록. PGA +18dB 입력 기준 -76dBu보다 나쁘면 코덱 교체 검토 |
| T8 | 왕복 지연 | 루프백 대비 이펙트 경로 시간차 | ms 기록. 판정은 T16 |
| T9 | 컴프레서 정합 | 계단 레벨 사인, 같은 파라미터로 자체 블록과 HexeFX 블록 | 정적 게인 곡선 차 0.1dB 이하, 어택·릴리즈 시정수 ±10% |
| T10 | 사이드체인 HPF | DI 트랙을 HPF 끔/켬으로 재생, B·E현 저음의 감쇠량과 청음 | 청음 A/B. 기본 차단 주파수를 여기서 정한다 |
| T11 | 릴레이 전환음 | 무음·지속음에서 K1, K2 전환 녹음 | 출력 과도 피크 -60dBu 이하, 청음 |
| T12 | 전원 투입·차단 | 신호를 넣으며 DC 잭 연결·분리 | 신호 끊김 없음, 과도 T11과 같은 기준 |
| T13 | PGA 계단 글리치 | 지속음에서 Input을 돌리며 녹음 | 청음에서 거슬리지 않음, 과도 크기 기록 |
| T14 | 제어 기능 | 탭 온/오프, 부팅 시 모드 변경과 재부팅 후 유지, 디버그 빌드 강제 정지로 워치독 리셋, 9V 연결 상태 펌웨어 업로드 | 모두 동작. 리셋 중 트루 바이패스 |
| T15 | 입력 클립 표시 | T5에서 0dBFS 도달 시 | 미터 점멸 |
| T16 | 연주 판정 | 패시브 재즈 베이스, 핑거와 슬랩으로 30분 이상 연습 2회. 앰프 또는 스칼렛 | 연습에 쓴다 |

단계별 테스트 배정은 [계획서](bass-effector.md#단계)에 있다.
