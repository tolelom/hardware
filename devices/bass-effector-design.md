# 베이스 컴프레서 페달 설계서

계획서: [bass-effector.md](bass-effector.md)
최종 갱신: 2026-09-15

---

## 1. 목표와 범위

패시브·액티브 베이스를 모두 받는 컴프레서 페달 1대를 만든다. 슬랩 연주의 피크와 18V 프리앰프
베이스까지 입력으로 받고, 앰프 입력에 바로 연결해 연습에 쓴다.

범위에 포함:
- 디지털 코어(Daisy Seed3, TAC5242 코덱)와 아날로그 입출력단
- 컴프레서 알고리즘 자체 구현
- 릴레이 트루 바이패스와 DSP 경로 버퍼드 바이패스
- 기성 다이캐스트 케이스 가공과 조립

범위에서 제외:
- 멀티밴드, 모드 전환(1176·옵토 스타일 등), 프리셋, 설정 앱, 스테레오
- 사이드체인 HPF 노브(펌웨어 고정값으로 시작)
- AD/DA를 거치지 않는 아날로그 버퍼드 바이패스
- 드라이브·EQ·옥타버·딜레이·루퍼. 같은 하드웨어에서 펌웨어로 늘릴 수 있게 코덱 경로를 유지하지만
  1호 범위는 아니다

## 3. 요구 사항

### 3.1 신호

| 항목 | 요구 | 근거 |
|---|---|---|
| 입력 임피던스 | 1MΩ | 레퍼런스 공통 |
| 최대 입력 | 약 +17dBu (Input 노브 최소 위치) | M87 +16.2dBu 환산, Ampeg -15dB 패드, Cali76 24V. 18V 프리앰프의 이론 상한은 약 +18.3dBu다(±9V 사인) |
| 최대 출력 | 약 +17dBu | 입력 상한과 같아야 블렌드·약한 압축에서 유니티가 유지된다 |
| 아날로그 경로 스윙 | 입력 버퍼, 패드, 출력단 전 구간이 +17dBu를 통과 | |
| 유니티 | 바이패스 볼륨 = 입력. Input 위치와 무관하게 압축이 걸리지 않은 신호는 Output 12시에서 유니티 | UAFX 1176, Cali76 매뉴얼 |
| 주파수 응답 | 20Hz~20kHz ±1dB | M87, UAFX 1176 사양. 5현 B현 기음은 약 31Hz |

보유 패시브 재즈 베이스의 핑거·슬랩 피크(M1)로 Input 노브의 게인 범위를 정한다.

### 3.2 컨트롤

노브 5개, 토글 없음.

| 컨트롤 | 동작 |
|---|---|
| Input | 고정 패드 뒤 디지털 게인으로 입력을 고정 스레숄드에 민다. 코덱에 소프트웨어로 바꾸는 아날로그 게인이 없다(4.3절). 압축 전 레벨은 Input 위치와 무관하게 유지된다 |
| Ratio | 연속 가변 |
| Att/Rel | 한 노브. 반시계 끝 = 빠른 어택·느린 릴리즈, 시계 끝 = 느린 어택·빠른 릴리즈 |
| Output | 마스터. 12시 = 0dB |
| Blend | 드라이/웻 믹스 |

사이드체인 HPF는 펌웨어 고정값이다.

### 3.3 표시

- 감쇠량 LED 8칸, 이펙트 온 LED 1개
- 입력 클립: ADC 샘플이 풀스케일 근처에 닿으면 미터 전체 점멸

### 3.4 바이패스

- K1(논래칭 DPDT 릴레이): 코일이 꺼져 있으면 입력 잭과 출력 잭을 직결한다. 전원 투입 중·차단 시·MCU
  리셋 중에는 항상 트루 바이패스
- 모드는 둘이다. 트루 바이패스는 K1을 끈다. 버퍼드 바이패스는 K1을 켠 채 DSP가 드라이 신호만 유니티로
  내보낸다
- 부팅 시 풋스위치를 누르고 있으면 모드가 바뀌고 QSPI 플래시에 저장된다

### 3.5 전원

- 정전압 9V, 센터 마이너스 2.1mm, 500mA 이상
- 역극성 보호와 과전압 차단은 P-MOSFET 2개를 소스끼리 맞댄 백투백으로 한다. 직렬 다이오드 강하가 아날로그
  레일 여유를 먹는다(4.2절)
  - Q1은 드레인이 DC 잭 쪽, Q2는 드레인이 부하 쪽이고 두 소스를 잇는다. 게이트 둘은 묶어 GND로 풀다운한다
  - 하나로는 안 된다. 역극성 보호 방향(드레인이 입력)으로 놓은 P-MOSFET은 바디 다이오드가 정방향 전원에서
    항상 도통하므로, 게이트를 소스로 당겨 채널을 꺼도 입력에서 0.7V 빠진 전압이 부하로 그대로 넘어간다.
    반대 방향으로 놓으면 과전압은 끊지만 역극성에서 바디 다이오드가 도통한다. Q1이 역극성을, Q2가 과전압을 맡는다
- 과전압 차단: 입력이 약 12.7V를 넘으면 12V 제너와 PNP가 공통 게이트를 공통 소스로 끌어올려 두 채널을 끊는다.
  게이트는 GND 쪽으로 당겨져 있어 소스(높은 전위)로 올리는 스위치는 PNP여야 한다. NPN 에미터 팔로워는 제너 강하만큼
  낮은 곳까지만 올려 채널이 안 꺼진다. PNP 베이스와 제너 사이에 전류 제한 R을 둔다.
  Q2의 바디 다이오드가 부하 쪽으로 막혀 있어 18V 어댑터를 잘못 꽂아도 LT1054 절대 최대 16V에 닿지 않고 소모되는
  부품이 없다. P-MOSFET은 Vgs 정격 ±20V 이상이거나 게이트에 보호 제너와 직렬 R을 둔다. 제너는 낮은 전류에서
  12V보다 조금 아래에서 꺾이므로 실제 임계는 12.7V보다 약간 낮다. 정전압 9V 어댑터의 무부하 전압(9~9.6V)은
  안 걸린다
- 전원 투입 시 출력 과도음 없음: 트루 모드는 K1이 꺼져 있어 성립한다. 버퍼드 모드는 부팅 완료 시 K1 전환이
  1회 있고 그 과도는 T11 기준으로 판정한다
- 전원 차단 시 출력 과도음 없음: 두 경로가 있다
  - 감시 경로: 9V 입력을 분압해 오디오 블록 주기(1ms)로 읽고 이동 평균한다. 부팅 시 잰 어댑터 전압에서
    1V 내려간 값을 임계로 두고, 넘어서면 K1을 끄고 재부팅 전까지 다시 켜지 않는다. 벌크 C 1000µF, 부하 약
    230mA면 9V에서 임계 8V까지 약 4.3ms, Seed3 VIN 하한 4V까지 약 22ms라 감지와 K1 릴리즈(2ms)가 그
    안에 끝난다. 잭을 꽂은 채 어댑터를 콘센트에서 뽑으면 두 MOSFET 채널이 역방향으로도 도통해 벌크 C가
    어댑터 쪽으로도 방전되므로, 이 시간은 어댑터 내부 부하만큼 짧아진다
  - 리셋 경로: 감시가 실패해도 VIN이 Seed3 하한 아래로 내려가 MCU가 리셋되고 구동 트랜지스터 풀다운으로
    K1이 풀린다.
    레일 C는 더블러 다이오드가 역류를 막아 자기 부하로만 방전되므로 9V 노드보다 늦게 무너진다
  - 분압비는 3.3/16 이하로 하고 ADC 핀 앞에 직렬 R과 소용량 C를 둔다. Seed3 ADC 핀의 동작 범위는 0~3.3V다
    (데이터시트 표 3)

### 3.6 펌웨어 업데이트

- 케이스를 열지 않고 USB-C에 접근
- Seed3는 VIN과 USB 전원을 동시에 연결해도 된다(데이터시트). 패드 절단 같은 개조가 없다
- 업로드는 USB DFU다. 모듈의 BOOT·RESET 버튼은 케이스 안에 있으므로 시리얼 콘솔 명령으로
  `System::ResetToBootloader`를 불러 DFU 모드에 들어간다. 펌웨어가 응답하지 않으면 케이스를 열어 버튼을 쓴다

## 4. 시스템 구성

### 4.1 블록도

```
K1: 논래칭 DPDT. 코일 꺼짐 = NC
  극 1  IN 잭 ─┬─ NC ─────────────────────────────────── 극 2 NC
               └─ NO ─┬─ R_pd ─ GND
                      └─ 직렬 R ─ 커플링 C ─┬─ R_bias ─ Vbias
                                            └─ [버퍼 ×1, OPA2992 A] ─ 커플링 C ─ [패드 -15dB] ─ 종단 RC ─ Seed3 Audio In 1
  극 2  OUT 잭 ─┬─ NC ─ 극 1 NC
                └─ NO ─┬─ 방전 R ─ GND
                       └─ 출력 직렬 R ─ 커플링 C ─ [출력단 +14.8dB, OPA2992 B, Vbias 기준] ─ 커플링 C ─ Seed3 Audio Out 1

9V DC ─ P-MOSFET ×2 백투백(Q1 역극성 보호, Q2 과전압 차단: 12V 제너 + PNP) ─ 벌크 C ─┬─ LT1054 더블러(쇼트키 ×2) ─ 레일 필터 ─ 아날로그 레일(레일 C)
                                                                     │     └─ Vbias(레일 1/2, 분압과 대용량 C)
                                                                     ├─ K1 코일(9V, 플라이백 다이오드, NPN 구동)
                                                                     ├─ 분압(3.3/16 이하) ─ 직렬 R·소용량 C ─ Seed3 ADC(전원 감시)
                                                                     └─ RC 필터 ─ Seed3 VIN
                                                                                    └─ Seed3 3V3A ─ 노브. 3V3D ─ 풀업. LED와 K1 구동 신호는 GPIO
```

- Seed3 오디오 입력은 모듈 안에서 AC 커플링되고 출력은 1Vrms 풀스케일이다(4.2절). 코덱 앞 바이어스 결선이
  없다
- 종단 RC는 데이터시트 계기 레벨 예시(100Ω과 33nF)의 차단 48kHz를 패드 출력 임피던스에 맞춰 옮긴 것이다

- R_pd와 방전 R은 K1 NO 접점의 회로 쪽에 둔다. 트루 바이패스 중에도 커플링 C의 접점 쪽 극판이 0V로 유지돼
  K1을 켤 때 팝이 나지 않는다
- 입력 임피던스는 교류에서 R_pd와 R_bias의 병렬이다. 2.2MΩ ∥ 1.8MΩ ≈ 1MΩ처럼 병렬 합을 약 1MΩ으로 맞춘다.
  R_pd를 크게 두면 커플링 C 충전 시정수가 길어져(4.7MΩ과 1.27MΩ, 100nF에서 약 0.6초) 빠르게 껐다 켤 때
  팝이 남는다
- 입력 커플링 C는 R_bias와 함께 차단 주파수 10Hz 이하가 되게 정한다
- 입력 직렬 R은 OPA2992 입력 클램프 다이오드로 흐르는 전류를 제한한다
- 출력 직렬 R은 케이블 용량 부하에서 op-amp 안정을 위한 것이다
- K1 구동 트랜지스터는 베이스 저항과 풀다운을 둔다
- 부품 값과 결선은 [회로 설계](bass-effector-schematic.md)에서 정한다

### 4.2 헤드룸 체인

문서 기준.

| 구간 | 값 | 비고 |
|---|---|---|
| Seed3 오디오 입력 최대 | 3.6Vpp (1Vrms, +2.2dBu) | 데이터시트 표 1·3. 모듈 안에서 AC 커플링 |
| 입력 풀스케일 | +17.2dBu | 패드 -15dB |
| Seed3 오디오 출력 0dBFS | 1Vrms (+2.2dBu) | 데이터시트 표 3. 개체 편차는 T4의 유니티 트림으로 흡수 |
| 출력단 게인 | +14.8dB | 출력 최대 약 +17dBu |
| 아날로그 레일 | 16.1V 이상 필요 | ±7.77V(+17dBu) 피크에 op-amp 출력 여유 0.3V를 더한 값 |

- 레일 전압: 더블러 출력은 입력 전압의 2배에서 LT1054 손실(10mA에서 0.35V 통상, 0.55V 최대)과 외부
  쇼트키 다이오드 강하 2개를 뺀 값이다. 입력 9.0V, 쇼트키 0.3V면 통상 약 17.05V, 최대 손실에서 약 16.85V다.
  P-MOSFET R_DS(on) 강하(IRF9540N 0.117Ω, 문서 기준. 250mA에서 2개 합 약 60mV)도 2배로 빠져 통상 약 16.9V다.
  역극성 보호를 직렬 다이오드로 하면 16.1V 요구에 여유가 없어져 P-MOSFET으로 한다(3.5절). 어댑터가 부하에서
  약 8.7V 아래로 처지면 16.1V가 깨지므로 T1에서 어댑터 실전압을 함께 잰다
- op-amp: OPA2992. 입력 공통모드 범위가 레일 끝까지, 출력은 레일에서 220~300mV(40V, 2kΩ),
  7nV/√Hz, 앰프당 2.4mA 통상·2.8mA 최대. SOIC·VSSOP·TSSOP·WSON·SOT-23-THIN이 있고 DIP은 없다
- 차지 펌프: LT1054. 입력 3.5~15V(절대 최대 16V), 발진 15~35kHz(통상 25kHz)
- Seed3 오디오 입출력 임피던스는 공개되지 않았다. 패드는 출력 임피던스를 수 kΩ 아래로 잡아 모듈 입력
  임피던스가 비율에 미치는 영향을 줄이고, 남는 차이는 T5로 잰 값을 펌웨어 상수에 넣는다. 출력단 입력
  임피던스는 데이터시트 예시(15kΩ) 이상으로 한다

### 4.3 디지털

- Daisy Seed3 모듈 1개. 코덱(TI TAC5242), SDRAM, USB-C, 3.3V 레귤레이터가 모듈 안에 있어 코덱 배선이 없다.
  오디오는 모듈 핀 16(Audio In 1)과 18(Audio Out 1)만 쓴다
- TAC5242는 핀 제어 코덱이라 소프트웨어로 바꾸는 아날로그 게인·필터가 없다. libDaisy도 Seed3를 리셋 핀만
  있는 코덱 경로로 초기화한다(`daisy_seed.cpp`). 입력 게인은 전부 디지털이다(6.3절)
- 노브 5개와 전원 감시: A0~A5(핀 22~27). 노브 전원은 3V3A. 풋스위치, LED 9개, K1 구동: D0~D10. I2C·UART 핀
  (D11~D14)은 비워 둔다
- 샘플레이트 48kHz, 블록 48샘플. libDaisy에 44.1kHz는 없다(`sai.h`)
- 빌드는 libDaisy Makefile, 업로드는 USB DFU(3.6절)

### 4.4 노이즈 기대치

TAC5242의 ADC 다이내믹 레인지는 119dB, DAC는 120dB다(TI 데이터시트, 차동 입력 기준). Seed3 모듈의
단일 입력 경로 수치는 공개되지 않았고, 데이터시트의 Pedal Dev Kit 계기 레벨 측정 그래프는 유휴 잡음이
FFT 빈 단위로 -120dBV 부근이다.

입력 게인이 전부 디지털이라 입력 기준 바닥 노이즈는 Input 위치와 무관하게 입력 풀스케일 +17.2dBu에서
모듈 다이내믹 레인지를 뺀 값으로 고정된다. 모듈이 칩 값에 가까우면 약 -100dBu이고, M87의 노이즈 플로어
-95dBV(약 -92.8dBu)보다 낮다. T7 판정 기준 100dB는 칩 값에서 단일 입력 경로와 만능기판 배선 몫으로
19dB를 뺀 값이다.

## 5. 기구

### 5.1 케이스

1590BB 클론. 페달파츠 표기 외형 95 × 120 × 34mm. Hammond 문서 기준으로 1590BB는 외형 119.5 × 94 × 34mm,
내부 높이 30mm, 사용 면적은 약 104 × 79mm다. 페달파츠 표기는 외형 치수라 같은 규격이다. 내부 배치는 높이
30mm 기준으로 한다.

125B(드릴 면 63.6 × 119.3mm, 사용 면적 52.1 × 107.8mm)에 노브 5개를 3개·2개 두 줄로 놓으면, 3개 줄을
20.3mm 간격에 지름 18.9mm 노브로 채울 때 드릴 면 가장자리 여유가 약 2mm라 모듈과 만능 기판 구성에는
쓰지 않는다. UAFX 1176과 Cali76 Bass는 이 크기지만 전용 기판이다.

### 5.2 패널 배치

노브는 3개·2개 두 줄, 간격 25mm. 한 줄 5개를 22mm 간격으로 놓으면 바깥 포텐셔미터 몸체(지름 16mm)가
중심에서 52mm까지 나가 사용 면적 폭(약 104mm)의 절반과 같아진다.

```
 ┌───────────────── 윗면: DC 잭, USB ──────────────────┐
 │     (Input)       (Ratio)       (Att/Rel)            │
OUT│                                                     │IN
 │     (Blend)       (Output)      ● ● ● ● ● ● ● ●  ○ 온  │
 │                      [풋스위치]                      │
 └──────────────────────────────────────────────────────┘
```

| 부품 | 치수 |
|---|---|
| 포텐셔미터 | Alpha 16mm 솔더 러그, 널링 축, 케이스 홀 7.5mm |
| 노브 | 푸시핏, 지름 18.9mm |
| 풋스위치 | 모멘터리, 홀 12mm. 패널 아래 깊이 확인 필요 |
| LED | 3mm 9개 |
| IN, OUT 잭 | 박스형 1/4" 잭, 홀 9.5mm, 몸체 16 × 16mm |
| DC 잭 | 홀 12mm |
| USB | 패널 장착 Micro-B 연장 케이블, M3 고정 귀 간격 17.3mm |

좌표는 케이스와 풋스위치 치수를 잰 뒤 도면으로 정한다. LED 일렬 타공은 페달파츠 사용자 지정 홀가공으로
맡길 수 있다.

### 5.3 내부 배치

- 아날로그 기판(버퍼, 패드, 출력단, 전원 보호, LT1054, K1)과 Seed3 기판(모듈 소켓, VIN 필터, 노브·LED 배선)을
  풋스위치 좌우로 나눈다
- Seed3는 핀 헤더 소켓에 꽂고, USB-C와 BOOT·RESET 버튼이 케이스를 열면 바로 닿는 방향으로 놓는다
- 차지 펌프는 입력 네트워크에서 가장 먼 쪽, K1도 1MΩ 입력단에서 떨어뜨린다
- 접지는 스타 결선. 차지 펌프 리플 전류와 디지털 리턴이 입력단 접지를 지나지 않게 한다
- IRF9540N은 탭이 드레인이다. Q1·Q2 탭끼리 닿으면 두 드레인이 이어져 역극성 보호와 과전압 차단이 둘 다
  빠진다. 두 탭은 서로, 케이스와 떨어뜨린다. 케이스 벽에 고정하는 부품은 없다

### 5.4 방열과 전류

Seed3는 VIN 9V를 모듈 안 레귤레이터로 내린다. 데이터시트는 VIN이 높을수록 레귤레이터 발열이 는다고 적고
수치는 없다. 케이스 벽에 고정하는 발열 부품은 없다.

TQ2-9V는 코일 579Ω, 약 15.5mA, 릴리즈 시간 2ms다(문서 기준).
9V 전류는 이전 Seed가 5V에서 약 100~140mA(포럼 보고, 문서 기준)인 것에 LED, K1 코일, LT1054와 아날로그단을
더해 어댑터 요구를 500mA로 둔다. Fluke 101로는 전류를 재지 않으므로 전류는 계산값으로만 기록한다. 열이
문제되면 MCU 클럭을 낮추는 선택지가 있다(libDaisy `Init(boost)` 인자로 400/480MHz).

## 6. 펌웨어

### 6.1 출발점

문서 기준.

| 블록 | 구성 |
|---|---|
| OpenAudio `AudioEffectCompressor_F32` | RMS 검출(제곱, 저역통과, dB), 스레숄드, 레시오, 어택/릴리즈, 프리게인. HPF(20Hz)는 오디오 경로 전체에 걸리고 검출기는 필터된 신호를 본다. 니·메이크업 없음 |
| HexeFX `AudioEffectCompressorStereo_F32` (MIT) | 위에 포스트게인, 사이드체인 L+R 모드, `getCurrentGain_dB()`, 바이패스 추가. 사이드체인 전용 HPF·니 없음 |

컴프레서 블록은 직접 구현한다.

### 6.2 오디오 그래프

```
오디오 콜백 in ─ [DC 제거] ─┬─ [프리게인] ─ [컴프레서: 검출기 앞 사이드체인 HPF] ─ [-프리게인] ─┐
                            └────────────────────── 드라이 ─────────────────────────────────┴─ [Blend] ─ [Output] ─ [유니티 트림] ─ [마스터 램프] ─ 오디오 콜백 out
```

- 48kHz, 블록 48샘플(1ms). libDaisy 기본값이고 `SetAudioBlockSize`로 바꿀 수 있다
- DC 제거는 드라이·웻 분기 전에 1개. 1차 필터면 차단 주파수 10Hz 이하로 해야 20Hz에서 -1dB 이내다. 라이브러리
  컴프레서의 20Hz HPF는 쓰지 않는다
- 웻 경로의 -프리게인이 Input의 디지털 드라이브를 되돌려, 압축이 걸리지 않은 웻과 드라이 레벨이 같다
- 드라이와 웻은 같은 블록에서 나와 시간이 맞는다
- 코덱은 핀 제어라 펌웨어에서 설정할 것이 없다. ADC HPF 유무는 T3의 저역 응답으로 확인한다

### 6.3 노브 매핑

| 노브 | 매핑 |
|---|---|
| Input | 디지털 프리게인. 범위는 M1로 정한다 |
| Ratio | 연속 |
| Att/Rel | 3.2절 |
| Output | Blend 뒤 마스터 게인. 12시 0dB |
| Blend | 선형 크로스페이드 |

- 노브는 약 100Hz로 읽어 평활하고, 파라미터 변화는 블록 안에서 램프한다

### 6.4 상태 머신

| 상황 | 순서 |
|---|---|
| 부팅 | K1 꺼짐 → 오디오 시작 → 아날로그 레일과 출력 커플링 C 안정 대기(약 10s, 회로 설계 5절) → 버퍼드 모드면 마스터 램프 0, K1 켬, 동작 시간 대기, 드라이 유니티로 램프 인 |
| 이펙트 켬 (트루 모드) | 마스터 램프 0 → K1 켬 → 동작 시간 대기 → 램프 인 |
| 이펙트 끔 (트루 모드) | 마스터 램프 아웃 → K1 끔 |
| 이펙트 켬·끔 (버퍼드 모드) | K1은 켠 채. 웻과 드라이 사이를 램프로 전환 |
| 모드 변경 | 부팅 시 풋스위치 누름 → 모드 전환, QSPI 플래시 저장(libDaisy `PersistentStorage`) |
| 전원 감시 | 오디오 블록마다 9V 감시값 이동 평균. 부팅 시 어댑터 전압 -1V 아래면 즉시 K1 끔, 재부팅 전까지 재투입 안 함(3.5절) |
| MCU 멈춤 | STM32 IWDG 리셋(libDaisy에 래퍼가 없어 HAL로 직접 설정). 구동 트랜지스터 베이스 풀다운으로 K1 해제 |

미터는 `getCurrentGain_dB` 값을 8칸으로 나눈다.

### 6.5 코드 단위

| 단위 | 역할 | 검증 |
|---|---|---|
| `Compressor` | F32 블록. 검출기, 사이드체인 HPF, 게인 계산 | PC 네이티브 테스트, HexeFX 블록 대조 |
| `ParamMapper` | 노브 → 파라미터, 유니티 트림 | 네이티브 테스트 |
| `BypassController` | K1·램프 상태 머신, 모드, 전원 감시 | 네이티브 테스트 |
| `Controls` | ADC 평활, 풋스위치 디바운스 | 네이티브 테스트 |
| `Meter` | 감쇠량 → LED, 클립 점멸 | 네이티브 테스트 |
| 오디오 콜백 결선 | 위 단위 연결, libDaisy | 실기기 |

빌드는 libDaisy를 서브모듈로 두고 Makefile과 arm-none-eabi-gcc로 한다. 네이티브 테스트는 CMake로 따로
돌린다. `effector_core`는 플랫폼 헤더가 없어 그대로 쓴다.

## 7. 테스트와 판정 기준

### 7.1 측정 환경

- 스칼렛 솔로 3세대와 PC, Fluke 101 멀티미터. 오실로스코프·온도계 없음
- 스칼렛 라인아웃 최대 +15.5dBu, 라인 입력 최대 +22dBu, INST 입력 최대 +12.5dBu(문서 기준). 라인아웃은
  전자식 밸런스라 TS로 연결하면 절반인 약 +9.5dBu까지 나올 것으로 보고 M2에서 확인한다
- 입력 +17dBu 헤드룸은 직접 쏘지 않고 T5의 패드 비율과 T6(같은 op-amp·레일인 출력단)으로 판정한다
- 온도 측정 수단이 없다. T2는 동작 이상 유무만 본다

### 7.2 대조군

| 대조군 | 테스트 |
|---|---|
| 스칼렛 루프백 케이블 | T3, T4, T7, T8 |
| 트루 바이패스 경로 | T4 |
| HexeFX 컴프레서 블록 | T9 |
| 한 번 녹음한 재즈 베이스 DI 트랙 | T10, T16 |

### 7.3 항목

T4, T5, T6, T7, T9, T11의 판정 기준은 근거 문서 없이 정한 값이라 [계획서](bass-effector.md#단계)의 1단계 결과를 보고 조정한다.

| # | 항목 | 방법 | 판정 기준 |
|---|---|---|---|
| M1 | 보유 베이스 피크 | 스칼렛 INST 입력, 게인 최소에서 핑거·슬랩을 녹음해 피크 dBFS 기록. 0dBFS = +12.5dBu 사인 기준(피크 약 4.62V)으로 환산. 클립하면 라인 모드(+22dBu)로 다시 잰다. 베이스 볼륨·톤과 줄 상태를 함께 기록 | 기록. Input 노브의 게인 범위를 정한다 |
| M2 | 스칼렛 교정 | 100Hz 사인을 TS 출력으로 내보내 Fluke 101 AC 전압으로 재고, 루프백으로 입력 스케일 확정 | dBFS와 dBu 환산 상수 기록. Fluke 101 AC 측정 대역 40~500Hz(문서 기준) 안이다 |
| T0 | 첫 전원 전 점검 | 멀티미터로 DC 극성, 레일·V9·3.3V 단락 여부 | 극성 일치, 단락 없음 |
| T1 | 아날로그 레일 | 전 부하 상태 전압과 어댑터 실제 출력 | 16.1V 이상 |
| T2 | 발열 | 케이스 닫고 1시간 연속 동작 | 출력 끊김·리셋 없음. 온도는 측정 수단이 없어 미판정 |
| T3 | 주파수 응답 | 스윕. 트루, 버퍼드, 이펙트(레시오 1:1) | 루프백 대비 20Hz~20kHz ±1dB |
| T4 | 유니티 | 1kHz -10dBu. 루프백으로 스칼렛 자체 레벨을 먼저 잰 뒤 트루 바이패스 대비 버퍼드와 이펙트(압축 없음, Output 12시, Blend 전 구간) | 유니티 트림 상수를 정한 뒤 ±0.5dB |
| T5 | 입력 풀스케일 | ADC 0dBFS에 닿는 입력 레벨. 스칼렛 라인아웃 상한(약 +9.5dBu) 때문에 패드 뒤 종단 노드에 직접 넣어 모듈 단독 풀스케일을 재고, 패드 비율은 -10dBu 입력의 앞뒤 레벨 비로 잰다 | 모듈 단독 +2.2dBu ±1dB, 패드 -15 ±1.5dB. 곱한 값을 펌웨어 상수로 |
| T6 | 출력 헤드룸 | T4 유니티 트림을 적용한 뒤 DSP 내부 사인 레벨을 올려 가며 스칼렛 라인 입력으로 THD+N 1%에 닿는 출력을 찾는다 | +16.5dBu 이상 |
| T7 | 바닥 노이즈 | 스칼렛 게인을 올려 자체 바닥을 충분히 낮춘 뒤 루프백으로 그 바닥을 재고 전력으로 뺀다. 입력 단락과 베이스 연결·줄 뮤트 두 조건, Input 최소와 최대. 125~8000Hz와 20Hz~20kHz 무가중 둘 다 | 125~8000Hz에서 풀스케일 대비 다이내믹 레인지 100dB 이상(4.4절). Input 위치에 따라 달라지지 않음. 미달이면 입력단 배선과 접지를 먼저 본다 |
| T8 | 왕복 지연 | 루프백 대비 이펙트 경로 시간차 | ms 기록. 판정은 T16 |
| T9 | 컴프레서 정합 | 계단 레벨 사인, 같은 파라미터로 자체 블록과 HexeFX 블록 | 정적 게인 곡선 차 0.1dB 이하, 어택·릴리즈 시정수 ±10% |
| T10 | 사이드체인 HPF | DI 트랙을 HPF 끔/켬으로 재생, B·E현 저음의 감쇠량과 청음 | 청음 A/B. 기본 차단 주파수를 여기서 정한다 |
| T11 | 릴레이 전환음 | 무음과 지속음에서 K1 전환 녹음. 바이패스를 10초 이상 유지한 뒤 켜는 경우와, 켜자마자 끄고 다시 켜는 경우 | 무음: 출력 과도 피크 -60dBu 이하. 지속음: 케이블을 뽑았다 꽂는 것 대비 추가 팝 없음, 청음 |
| T12 | 전원 투입·차단 | 신호를 넣으며 DC 잭 연결·분리. 차단은 잭을 꽂은 채 어댑터를 콘센트에서 뽑는 경우도 한다 | 신호 끊김 없음, 과도는 T11 무음 기준. 차단 시 감시 경로와 리셋 경로(감시를 끈 디버그 빌드) 각각에서 K1이 레일보다 먼저 풀린다. 과전압 차단은 18V 전원이 없어 미판정 |
| T14 | 제어 기능 | 탭 온/오프, 부팅 시 모드 변경과 재부팅 후 유지, 디버그 빌드 강제 정지로 워치독 리셋, 9V 연결 상태에서 시리얼 명령으로 DFU 진입과 펌웨어 업로드 | 모두 동작. 리셋 중 트루 바이패스 |
| T15 | 입력 클립 표시 | T5에서 0dBFS 도달 시 | 미터 점멸 |
