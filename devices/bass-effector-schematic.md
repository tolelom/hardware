# 베이스 컴프레서 페달 회로 설계

설계서: [bass-effector-design.md](bass-effector-design.md). 계획서: [bass-effector.md](bass-effector.md)
회로도 파일: [effector/hardware/bass-compressor.kicad_sch](../effector/hardware/bass-compressor.kicad_sch)
넷리스트(자동 생성): [effector/hardware/netlist.md](../effector/hardware/netlist.md)
최종 갱신: 2026-09-14

설계서 4.1절 블록도의 각 블록을 부품 값과 결선으로 푼다. 값의 근거를 블록마다 한 줄씩 적는다.
지정자와 결선의 기준은 `effector/hardware/gen_schematic.py`의 PARTS 표이고, 이 문서는 그 값이 왜
그런지 설명한다. 둘이 어긋나면 생성기를 고치고 이 문서를 맞춘다.

전제: 만능기판 스루홀. OPA2992는 SOIC 변환 기판, LT1054는 DIP 소켓. 레일 통상값은 16.9V, Vbias는
그 절반인 8.45V로 계산했다. 값이 2단계 측정(T1, T4, T5)으로 바뀌면 여기와 생성기를 같이 고친다.

## 1. 전원 입력과 보호 (블록 A)

```
DC 잭 슬리브(+9V) ─ Q1 D    S ─┬─ S    D Q2 ─ V9 ─ C7 1000µF ─ GND
                    G ─┬─ G ──┘  (VS)
                       │        Q3 2N3906: E=VS, C=VG, B ─ R15 4.7k ─ D3 12V 제너 ─ GND
                       R13 100k          R14 10k: VS-B
                       GND
DC 잭 센터 ─ GND
```

| 부품 | 값 | 근거 |
|---|---|---|
| Q1, Q2 | IRF9540N | 백투백. Q1 드레인이 잭, Q2 드레인이 부하. 소스끼리 잇는다. Vgs 정격 ±20V라 18V 입력도 안에 든다 |
| R13 | 100k | 공통 게이트 풀다운. 게이트 누설이 nA라 값이 커도 된다. Vgs = -9V로 두 채널 모두 완전 도통 |
| Q3 | 2N3906 | 과전압이면 게이트를 소스로 끌어올린다. 게이트는 GND 쪽으로 당겨져 있어 위로 올리는 스위치는 PNP여야 한다. NPN은 에미터 팔로워로 Vz + 0.7V만큼 낮은 곳까지만 올릴 수 있어 채널이 안 꺼진다 |
| R14 | 10k | Q3 에미터-베이스. 제너가 안 흐를 때 베이스를 소스에 붙여 Q3를 끈다 |
| R15 | 4.7k | Q3 베이스와 제너 사이 전류 제한. 없으면 도통 시 에미터-베이스 접합과 제너가 맞물려 전류가 제한되지 않는다. 18V 입력에서 (18 - 0.7 - 12) / 4.7k = 1.1mA 베이스 전류, R13 전류 0.18mA를 포화로 끈다 |
| D3 | 1N4742A 12V | 임계 = Vz + Veb = 약 12.7V. 낮은 전류에서 제너가 12V보다 조금 아래에서 꺾여 실제 임계는 12.2V 근처. 정전압 9V 어댑터 무부하 9.6V는 안 걸리고 12V 어댑터는 걸릴 수도 안 걸릴 수도 있다(설계서 3.5절) |
| C7 | 1000µF 25V | 벌크. 230mA 부하에서 9V → 7V까지 8.7ms(설계서 3.5절) |

동작 확인(설계서 3.5절 그대로): 정방향에서 Q1 바디 다이오드가 먼저 도통하고 게이트가 GND라 두 채널이
열린다. 역방향에서 Q1 바디 다이오드가 막고 Vgs ≥ 0이라 열리지 않는다. 과전압에서 Q3가 공통 게이트를
VS로 올려 두 채널을 끊고, Q2 바디 다이오드가 부하 쪽으로 막혀 있어 전압이 넘어가지 않는다. VS는 Q1
바디 다이오드로 입력 - 0.7V에 머물러 제너 감지가 유지된다.

과전압 시험은 18V 전원이 없어 미판정(설계서 T12). 12V 어댑터가 있으면 임계 근처 동작만 볼 수 있다.

## 2. LT1054 더블러와 아날로그 레일 (블록 B)

LT1054 데이터시트 그림 20(양전압 더블러)을 그대로 쓴다.

```
V9 ─ C16 10µF ─ GND        V9 ─ D1 1N5819 ─ PUMPX ─ D2 1N5819 ─ VRAIL_RAW ─ R16 10Ω ─ VRAIL
U2 LT1054: 8 V+ = V9, 3 GND, 5 VOUT = GND, 2 CAP+ ─ C8 10µF ─ PUMPX
           1 FB/SD, 4 CAP-, 6 VREF, 7 OSC 개방
VRAIL_RAW ─ C9 100µF ─ GND    VRAIL ─ C10 100µF, C17 100nF ─ GND
VRAIL ─ R11 10k ─ VBIAS ─ R12 10k ─ GND    VBIAS ─ C6 100µF ─ GND
```

| 부품 | 값 | 근거 |
|---|---|---|
| U2 | LT1054CP | 그림 20 결선. VOUT 핀을 GND에 묶고 CAP-는 개방. CAP+가 0~9V로 흔들리며 C8을 밀어 올린다 |
| C8 | 10µF 50V | 펌프. 그림 20의 값. 25kHz에서 등가 4Ω, 6mA에서 24mV 손실. + 쪽이 PUMPX(항상 CAP+보다 높다) |
| C16 | 10µF 50V | LT1054 입력. 그림 20의 2µF 이상. 핀 8 가까이 |
| D1, D2 | 1N5819 | 쇼트키 0.3V. 그림 20의 1N4001(0.7V)보다 레일이 0.8V 높다 |
| C9 | 100µF 35V | 더블러 출력. 리플 = 6mA / (25kHz × 100µF) = 2.4mVpp. 12V 어댑터에서 레일 약 23V라 25V 대신 35V |
| R16, C10 | 10Ω, 100µF 35V | 레일 필터. 차단 159Hz, 25kHz에서 -44dB라 리플 15µV. 6mA에서 60mV 강하 |
| C17 | 100nF | U1 전원 핀 가까이 |
| R11, R12 | 10k, 10k | Vbias = 레일 / 2 = 8.45V. 0.85mA. 레일이 흔들리면 같이 흔들리는 것이 의도(양쪽 헤드룸 대칭) |
| C6 | 100µF 35V | Vbias 임피던스. 20Hz에서 80Ω. R6(100k)와 R3(1.8M)만 매달리므로 충분. 기동 시정수 0.5s |

레일 계산(설계서 4.2절): 2 × 9.0 - 0.35(LT1054) - 0.6(쇼트키 2개) - 0.06(MOSFET 2개) - 0.06(R16) ≈ 16.9V.
레일 전류는 op-amp 4.8mA, Vbias 0.85mA, 피드백망 0.1mA로 약 6mA. T1에서 잰다.

## 3. 5V 레귤레이터와 전원 감시 (블록 C)

| 부품 | 값 | 근거 |
|---|---|---|
| U3 | 7805 TO-220 | 입력 V9, 출력 Teensy VIN. 탭을 절연 패드로 케이스에 고정(설계서 5.4절) |
| C11 | 100nF | 입력. C7이 같은 노드에 있어 소용량만 |
| C12, C13 | 100nF, 10µF 50V | 출력 |
| R19, R20 | 47k, 10k | 감시 분압 0.175. 9V → 1.58V, 12.7V → 2.23V, 18V → 3.16V로 3.3V 아래(설계서 3.5절 "3.3/16 이하") |
| C14 | 100nF | 분압 노드. 시정수 (47k ∥ 10k) × 100nF = 0.8ms. 블록 주기 0.73ms와 같은 급 |
| R21 | 1k | ADC 핀 직렬. 핀 보호. ADC 소스 임피던스는 C14가 받쳐 준다 |

12비트 ADC에서 1LSB = 0.8mV = 입력 4.6mV. 설계서의 "-1V 임계"는 217LSB라 잡음 여유가 넉넉하다.

## 4. 입력 네트워크와 버퍼, 패드 (블록 D)

```
IN 잭 팁 ─ K1 11(COM1)   K1 14(NO1) = IN_A ─ R2 10k ─ C1 100nF ─ IN_C ─ U1A(+)   U1A 출력 = BUF_OUT ─ U1A(-)
IN_A ─ R1 2.2M ─ GND     IN_C ─ R3 1.8M ─ VBIAS
BUF_OUT ─ C2 1µF ─ R4 47k ─ SHIELD_LINEIN_L ─ R5 15k ─ GND
```

| 부품 | 값 | 근거 |
|---|---|---|
| R1 | 2.2M | R_pd. NO 접점의 회로 쪽. 트루 바이패스 중에도 C1의 접점 쪽 극판을 0V로 잡는다(설계서 4.1절) |
| R2 | 10k | 클램프 전류 제한. 18V 베이스 ±9V 피크가 레일을 0.5V 넘을 때 55µA. OPA2992 입력 전류 한계 ±10mA의 1/180. 입력 용량 10pF와 1.6MHz라 대역에 영향 없다 |
| C1 | 100nF 필름 | R3와 차단 0.9Hz. 설계서 "10Hz 이하". 기동 시 R1 + R3 = 4M으로 충전, 시정수 0.4s |
| R3 | 1.8M | R_bias. 입력 임피던스 = R1 ∥ (R2 + R3) = 2.2M ∥ 1.81M = 0.99M |
| U1A | OPA2992 A | 유니티 버퍼. 출력을 - 입력에 직결 |
| C2 | 1µF 필름 | 패드 커플링. 부하 R4 + (R5 ∥ 29k) = 56.9k와 차단 2.8Hz, 20Hz에서 -0.08dB. 전해를 피하려고 패드를 고임피던스로 잡았다 |
| R4, R5 | 47k, 15k | 패드. 코덱 LINEIN 29kΩ(데이터시트)을 포함해 (15k ∥ 29k) / (47k + 15k ∥ 29k) = 0.174 = -15.2dB. 입력 풀스케일 = 2.83Vpp / 0.174 = 16.3Vpp = +17.4dBu(PGA 0dB). 패드 출력 임피던스 약 8.5k, 잡음 12nV/√Hz로 코덱 바닥보다 30dB 아래 |

패드 비율이 코덱 입력 임피던스(통상값만 있음)에 걸려 있어 ±1dB는 T5에서 잰 값으로 펌웨어 상수를 잡는다.

## 5. 출력단 (블록 E)

```
SHIELD_LINEOUT_L ─ C3 1µF ─ OUT_IN ─ U1B(+)      OUT_IN ─ R6 100k ─ VBIAS
U1B 출력 = U1B_OUT ─ R7 51k ─ FB ─ U1B(-)         FB ─ R8 10k ─ C4 10µF(+) ─ GND
U1B_OUT ─ R9 100Ω ─ C5 10µF(+) ─ OUT_C ─ K1 24(NO2)    OUT_C ─ R10 100k ─ GND
OUT 잭 팁 ─ K1 21(COM2)
```

| 부품 | 값 | 근거 |
|---|---|---|
| C3, R6 | 1µF 필름, 100k | 커플링과 바이어스. 차단 1.6Hz. LINEOUT 출력 임피던스 320Ω, 최소 부하 10k를 만족 |
| R7, R8 | 51k, 10k | 게인 1 + 51/10 = 6.1 = +15.7dB. 설계서 +15.5dB. LINEOUT 통상 2.61Vpp × 6.1 = 15.9Vpp = +17.2dBu |
| C4 | 10µF 50V | R8을 GND로 AC 접지. DC 게인 1이라 출력 DC = Vbias. R8과 차단 1.6Hz. Vbias로 돌려보내지 않아 Vbias에 신호 전류가 안 흐른다. + 쪽이 R8(FB는 Vbias 전위) |
| R9 | 100Ω | 케이블 용량과 op-amp 분리 |
| C5 | 10µF 50V | 출력 커플링. 앰프 입력 10k에서도 1.6Hz. + 쪽이 op-amp(Vbias 전위) |
| R10 | 100k | 방전 R. NO 접점의 회로 쪽. C5 접점 쪽 극판을 0V로 잡는다 |

헤드룸: Vbias 8.45V ± 7.96V 피크 = 0.49~16.41V. 레일 16.9V에서 위아래 0.49V. OPA2992 스윙 0.22~0.3V(2kΩ)
안이지만 여유가 작다. 어댑터가 8.7V 아래면 T4 유니티 트림으로 출력 목표를 낮춘다.

## 6. K1 릴레이와 구동 (블록 F)

| 부품 | 값 | 근거 |
|---|---|---|
| K1 | TQ2-9V | 코일 A1 = V9, A2 = Q4 컬렉터. 코일 꺼짐 = NC. 11·21 COM, 12·22 NC, 14·24 NO. NC끼리 직결이 트루 바이패스 |
| D4 | 1N4148 | 플라이백. 캐소드 V9 |
| Q4 | 2N3904 | 코일 15.5mA. R17로 베이스 1.2mA, hFE 13이면 포화 |
| R17 | 2.2k | (3.3 - 0.7) / 2.2k = 1.2mA |
| R18 | 10k | 베이스 풀다운. MCU 리셋 중 핀이 하이 임피던스여도 K1이 풀린다(설계서 6.4절) |

TQ2 실물 핀 번호는 데이터시트의 단면도로 배치 때 확인한다. 회로도의 11·12·14·21·22·24는 KiCad 범용 심볼
번호다.

## 10. 회로도 파일

`effector/hardware/bass-compressor.kicad_sch`는 KiCad 8 형식이고 9와 10에서 열린다. 부품은 블록별로
줄지어 놓고 핀마다 글로벌 라벨을 붙인 넷리스트형 회로도다. 배선 그림이 아니라 접속 정의라서 KiCad에서
ERC를 돌리고, 필요하면 라벨을 따라 선으로 정리한다. 이 PC에 KiCad가 없어 파일을 열어 보지는 못했다
(2026-09-14). 확인해야 할 것: ERC 경고 0, 심볼 21종이 라이브러리 없이 열리는지.

다시 만들려면 KiCad 심볼 라이브러리 9.0.5의 .kicad_sym 파일 12개(Device, Amplifier_Operational,
Transistor_FET, Transistor_BJT, Regulator_Linear, Regulator_SwitchedCapacitor, Relay, Connector,
Connector_Audio, Connector_Generic, Switch, power)를 한 폴더에 받고 실행한다.

    python effector/hardware/gen_schematic.py --libs <폴더>

값이나 결선을 바꿀 때는 생성기의 PARTS 표를 고치고 다시 만든다. netlist.md는 같이 갱신된다.

## 11. 설계서와 다른 점

설계서를 고치지 않고 여기서만 정한 것과, 설계서를 이 문서에 맞춰 고친 것.

- 과전압 차단 트랜지스터를 NPN에서 PNP(2N3906)로 바꿨다. 설계서 3.5절을 같이 고쳤다
- LED 저항을 1k에서 470Ω으로 내렸다. 설계서 부품표는 페달파츠 2차라 값만 여기서 정한다
- 레일·Vbias 전해 커패시터를 25V에서 35V로 올렸다. 12V 어댑터 대비
- 출력단 게인을 +15.5dB 대신 E24 값으로 +15.7dB로 잡았다. 유니티 트림이 흡수한다
- 출력단 피드백 하단(R8)을 Vbias가 아니라 C4를 거쳐 GND에 둔다. Vbias 노드에 신호 전류가 흐르지 않게
