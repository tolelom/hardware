# 오디오 플레이어 계획

부품 기준 문서: [parts/pocketbeagle2.md](../../parts/pocketbeagle2.md)
최종 갱신: 2026-09-08

## 무엇을 만드나

PocketBeagle 2로 microSD 음원을 재생하는 플레이어를 만든다. 1세대는 거치형이다
(2026-09-08 확정). USB 전원으로 켜 두고 폰의 MPD 클라이언트로 조작한다.
휴대형(배터리, 수 초 부팅, 화면)은 2세대다.

## 상태

미착수. 2026-09-01에 보류했다가 09-08에 1세대를 거치형으로 좁혀 다시 계획했다.
막는 것은 둘이다.

| 막는 것 | 내용 |
|---|---|
| PB2 브링업 | 로드맵 1f(SD에 처음 쓰기)가 미착수다. McASP를 다루려면 로드맵 4단계(커널과 디바이스 트리)에 도달해야 한다 |
| I2S DAC 없음 | PCM5102A 모듈을 산다. 아래 DAC 절 |

## 왜 PocketBeagle 2인가

- McASP0의 전송 클럭과 수신 클럭이 따로 나오고 데이터 라인이 4개라 전이중 구성에 여유가 있다
- 배포 이미지 커널이 `PREEMPT_RT`다. 실시간 패치가 들어가 오디오 지연에 유리하다
- `BQ21040` 리튬 충전기와 `VBAT` 입력이 온보드라 2세대 배터리 구동에 별도 전원 회로가 필요 없다
- 브링업을 이미 이 보드로 하고 있어 밑단 지식이 그대로 이어진다

## 1세대 구성 (거치형)

```
microSD 음원 → MPD (리눅스) → ALSA → McASP0 (I2S 마스터) → PCM5102A → 라인아웃 → 헤드폰 또는 헤드폰 앰프
                 ^
        폰 MPD 클라이언트 ─ WiFi ─ USB1 호스트의 WiFi 동글
```

| 항목 | 결정 |
|---|---|
| 전원 | USB. 배터리 없음 |
| 조작 | 보드에 버튼 없음. MPD를 돌리고 폰의 MPD 클라이언트로 원격 조작 |
| 네트워크 | PB2에 무선이 없어 USB1 호스트에 WiFi 동글. 칩셋은 MediaTek MT7612U 또는 MT7610U(mt76, 커널 4.19부터 내장). 아래 부품 표 |
| DAC | PCM5102A 모듈. 아래 |
| 화면 | 없음 |

USB1 호스트 배선(헤더의 D+·D-·VBUS·DRVVBUS에 소켓)은 LDAC 동글 3단계와 같은 작업이다.
한 번 하면 둘 다 쓴다.

### DAC

1세대는 PCM5102A다. MCLK 없이 BCK에서 내부 PLL로 동작하므로 McASP가 BCLK와 LRCLK만
내면 되고, 커널에 `pcm5102a` 코덱 드라이버가 있어 디바이스 트리에서 simple-audio-card로
McASP와 묶는다(문서 기준). 클럭 구조가 단순해지는 대신, 마스터 클럭을 SoC가 줄지
DAC가 줄지 하는 문제는 1세대에서 다루지 않는다. 그것은 MCLK가 필요한 코덱(PCM5122 등)으로
2세대에서 다룬다.

PCM5102A 라인아웃은 저임피던스 이어폰은 직결되고 고임피던스 헤드폰은 헤드폰 앰프가
필요하다. 앰프는 3단계에서 보유 헤드폰으로 판단한다.

## 배우는 것과 쓰는 것

배우는 것: McASP와 I2S 코덱 연결, 디바이스 트리 오버레이, ALSA, MPD 구성, USB 호스트.
2세대에서 클럭 구조, 최소 루트파일시스템, 부팅 시간 단축, 배터리 전원 관리.

쓰는 것: 책상에서 microSD 음원을 폰으로 조작해 듣는 거치형 플레이어다.

## 단계

| # | 단계 | 판정 기준 |
|---|---|---|
| 0 | PB2 브링업 로드맵 4단계 도달 | 디바이스 트리로 비활성 주변장치 하나를 살린다 |
| 1 | 소리 내기 | PCM5102A를 McASP0에 연결하고 오버레이를 적용해 `aplay`로 헤드폰에서 소리가 난다 |
| 2 | 원격 재생 | USB1에 WiFi 동글을 꽂고 MPD를 올려 폰의 MPD 클라이언트에서 microSD 음원을 고르고 재생·정지가 된다 |
| 3 | 거치형 마감 | 케이스에 넣고 USB 전원만 꽂아 부팅하면 폰에서 조작이 된다. 헤드폰 앰프 필요 여부를 판단한다 |
| 4 | 2세대: 부팅 단축 | 전원 인가부터 재생까지 수 초 이내. 로드맵 7단계와 같은 작업이다 |
| 5 | 2세대: 전원 | 배터리로 동작하고 잔량이 표시된다 |
| 6 | 2세대: UI | SPI LCD와 인코더로 보드 단독 조작이 된다 |

## 그만둘 조건

- PB2 브링업이 1f에서 막히면 여기까지 오지 못한다. 브링업이 선행이고 그쪽이 먼저 판정된다.
- 1단계에서 McASP와 PCM5102A 조합으로 소리를 못 내면 코덱을 바꾸기 전에 오버레이와
  클럭 설정을 먼저 본다. 같은 코덱을 쓴 다른 보드의 디바이스 트리가 대조군이다.
