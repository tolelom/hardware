## M1 보유 베이스 피크

`입력 dBu = 피크 dBFS + K`. K는 INST 12.5, LINE 22(스칼렛 솔로 3세대, 문서 기준).
`V피크 = V0 × 10^(피크 dBFS / 20)`, V0는 INST 4.62V, LINE 13.79V.

### 예비 측정 (2026-09-17, MainStage 미터를 눈으로 읽음)

스칼렛 게인 최소, MainStage 이펙트 전부 끔. 눈으로 읽은 값이라 짧은 트랜지언트를 3~5dB 놓쳤을 수 있다.

| 연주 | 입력 모드 | 피크 dBFS | 환산 dBu | 환산 V피크 |
|---|---|---|---|---|
| 핑거 약하게 | LINE | -45 | -23.0 | 0.08 |
| 핑거 세게 | LINE | -30 | -8.0 | 0.44 |
| 슬랩 약하게 | LINE | -30 | -8.0 | 0.44 |
| 슬랩 세게 | LINE | -15 | +7.0 | 2.45 |
| 핑거 약하게 | INST | -35 | -22.5 | 0.08 |
| 핑거 세게 | INST | -20 | -7.5 | 0.46 |
| 슬랩 약하게 | INST | -30 | -17.5 | 0.15 |
| 슬랩 세게 | INST | -12 | +0.5 | 1.16 |

핑거는 두 모드의 환산값이 0.5dB 안에서 일치한다. 환산 상수가 맞고, LINE 모드의 낮은 입력 임피던스가
패시브 픽업을 누르는 영향도 핑거 대역에서는 0.5dB 안이라는 뜻이다.

슬랩만 6.5~9.5dB 어긋난다. 측정이 아니라 타격 세기 편차로 본다. 설계는 센 쪽을 받아야 하므로 슬랩 피크를
+10dBu로 잡았다(설계서 3.1절). Input 노브 범위는 0~+30dB로 정해졌다.

### 확정 측정 (2026-11-01, Audacity 4.0 Amplify, 맥북 프로)

베이스 볼륨·톤 최대, 스칼렛 INST 게인 최소. 한 조건 3회를 재고 중앙값으로 판정한다.

| 연주 | 베이스 볼륨·톤 | 입력 모드 | 1회 dBFS | 2회 | 3회 | 중앙값 | 환산 dBu | 환산 V피크 |
|---|---|---|---|---|---|---|---|---|
| 핑거 세게 | 최대 | INST | -13.77 | -23.00 | -21.35 | -21.35 | -8.9 | 0.40 |
| 슬랩 | 최대 | INST | -12.00 | -8.37 | -8.07 | -8.37 | +4.1 | 1.76 |
| 슬랩 | 통상 위치 | INST | | | | | | |

- 핑거 1회(-13.77)는 2·3회와 8dB 넘게 떨어진다. 녹음 중 접촉 잡음이나 유난히 센 한 음으로 본다. 중앙값에는 영향이 없다.
- 슬랩 1회는 "나름 세게", 2·3회는 "최대로" 쳤다. 2·3회 차이 0.3dB. 측정한 최대는 +4.4dBu(1.83V 피크)다.
- 판정: 입력 풀스케일 +17.2dBu까지 슬랩 최대 기준 약 13dB가 남는다. 패드 -15dB를 키울 필요가 없다.
  예비 측정의 슬랩 세게(INST +0.5, LINE +7.0dBu) 사이에 들어와, 설계 가정 +10dBu는 여유 쪽으로 확인됐다.
- 슬랩 통상 위치(베이스 볼륨을 평소 위치로)는 재지 않았다.
- 핑거·슬랩 원본 WAV는 남기지 않았다. 값은 Amplify 창에서 읽은 것이다.

줄 상태: 미기록

DI 녹음(2026-11-01, 같은 설정, 81초, 48kHz 32비트 정수, 원본은 M4 `~/Downloads/m1.wav`): 핑거 2.5~30초, 약하게 30~38초,
슬랩 42~68초, 무음 76~81초. 무음 끝 2초(79~81초)의 입력 2 잡음은 20Hz 하이패스 기준 -101.8dBFS(-89.3dBu, 비가중)이고
아직 줄어드는 중이라 실제 바닥은 이보다 낮다. 60Hz 험 성분은 잡음 전력의 1% 미만이다. 같은 무음을 16비트로 내보낸 파일은 ±3 LSB에
갇혀 쓸 수 없었다(내보내기는 24비트 이상).

## M2 스칼렛 교정

| 항목 | 1회 | 2회 | 3회 | 중앙값 |
|---|---|---|---|---|
| Fluke Vrms (100Hz, 진폭 0.5, 노브 최대) | 1.207 | 1.204 | 1.203 | 1.204 |
| 출력 상수 K_out (dBu - RMS dBFS) | 12.88 | 12.86 | 12.85 | 12.86 |
| 루프백 녹음 RMS dBFS (입력 2 LINE, 게인 최소) | -21.408 | -21.410 | -21.422 | -21.410 |
| 입력 상수 K_in (dBu - RMS dBFS) | 25.23 | 25.24 | 25.25 | 25.24 |

2026-11-01, 맥북 프로 Audacity 4.0, 스칼렛 솔로 3세대 큰 출력 노브 최대, Direct Monitor 끔, TS 케이블 하나로 LINE OUTPUT L → 입력 2.
K_in을 풀스케일 사인(RMS -3.01dBFS) 기준으로 바꾸면 LINE 입력 상한 +22.2dBu로 문서값 +22dBu와 맞는다.
K_out으로 보면 노브 최대에서 TS 라인아웃 풀스케일 사인은 +9.85dBu다. Seed3 입력 제한 +2.2dBu는 재생 RMS -10.7dBFS(사인 진폭 약 0.41)다.
