## 1. 목표와 판정 기준

Daisy Seed3 기반 베이스 멀티 이펙터 페달의 하드웨어 플랫폼을 만든다. 첫 이펙트는 컴프레서이고, 이후 이펙트는 같은
하드웨어에서 펌웨어로 늘린다.

판정 기준은 상용 제품급 완성도다. 성능, 기능, 크기, 전용 PCB, 마감을 판매 제품 수준으로 맞춘다. 기능을 미리 범위로
빼지 않고, 각 후보는 "연주에서 쓰는가"와 레퍼런스 대조로 넣고 뺀다.

| 항목 | 목표 | 근거 |
|---|---|---|
| 바닥 노이즈 | A 가중 다이내믹 레인지 110dB 이상 (T7 통과선은 105) | TLC -95dBu, Keeley -95dBV급 (설계서 2절) |
| 헤드룸 | 입력·출력 +17dBu | 설계서 3.1절, M1 슬랩 피크 +10dBu |
| 크기 | 폭 약 190mm. HX Stomp(178×126×66), Ampero II Stomp(185×145×58)와 같은 급 | 컬러 화면 + 노브 5~6개 제품이 175~185mm 구간에 몰려 있다 |
| 기판 | 전용 PCB. 공장 SMT 조립, 스루홀(잭·풋스위치·인코더·소켓)은 손납땜 | 상용급 기준 |
| 완료 | 케이스를 닫고 컴프레서로 T16(30분 연습 2회)을 통과 | 설계서 7.3절 |

서브프로젝트는 넷으로 나눈다. 이 문서는 1번이다.

| # | 서브프로젝트 | 내용 |
|---|---|---|
| 1 | 하드웨어 플랫폼 | 케이스, 패널 UI, 기판 2장, 전원, 아날로그 입출력, 핀 배정 |
| 2 | 펌웨어 플랫폼 | 화면 UI, 인코더·풋스위치 입력, 프리셋 저장, 이펙트 체인, MIDI, 바이패스·전원 감시 |
| 3 | 컴프레서 이펙트 | `effector_core` 계승. Attack·Release 분리, 가변 사이드체인 HPF, Ratio, Blend, 톤, 입력 레벨 미터 |
| 4 | 이후 이펙트 | 드라이브, EQ, 옥타버, 시간계 등 |

Seed3 모듈의 실제 노이즈·풀스케일·지연(1단계 계획 Task 8·9의 M2, T5, T7, T8)은 어떤 기판에서든 먼저 필요하므로
이 설계와 병행해 잰다.

## 2. 케이스

Hammond 1590R1. 외형 192 × 111.25 × 60.76mm, 벽 2.03mm(판매점 표기, DigiKey). 내부에 1.5mm 기판용 카드 가이드가
주조돼 있다. 내부 높이와 구배는 실측한다.

| 후보 | 외형 | 탈락 사유 |
|---|---|---|
| Hammond 1590E | 187.5 × 119.5 × 82mm | 높이가 커 바닥에서 솟는다 |
| 1590DD (Hammond, Tayda) | 188 × 120 × 37mm | 높이가 낮아 조작부 기판과 Seed3 스택을 겹쳐 쌓지 못한다 |
| 1590XX | 145 × 121 × 39mm | 폭과 높이 모두 부족 |
| 맞춤 케이스(Protocase 등) | 자유 | 시제품 단계에서는 패널 수정마다 견적이 다시 든다. 최종 디자인이 굳은 뒤 다시 본다 |

화면 창이 사각형이라 타공은 CNC 밀링으로 한다. Tayda·페달파츠 타공 서비스는 자사 케이스만 받는다(확인 필요).
가공 도면은 `enclosure.py`가 DXF로 낸다.

## 3. 패널

왼손형이다(최종 시안 F4). 노브를 돌리는 손이 화면을 가리지 않게 노브를 왼쪽, 화면을 오른쪽에 둔다. 오른손형은 조작부 기판의
화면·인코더 자리를 좌우 대칭으로 두면 패널(CNC 도면)만 바꾸고 펌웨어에서 노브 번호를 뒤집어 만들 수 있다.

```
 ┌──── 뒷면(위에서 볼 때 왼쪽부터): OUT · IN · EXP · MIDI OUT · MIDI IN · USB-C · DC 9V ────┐
 │ (NAV)  (E1)  (E2)  (E3)     ┌──────────────────┐                                       │
 │                             │  3.5" IPS         │                                       │
 │        (E4)  (E5)  (E6)     │  320×480 (가로)   │                                       │
 │                             └──────────────────┘                                       │
 │      ●                    ●                    ●                                         │
 │    [FS1]                [FS2]                [FS3]                                       │
 └──────────────────────────────────────────────────────────────────────────────────────────┘
```

| 요소 | 사양 | 역할 |
|---|---|---|
| 화면 | 3.5" IPS TFT 320×480(가로 480×320), 4선 SPI, HX8357D. 직렬 인터페이스(DBI Type C)로 RGB 5-6-5 16비트 색을 받는다(HX8357-D 데이터시트 Figure 4.21). 채택 Orient AFK320480A0-3.5INTH-ANO(데이터시트·도면 V01): 유리 82.94 × 54.66mm, 기판 82.94 × 65.66mm(2.54mm 8핀 헤더 두 줄), 두께 최대 7.74mm, 표시 영역 73.44 × 48.96mm, 휘도 최소 800·통상 1000cd/m², 백라이트 구동기 모듈 내장, $22.90. 대안 EA TFT035-34AINN: 82.9 × 54.7 × 2.2mm, 보이는 영역 74.4 × 50mm, 1000cd/m²(검색 요약, 원문 확인 필요), 0.3mm FFC라 변환 기판 필요, €39.29 | 이펙트·파라미터 이름과 값, 프리셋 목록, 메뉴, 감쇠·입력 레벨 미터, 튜너 |

## 4. 기판 구성

두 장으로 나눈다.

| 기판 | 위치 | 부품 |
|---|---|---|
| 조작부 기판 | 패널 바로 아래 | 인코더 7개, 화면 커넥터, 풋스위치 3개, LED 3개, MCP23017 ×2, 3.3V 보조 전원 |
| 메인 기판 | 바닥 쪽 | Daisy Seed3(저배기 소켓), 블록 A~F 계승 회로, MIDI IN·OUT, EXP 입력, 뒷면 단자 7개(기판 장착, 뒷면 벽을 따라 한 줄), 스테레오 출력 자리 |

- 층을 나누는 이유: 풋스위치(패널 아래 약 30mm)와 Seed3 스택(약 20mm)이 같은 자리에 겹치지 않게 하고, 아날로그
  입력단을 화면·SPI·인코더 배선에서 떼어 놓는다.
- 두 기판은 보드 투 보드 커넥터 또는 리본 케이블로 잇는다. 신호는 SPI(화면), I2C(MCP23017), 인터럽트, 풋스위치·LED,
  전원과 접지다.
- Seed3는 풋스위치 줄 아래가 아니라 화면·인코더 아래에 둔다. 소켓 높이가 모자라면 직접 납땜으로 바꾼다.
- 뒷면 단자는 메인 기판 뒷변에 기판 장착형으로 달아 높이를 맞춘다. 1/4" 잭 몸체가 뒷벽에서 안쪽으로 약 30mm 들어오므로(대표값)
  그 띠에는 Seed3 소켓과 키 큰 부품을 두지 않는다.
- 조립: 저항·커패시터·IC는 공장 SMT. 잭, 풋스위치, 인코더, Seed3 소켓, LT1054(DIP일 때)는 손납땜.
- 메인 기판 외곽은 1590R1 안쪽 카드 가이드를 피해 정한다.

## 5. 전기 설계

### 5.1 계승하는 회로

설계서·회로 설계의 블록 A(전원 보호), B(LT1054 레일), C(Seed3 VIN 필터·전원 감시), D(입력 버퍼·패드), E(출력단),
F(K1 바이패스)를 메인 기판으로 옮긴다. 값은 BLOCKS 그대로 시작하고, 바꿀 때는 회로 설계 문서와 커밋에 이유와
시뮬레이션·측정 근거를 남긴다. 블록 G(포트 5개, LED 9개)는 인코더와 화면으로 대체해 없앤다.

### 5.2 새 회로

| 블록 | 구성 | 근거 |
|---|---|---|
| 조작부 3.3V | V9에서 별도 3.3V 레귤레이터. 화면 백라이트, MCP23017, LED용 | Seed3 모듈 레귤레이터의 여유 전류가 공개되지 않았다. 9V에서 3.3V로 선형 강하하면 100mA에서 약 0.6W라 강압형을 검토하되, 스위칭 잡음은 조작부 기판 안에서 필터로 막고 아날로그 기판과 접지를 한 점에서 잇는다 |
| 인코더 확장 | MCP23017 ×2 (I2C, 각 16비트). 인코더 7개 × 3선 = 21선 | Seed3 GPIO 절약. 인터럽트 핀으로 변화를 알린다 |
| 화면 | SPI + DC + RST + 백라이트 PWM | DMA SPI로 오디오 콜백과 분리, 프레임 버퍼는 SDRAM. 전체 프레임은 307.2KB(480×320×16비트)로 50MHz SPI에서 약 20fps라 바뀐 영역만 보낸다 |
| MIDI IN | TRS 타입 A, H11L1 광커플러(3~15V 동작, Daisy Pod와 같은 계열) → UART RX. 6N137은 5V 전용이라 뺐다 | MIDI 규격의 절연 입력 |
| EXP | TRS, 링에 3.3V 기준, 팁과 링을 각각 ADC로. 익스프레션 페달과 2버튼 외장 풋스위치(팁–슬리브 1번, 링–슬리브 2번, Boss FS-6 방식)를 둘 다 받고 링 전압으로 구분한다. 꽂힘 감지 | 익스프레션 페달, 발판이 모자랄 때 외장 풋스위치(자작 악보 페달 겸용, [README.md](../../page-pedal/README.md)) |
| 스테레오 출력 | 출력단 한 채널 풋프린트, Seed3 Audio Out 2 배선 | 부품은 얹지 않는다 |
| microSD | 4비트 SDMMC (Seed3 D1~D6) | 캐비닛 IR, 프리셋 백업, 샘플. Seed3 Pedal Dev Kit과 같은 핀 |
| MIDI OUT | TRS 타입 A, UART TX(D13) | 다른 장비의 프리셋·템포 제어. THRU는 넣지 않는다 |

### 5.3 핀 배정

기준은 `devices/bass-effector/hardware/pinmap.py`의 `PLATFORM`이다. `check()`가 중복, ADC 아닌 핀의 ADC 배정, 핀에 없는 주변장치 기능,
예약 핀을 막는다.

| 기능 | Seed3 핀 |
|---|---|
| K1 구동 | D0 (계승) |
| microSD SDMMC1 D3, D2, D1, D0, CMD, CK | D1, D2, D3, D4, D5, D6 |
| 화면 SPI1 NSS, SCK, MOSI | D7, D8, D10 |
| I2C1 SCL, SDA (MCP23017) | D11, D12 |
| MIDI OUT USART1 TX / MIDI IN RX | D13 / D14 |
| EXP 팁 / 링 (ADC) | D15 (A0) / D28 (A11) |
| 화면 백라이트 PWM (TIM2_CH4) | D16 |
| 화면 DC, RST | D17, D18 |
| MCP23017 인터럽트 A, B | D19, D21 |
| 전원 감시 (ADC) | D20 (A5, 계승) |
| 풋스위치 FS1~3 | D22, D23, D24 |
| 풋스위치 LED 1~3 | D25, D26, D27 |

합계 27핀. Seed3 GPIO는 D0~D30 31개이고 그중 A0~A11 12개가 ADC를 겸한다(Seed3 데이터시트 v2.1.0 표 2). 비운 핀은
D9(화면 모듈이 쓰기 전용 4선 SPI라 MISO 불필요), D29·D30(외부 USB, USB 호스트 자리)이다.

Seed3 Pedal Dev Kit(Electro-Smith, Rev4 2026-09-15 공개, 회로도·BOM 공개)은 9V 단일 전원에 입력단 감쇠 -4.6dB, 출력 ×2.2라
잭 기준 최대 입출력이 약 +9dBu다(부품값으로 계산). 보유 베이스 슬랩 피크(+10dBu)를 받지 못하므로 입출력단은 계승 회로를
쓴다. 같은 보드에서 입력 RF 필터와 전원 입력 페라이트 비드를 가져왔다(회로 설계 1절·4절의 FB1, C24).

### 5.4 전류 예산

| 부하 | 3.3V 쪽 | 9V 기준 전류 | 출처 |
|---|---|---|---|
| 기존 페달 부하 (Seed3, K1, LT1054, 아날로그단) | | 약 230mA | 설계서 5.4절 계산. 1호 LED 9개분이 빠져 실제는 조금 적다 |
| 화면 백라이트 | LED 6직렬 2병렬 VF 19.2V × 40mA = 0.77W, 모듈 안 승압 효율 85% 가정 시 약 270mA | | Orient AFK320480A0 데이터시트 V01 5절. 효율은 가정 |
| microSD | 쓰기 중 약 100mA, 고속 모드 최대 약 200mA | | SD 규격 일반값(가정) |
| MCP23017 ×2, 인코더·풋스위치 풀업, 화면 로직 | 약 15mA | | 풀업 17개 × 0.33mA 최악, 나머지 수 mA |
| 보조 3.3V 합계 | 약 390~490mA | 약 160~200mA | TPS562208 강압 효율 90% 가정. MIDI OUT 링 단락(TS 플러그) 시 100mA가 더해진다 |
| 합계 | | 약 390~430mA | |

합계가 9V 500mA 어댑터의 78~86%로 80% 기준에 걸린다. 요구 어댑터를 9V 1A로 올린다.

전원 차단 유지 시간은 1호 근거(230mA에서 9V → 8V 4.3ms, → 4V 22ms)가 플랫폼에서 성립하지 않는다. 부하가 약 430mA이고
강압기는 입력이 떨어질수록 전류를 더 끌어 정전력(약 3.87W)으로 본다. K1은 V9가 5.5V(아날로그 레일 약 10V, Vbias에
가까워지는 점)로 떨어지기 전에 놓여야 하고, 필요한 시간은 감지 1ms + 이동 평균 2ms + 릴리즈 2ms + 여유 3ms = 8ms다.

| 벌크 | 9V → 8V | 9V → 5.5V | 9V → 4V |
|---|---|---|---|
| 1000µF (C7만) | 2.2ms | 6.6ms | 8.4ms |
| 2000µF (C7 + C37) | 4.4ms | 13.1ms | 16.8ms |

그래서 C37 1000µF를 C7과 병렬로 더했다(회로 설계 문서 1절). 펌웨어는 감지 즉시 백라이트를 먼저 끈다(9V 기준 약 0.11A 감소).
값은 계산이고 T12 실측이 판정한다.

## 6. 기구 높이

외형 60.76mm에서 바닥 두께와 패널 두께를 뺀 내부 높이는 실측 전이다(55mm 안팎 추정). 확인할 겹침은 둘이다.

- 풋스위치 줄: 풋스위치 패널 아래 약 30mm. 이 아래에는 메인 기판의 낮은 부품만 둔다.
- 화면·인코더 영역: 조작부 기판(인코더 몸체 약 10~15mm, 화면 모듈 약 5mm) 아래에 메인 기판과 Seed3 스택(약 20mm).

`enclosure.py --final`은 내부 높이와 부품 높이가 실측될 때까지 최종 도면을 내지 않는다.

## 7. 검증

| 대상 | 방법 |
|---|---|
| 패널 배치 | `enclosure.py`에 사각형 부품(화면 창, 화면 모듈)과 1590R1 치수를 더하고 간섭·가장자리·높이 검사 |
| CNC 도면 | `enclosure.py`가 면별 DXF와 좌표 표를 낸다 |
| 회로 | `platform_blocks.py`가 플랫폼 회로도·넷리스트·SPICE(`spice/generated/platform/`)를 만들고 `check()`가 넷 단독 핀과 지정자 중복을 막는다. 새 블록 테스트벤치(EXP 분압, 보조 3.3V 입력 필터)는 아직 없다 |
| 핀 배정 | `pinmap.check()`, 그리고 테스트가 J4 소켓 넷이 `pinmap.PLATFORM`과 같고 모든 배정 핀이 부품에 닿는지 본다 |
| 실측 | 1단계 M2·T5·T7·T8, 이후 기판 Rev A에서 설계서 7.3절 시험 항목 전체 |

PCB 레이아웃 도구 경로: M4 KiCad 10.0.7은 GUI에서 첫 실행을 승인한 뒤 `kicad-cli`가 동작한다. ERC 결과는 회로 설계 문서 9절
(2026-10-29, 오류·경고 0건). 회로도 생성은 KiCad 9.0.7 심볼 파일만으로 된다. 레이아웃은 아직 시작하지 않았다.
