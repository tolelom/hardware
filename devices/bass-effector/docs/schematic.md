# 베이스 컴프레서 페달 회로 설계

설계서: [design.md](design.md). 계획서: [plan.md](plan.md)
회로도 파일: [devices/bass-effector/hardware/bass-compressor.kicad_sch](../hardware/bass-compressor.kicad_sch)
넷리스트(자동 생성): [devices/bass-effector/hardware/netlist.md](../hardware/netlist.md)
최종 갱신: 2026-09-16

설계서 4.1절 블록도의 각 블록을 부품 값과 결선으로 푼다. 값의 근거를 블록마다 한 줄씩 적는다.
지정자와 결선의 기준은 `devices/bass-effector/hardware/gen_schematic.py`의 PARTS 표이고, 이 문서는 그 값이 왜
그런지 설명한다. 둘이 어긋나면 생성기를 고치고 이 문서를 맞춘다.

전제: 만능기판 스루홀. OPA2992는 SOIC 변환 기판, LT1054는 DIP 소켓, Daisy Seed3는 2.54mm 20핀 소켓 2줄.
레일 통상값은 16.9V, Vbias는 그 절반인 8.45V로 계산했다. 값이 2단계 측정(T1, T4, T5)으로 바뀌면 여기와 생성기를 같이 고친다.

## 1. 전원 입력과 보호 (블록 A)

```
DC 잭 슬리브(+9V) ─ Q1 D    S ─┬─ S    D Q2 ─ V9 ─ C7 1000µF ─ GND
                    G ─┬─ G ──┘  (VS)
                       │        Q3 2N3906: E=VS, C=VG, B ─ R15 4.7k ─ D3 12V 제너 ─ GND
                       R13 100k          R14 10k: VS-B
                       GND               D14 15V 제너: 캐소드 VS, 애노드 VG
DC 잭 센터 ─ GND
```

| 부품 | 값 | 근거 |
|---|---|---|
| FB1 | 페라이트 비드 600Ω@100MHz | DC 잭과 Q1 사이. 어댑터 선으로 들어오는 고주파와 페달 안 스위칭 잡음(LT1054, 화면 백라이트)이 선을 타고 나가는 것을 막는다. Seed3 Pedal Dev Kit 전원 입력과 같은 구성(Rev3 회로도). 품번은 정격 전류 1A 이상, DC 저항 0.1Ω 이하에서 고른다 |
| Q1, Q2 | IRF9540N | 백투백. Q1 드레인이 잭, Q2 드레인이 부하. 소스끼리 잇는다. Vgs 정격 ±20V라 18V 입력도 안에 든다 |
| R13 | 100k | 공통 게이트 풀다운. 게이트 누설이 nA라 값이 커도 된다. Vgs = -9V로 두 채널 모두 완전 도통 |
| Q3 | 2N3906 | 과전압이면 게이트를 소스로 끌어올린다. 게이트는 GND 쪽으로 당겨져 있어 위로 올리는 스위치는 PNP여야 한다. NPN은 에미터 팔로워로 Vz + 0.7V만큼 낮은 곳까지만 올릴 수 있어 채널이 안 꺼진다 |
| R14 | 10k | Q3 에미터-베이스. 제너가 안 흐를 때 베이스를 소스에 붙여 Q3를 끈다 |
| R15 | 4.7k | Q3 베이스와 제너 사이 전류 제한. 없으면 도통 시 에미터-베이스 접합과 제너가 맞물려 전류가 제한되지 않는다. 18V 입력에서 (18 - 0.7 - 12) / 4.7k = 1.1mA 베이스 전류, R13 전류 0.18mA를 포화로 끈다 |
| D3 | 1N4742A 12V | 임계 = Vz + Veb = 약 12.7V. 낮은 전류에서 제너가 12V보다 조금 아래에서 꺾여 실제 임계는 12.2V 근처. 정전압 9V 어댑터 무부하 9.6V는 안 걸리고 12V 어댑터는 걸릴 수도 안 걸릴 수도 있다(설계서 3.5절) |
| D14 | 1N4744A 15V | Q1·Q2 게이트-소스 보호. 18V 어댑터를 꽂는 순간 Q3가 켜지기 전에 Vgs가 약 17.3V까지 가고 케이블 링잉이 더해지면 정격 ±20V를 넘을 수 있어 15V로 묶는다. 9V에서 8.9V, 차단 임계 12.7V에서도 15V 아래라 평소에는 흐르지 않는다. 역방향 누설 5µA 이하(9.1V 기준)는 R13에서 0.5V 이하라 Vgs에 영향이 작다(2026-09-15 추가) |
| C7 | 1000µF 25V | 벌크. 230mA 부하에서 9V → 8V(감시 임계)까지 4.3ms, 4V(Seed3 VIN 하한)까지 22ms(설계서 3.5절) |

동작 확인(설계서 3.5절 그대로): 정방향에서 Q1 바디 다이오드가 먼저 도통하고 게이트가 GND라 두 채널이
열린다. 역방향에서 Q1 바디 다이오드가 막고 Vgs ≥ 0이라 열리지 않는다. 과전압에서 Q3가 공통 게이트를
VS로 올려 두 채널을 끊고, Q2 바디 다이오드가 부하 쪽으로 막혀 있어 전압이 넘어가지 않는다. VS는 Q1
바디 다이오드로 입력 - 0.7V에 머물러 제너 감지가 유지된다.

과전압 시험은 18V 전원이 없어 미판정(설계서 T12). 12V 어댑터가 있으면 임계 근처 동작만 볼 수 있다.

차단은 스위치처럼 끊기지 않는다. Q3가 선형 구간을 지나므로 12.5~15V 입력에서 두 MOSFET이 반쯤 열린다(12절
시뮬레이션). 이 구간에서 소모는 저항 부하 기준 최대 VS² / 4R로 약 1W(40Ω)이고 방열판 없는 TO-220에서 약 66°C
상승이다(계산값). Seed3는 정전력 부하라 V9가 내려가면 전류가 늘어 리셋과 재기동을 반복할 수 있다. 1N4742A의
Vz는 21mA 기준 11.4~12.6V이고 이 회로의 수십 µA에서는 더 낮아 임계는 약 12~13.9V로 흩어진다(데이터시트와
계산). 무부하 13V 이상이 나오는 비안정화 12V 어댑터가 이 구간에 든다. 1호는 정전압 9V 전용으로 두고 고치지
않는다. V9에서 Q3 베이스로 저항을 걸어 히스테리시스를 주면 기동 순간 V9가 0V라 Q3가 먼저 켜져 영영 도통하지
않으므로 그 방식은 쓰지 않는다.

## 2. LT1054 더블러와 아날로그 레일 (블록 B)

LT1054 데이터시트 그림 20(양전압 더블러)을 그대로 쓴다.

```
V9 ─ C16 10µF ─ GND        V9 ─ D1 1N5819 ─ PUMPX ─ D2 1N5819 ─ VRAIL_RAW ─ R16 10Ω ─ VRAIL
U2 LT1054: 8 V+ = V9, 3 GND, 5 VOUT = GND, 2 CAP+ ─ C8 10µF ─ PUMPX
           1 FB/SD, 4 CAP-, 6 VREF, 7 OSC 개방
VRAIL_RAW ─ C9 100µF ─ GND    VRAIL ─ C10 100µF, C17 100nF ─ GND
VRAIL ─ R11 10k ─ VBIAS ─ R12 10k ─ GND    VBIAS ─ C6 100µF ─ GND
```

| 부품 | 값 | 근거 |
|---|---|---|
| U2 | LT1054CP | 그림 20 결선. VOUT 핀을 GND에 묶고 CAP-는 개방. CAP+가 0~9V로 흔들리며 C8을 밀어 올린다 |
| C8 | 10µF 50V | 펌프. 그림 20의 값. 25kHz에서 등가 4Ω, 6mA에서 24mV 손실. + 쪽이 PUMPX(항상 CAP+보다 높다) |
| C16 | 10µF 50V | LT1054 입력. 그림 20의 2µF 이상. 핀 8 가까이 |
| D1, D2 | 1N5819 | 쇼트키 0.3V. 그림 20의 1N4001(0.7V)보다 레일이 0.8V 높다 |
| C9 | 100µF 35V | 더블러 출력. 리플 = 6mA / (25kHz × 100µF) = 2.4mVpp. 12V 어댑터에서 레일 약 23V라 25V 대신 35V |
| R16, C10 | 10Ω, 100µF 35V | 레일 필터. 차단 159Hz, 25kHz에서 -44dB라 리플 15µV. 6mA에서 60mV 강하 |
| C17 | 100nF | U1 전원 핀 가까이 |
| R11, R12 | 10k, 10k | Vbias = 레일 / 2 = 8.45V. 0.85mA. 레일이 흔들리면 같이 흔들리는 것이 의도(양쪽 헤드룸 대칭) |
| C6 | 100µF 35V | Vbias 임피던스. 20Hz에서 80Ω. R6(100k)와 R3(1.8M)만 매달리므로 충분. 기동 시정수 0.5s |

레일 계산(설계서 4.2절): 2 × 9.0 - 0.35(LT1054) - 0.6(쇼트키 2개) - 0.06(MOSFET 2개) - 0.06(R16) ≈ 16.9V.
레일 전류는 op-amp 4.8mA, Vbias 0.85mA, 피드백망 0.1mA로 약 6mA. T1에서 잰다.

## 3. Seed3 VIN 필터와 전원 감시 (블록 C)

```
V9 ─ R32 3.3Ω ─ SEED_VIN ─ C11 100µF(+), C12 100nF ─ GND    SEED_VIN ─ J4 39(VIN)
V9 ─ R19 47k ─ VMON ─ R20 10k ─ GND    VMON ─ C14 100nF ─ GND    VMON ─ R21 1k ─ J4 27(A5)
```

| 부품 | 값 | 근거 |
|---|---|---|
| R32 | 3.3Ω 1/4W | Seed3 데이터시트 그림 1.4의 인덕터 대신 저항. 150mA에서 0.5V 강하, 74mW. VIN은 약 8.5V로 4~17V 안 |
| C11 | 100µF 35V | 데이터시트 그림 1.1·1.4의 100µF. R32와 차단 0.5kHz. 모듈 안 스위칭 잡음이 V9로 되돌아오는 것도 막는다 |
| C12 | 100nF | 핀 39 가까이 |
| R19, R20 | 47k, 10k | 감시 분압 0.175. 9V → 1.58V, 12.7V → 2.23V, 18V → 3.16V로 3.3V 아래(설계서 3.5절 "3.3/16 이하") |
| C14 | 100nF | 분압 노드. 시정수 (47k ∥ 10k) × 100nF = 0.8ms. 블록 주기 1ms와 같은 급 |
| R21 | 1k | ADC 핀 직렬. 핀 보호. ADC 소스 임피던스는 C14가 받쳐 준다 |

Seed3 ADC는 16비트다. 12비트로 읽어도 1LSB = 0.8mV = 입력 4.6mV이고 설계서의 "-1V 임계"는 217LSB라 잡음
여유가 넉넉하다. 모듈 자체의 역극성 보호와 USB 전원 다이오드는 데이터시트 그림 1.0에 있고, 블록 A가 앞에
있어 여기서는 의지하지 않는다.

## 4. 입력 네트워크와 버퍼, 패드 (블록 D)

```
IN 잭 팁 ─ K1 11(COM1)   K1 14(NO1) = IN_A ─ R2 10k ─ C1 100nF ─ IN_C ─ U1A(+)   U1A 출력 = BUF_OUT ─ U1A(-)
IN_A ─ R1 2.2M ─ GND     IN_C ─ R3 1.8M ─ VBIAS
BUF_OUT ─ C2 47µF(+) ─ R4 3.3k ─ SEED_AUDIO_IN1 ─ R5 820Ω, C23 4.7nF ─ GND    SEED_AUDIO_IN1 ─ J4 16
```

| 부품 | 값 | 근거 |
|---|---|---|
| R1 | 2.2M | R_pd. NO 접점의 회로 쪽. 트루 바이패스 중에도 C1의 접점 쪽 극판을 0V로 잡는다(설계서 4.1절) |
| R2 | 10k | 클램프 전류 제한. 18V 베이스 ±9V 피크가 레일을 0.5V 넘을 때 55µA. OPA2992 입력 전류 한계 ±10mA의 1/180. 입력 용량 10pF와 1.6MHz라 대역에 영향 없다 |
| C1 | 100nF 필름 | R3와 차단 0.9Hz. 설계서 "10Hz 이하". 기동 시 R1 + R3 = 4M으로 충전, 시정수 0.4s |
| R3 | 1.8M | R_bias. 입력 임피던스 = R1 ∥ (R2 + R3) = 2.2M ∥ 1.81M = 0.99M |
| U1A | OPA2992 A | 유니티 버퍼. 출력을 - 입력에 직결 |
| C2 | 47µF 50V | 패드 커플링. 부하 R4 + (R5 ∥ 5k) = 4.0k와 차단 0.85Hz, 20Hz에서 -0.01dB. 20Hz에서 커패시터 양단에 신호의 4.2%, 41Hz에서 2.1%가 걸린다. + 쪽이 BUF_OUT(Vbias 전위), 반대쪽은 R4·R5로 0V |
| R4, R5 | 3.3k, 820Ω | 패드. 코덱 입력 임피던스 5kΩ ±20%(TAC5242 데이터시트, 모듈은 커플링 C만 더한다고 본다)를 포함해 (820 ∥ 5k) / (3.3k + 820 ∥ 5k) = 0.176 = -15.1dB. 4k~6k에서 -15.3~-14.9dB. 입력 풀스케일 = 1Vrms / 0.176 = 5.68Vrms = +17.3dBu. U1A 부하 4.0k는 OPA2992 정격(2kΩ) 안 |
| C24 | 100pF C0G 50V | RF 필터. R2 10k와 159kHz. 버퍼 입력 핀 가까이 둔다. 20kHz에서 약 0.07dB, 1MHz에서 -15dB 이하(`test_benches.py`). Seed3 Pedal Dev Kit 입력단의 100Ω/100pF와 같은 목적 |
| C23 | 4.7nF | 종단. 패드 출력 임피던스 580Ω(R4 ∥ R5 ∥ 5k)과 차단 58kHz. 20kHz에서 -0.5dB라 T3 기준 안이고, 유니티 트림이 흡수한다 |

코덱 임피던스 허용차 ±20%가 만드는 ±0.2dB와 모듈 안 직렬 부품이 있을 경우의 차이는 T5에서 잰 값으로 펌웨어
상수를 잡는다.

## 5. 출력단 (블록 E)

```
J4 18 = SEED_AUDIO_OUT1 ─ C3 1µF ─ OUT_IN ─ U1B(+)      OUT_IN ─ R6 100k ─ VBIAS
U1B 출력 = U1B_OUT ─ R7 47k ─ FB ─ U1B(-)         FB ─ R8 10k ─ C4 10µF(+) ─ GND
U1B_OUT ─ R9 100Ω ─ C5 10µF(+) ─ OUT_C ─ K1 24(NO2)    OUT_C ─ R10 100k ─ GND
OUT 잭 팁 ─ K1 21(COM2)
```

| 부품 | 값 | 근거 |
|---|---|---|
| C3, R6 | 1µF 필름, 100k | 커플링과 바이어스. 차단 1.6Hz. 코덱 단일 출력은 공통모드 1.65V(TAC5242 데이터시트, AVDD 3.3V)라 C3 양단에 Vbias - 1.65V가 걸린다. 필름이라 극성 무관. 부하 100k는 코덱 라인아웃 하한 600Ω과 Seed3 예시(15k) 이상 |
| R7, R8 | 47k, 10k | 게인 1 + 47/10 = 5.7 = +15.1dB. 설계서 +14.8dB. 1Vrms × 5.7 = 5.7Vrms = +17.3dBu |
| C4 | 10µF 50V | R8을 GND로 AC 접지. DC 게인 1이라 출력 DC = Vbias. R8과 차단 1.6Hz. Vbias로 돌려보내지 않아 Vbias에 신호 전류가 안 흐른다. + 쪽이 R8(FB는 Vbias 전위) |
| R9 | 100Ω | 케이블 용량과 op-amp 분리 |
| C5 | 10µF 50V | 출력 커플링. 앰프 입력 10k에서도 1.6Hz. + 쪽이 op-amp(Vbias 전위) |
| R10 | 100k | 방전 R. NO 접점의 회로 쪽. C5 접점 쪽 극판을 0V로 잡는다 |

헤드룸: Vbias 8.45V ± 8.06V 피크 = 0.39~16.51V. 레일 16.9V에서 위아래 0.39V. OPA2992 스윙 0.22~0.3V(2kΩ)
안이지만 여유가 작다. 레일이 요구 하한 16.1V면 +16.6dBu에서 클립하고 T6 기준(+16.5dBu)에는 든다. 어댑터가
8.7V 아래면 T4 유니티 트림으로 출력 목표를 낮춘다.

기동 대기: C5는 R9 + R10으로 충전돼 시정수 약 1s이고, Vbias도 C6으로 시정수 0.5s에 걸쳐 오른다. 둘을
합친 OUT_C 잔류 전압은 2 × 8.45V × e^(-t/1s) 꼴로 줄어 T11 무음 기준 -60dBu(0.78mV)에 약 10s에 닿는다.
버퍼드 모드 부팅에서 K1을 켜기 전 대기는 이 값 이상으로 두고 T11에서 확인한다. 대기 중에는 K1이 꺼져 있어
신호가 트루 바이패스로 지나간다.

## 6. K1 릴레이와 구동 (블록 F)

| 부품 | 값 | 근거 |
|---|---|---|
| K1 | TQ2-9V | 코일 A1 = V9, A2 = Q4 컬렉터. 코일 꺼짐 = NC. 11·21 COM, 12·22 NC, 14·24 NO. NC끼리 직결이 트루 바이패스. 코일 허용 상한은 정격의 150%(13.5V, 데이터시트)라 차단 임계 아래인 12V 어댑터도 안에 든다 |
| D4 | 1N4148 | 플라이백. 캐소드 V9 |
| Q4 | 2N3904 | 코일 15.5mA. R17로 베이스 1.2mA, hFE 13이면 포화 |
| R17 | 2.2k | (3.3 - 0.7) / 2.2k = 1.2mA. Seed3 GPIO 푸시풀 3.3V |
| R18 | 10k | 베이스 풀다운. MCU 리셋 중 핀이 하이 임피던스여도 K1이 풀린다(설계서 6.4절) |

회로도의 11·12·14·21·22·24는 KiCad 범용 심볼 번호다. TQ2 실물 핀(Panasonic TQ 데이터시트 p.10 바닥면도, 문서
기준): 코일 1(+)·10(-), 극 A는 COM 3·NC 2·NO 4, 극 B는 COM 8·NC 9·NO 7, 5·6은 비어 있다. 바닥면도라 윗면

## 10. 회로도 파일

`devices/bass-effector/hardware/bass-compressor.kicad_sch`는 KiCad 8 형식이고 9와 10에서 열린다. 부품은 블록별로

ERC를 돌리고, 필요하면 라벨을 따라 선으로 정리한다. KiCad 9.0.9의 `kicad-cli sch erc --severity-all`로
오류 0, 경고 0을 확인했다(2026-09-15). 같은 폴더의 `sym-lib-table`이 설치된 KiCad 9 심볼 라이브러리
(`${KICAD9_SYMBOL_DIR}`)를 가리키며, 없으면 심볼은 파일에 내장된 사본으로 열리고 라이브러리 경고만 난다.

    kicad-cli sch erc --severity-all --format report -o erc.txt devices/bass-effector/hardware/bass-compressor.kicad_sch

다시 만들려면 KiCad 9가 설치된 PC에서는 그 심볼 폴더를, 아니면 KiCad 심볼 라이브러리 9.0.7의 .kicad_sym
파일 11개(Device, Amplifier_Operational, Transistor_FET, Transistor_BJT, Regulator_SwitchedCapacitor, Relay,
Connector, Connector_Audio, Connector_Generic, Switch, power)를 받은 폴더를 지정한다.

    python devices/bass-effector/hardware/gen_schematic.py --libs /usr/share/kicad/symbols

값이나 결선을 바꿀 때는 생성기의 PARTS 표를 고치고 다시 만든다. netlist.md는 같이 갱신된다.

## 11. 설계서와 다른 점

설계서를 고치지 않고 여기서만 정한 것과, 설계서를 이 문서에 맞춰 고친 것.

- 과전압 차단 트랜지스터를 NPN에서 PNP(2N3906)로 바꿨다. 설계서 3.5절을 같이 고쳤다
- 게이트 보호 제너 D14(1N4744A 15V)를 더했다. 설계서 3.5절의 "Vgs 정격 ±20V 이상이거나 게이트 보호 제너" 중 둘 다
  택한다(2026-09-15 검토). 직렬 R은 R13 100k가 맡는다
- LED 저항을 1k에서 470Ω으로 내렸다. 설계서 부품표는 페달파츠 주문이라 값만 여기서 정한다
- 레일·Vbias 전해 커패시터를 25V에서 35V로 올렸다. 12V 어댑터 대비
- 출력단 게인을 +14.8dB 대신 E24 값으로 +15.1dB로 잡았다. 유니티 트림이 흡수한다
- 패드 커플링을 필름 1µF에서 전해 47µF로 바꿨다. 모듈 입력 임피던스가 미공개라 패드를 저임피던스로 잡으면서
  차단 주파수를 지키려면 용량이 필요하다. 47µF에서 차단이 0.85Hz라 20Hz에서 커패시터 양단에 걸리는
  신호가 4.2%다
- 출력단 피드백 하단(R8)을 Vbias가 아니라 C4를 거쳐 GND에 둔다. Vbias 노드에 신호 전류가 흐르지 않게

### 12.1 공차 몬테카를로

`monte_carlo.py`, 200벌, 시드 1. 저항 ±1%(R32 ±5%), 필름·세라믹 ±10%(C23 ±5%), 전해 ±20%, 코덱 입력 4~6kΩ, 어댑터
8.7~9.6V(블록 A 포함, V9 부하 40Ω), 쇼트키 순방향 0.25~0.45V(1mA, 모델 IS로 환산), 레일 부하 2.8kΩ. 레일은 기동 뒤
100~150ms 최솟값이라 Vbias 충전 전류가 남아 있어 정착 값보다 조금 낮다. 출력 스윙은 그 레일에서 모듈 0dBFS
사인을 넣은 값이다.

LT1054 온저항은 두 시나리오로 돌렸다. 데이터시트 범위는 10mA 손실 0.35~0.55V에 해당하는 7.9~12.7Ω(이상 다이오드로
보정), 보수 시나리오는 기존 모델 25Ω 고정이다.

| 값 | 기준 | 데이터시트 범위: 최솟값 / 50% / 미달 | 보수 시나리오: 최솟값 / 50% / 미달 |
|---|---|---|---|
| 아날로그 레일 최솟값 | 16.1V 이상 | 15.88V / 16.90V / 8 | 15.43V / 16.42V / 62 |
| 패드 비율 | -15 ±1.5dB | -15.46dB / -15.16dB / 0 | 같음 |
| 출력단 0dBFS 스윙 | +16.5dBu 이상 | +16.78dBu / +17.19dBu / 0 | +16.53dBu / +17.08dBu / 0 |
| Vbias / 레일 | 0.5 ±2% | 0.496 / 0.500 / 0 | 같음 |

레일 16.1V는 +17dBu 스윙에서 거꾸로 낸 요구라, 레일이 그 아래로 내려간 표본도 T6 기준(+16.5dBu)은 모두 통과했다.
보수 시나리오의 최솟값은 기준과 0.03dB 차이다. 단일 변수로 바꾸면 레일은 어댑터 8.7V에서 0.57V, 쇼트키 0.45V에서
0.26V 내려간다(공칭 대비, 온저항 25Ω). 실제 여유는 T1(어댑터 실전압과 레일)과 T6이 판정한다.

### 12.2 잡음 예산

`noise_budget.py`. op-amp는 `opamp_rr_noise.inc`(동작 모델에 OPA2992 데이터시트 잡음원: 전압 1kHz 7nV/√Hz, 10kHz
4.4nV/√Hz, 전류 60fA/√Hz)이고, 1/f 모양 대신 백색 전압 잡음 7n(보수)과 4.4n(광대역) 두 값으로 돌렸다. 저항 열잡음은
ngspice가 넣는다. 코덱 다이내믹 레인지는 A 가중 값으로 보고 다른 대역은 백색 가정으로 환산했다. 시스템이 유니티라
출력 잭 기준 잡음을 입력 기준으로 그대로 합산한다. 입력 풀스케일은 경로 게인에서 +17.4dBu로 나온다.

잭 단락, 모듈 출력 임피던스 0Ω(100Ω도 같은 값), en 7nV:

| 코덱 | 입력 쪽 dBu(A) | 출력 쪽 dBu(A) | 합산 dBu(A) | DR dB(A) | DR 125~8000Hz | T7 구간 | 지배 쪽 |
|---|---|---|---|---|---|---|---|
| 칩 값 (ADC 119dB, DAC 120dB) | -101.0 | -97.5 | -95.9 | 113.3 | 115.4 | 통과 | 출력 |
| 칩 값 -10dB | -91.6 | -91.8 | -88.7 | 106.1 | 108.2 | 통과 | 비슷(0.2dB 차) |

en 4.4nV에서는 출력 쪽이 0.5dB 낮고 DR은 0.3dB 높다. 출력 쪽 아날로그 잡음의 부품별 기여(A 가중, 출력 잭)는
R8 -101.2dBu, op-amp 전압 잡음 -104.8dBu, R7 -107.9dBu 순이다. R8 열잡음이 게인 R7/R8 = 4.7배로 나오는 몫이 가장 크다.
입력 쪽 아날로그 잡음은 코덱 바닥(칩 값)을 약 0.6dB 올린다. 기여는 R5, R2, R4 순이다.

베이스 연결(픽업 가정값: 직렬 7kΩ·3H, 병렬 600pF, 볼륨·톤 포트 부하 125kΩ. 보유 베이스 실측 전)에서는 입력 쪽이
-100.3dBu(A)로 잭 단락보다 0.7dB 크고, DR은 칩 값 113.1dB(A), 칩 값 -10dB 106.1dB(A)다. 입력 기준 잡음은 출력 노드
잡음을 1kHz 경로 게인으로 나눈 값이다. 픽업 L·C가 고역 게인을 떨어뜨려 주파수별 게인으로 나눈 `inoise_spectrum`은
고역 잡음을 부풀리므로 쓰지 않는다.
