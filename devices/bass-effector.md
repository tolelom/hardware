# 베이스 이펙터 계획

상세 설계: [bass-effector-design.md](bass-effector-design.md). 회로 값과 결선: [bass-effector-schematic.md](bass-effector-schematic.md)
최종 갱신: 2026-09-15

## 무엇을 만드나

베이스를 입력받아 실시간 처리하는 페달이다. 1호는 컴프레서 페달 하나다(2026-09-08).
이펙트 체인(드라이브·EQ·옥타버·딜레이)과 루퍼는 1호 뒤에 같은 하드웨어에서 펌웨어로 늘린다.

## 상태

미착수. 설계서 검토 대기.

## 구성 요약

| 항목 | 결정 |
|---|---|
| 디지털 코어 | Teensy 4.1과 Audio Shield Rev D(SGTL5000). 코덱은 교체 경계를 두고 SGTL5000으로 시작 |
| 아날로그 입출력 | LT1054 더블러 레일, OPA2992 버퍼와 출력단, 코덱 앞 고정 패드 -15dB |
| 컨트롤 | 노브 5개(Input, Ratio, Att/Rel, Blend, Output), 풋스위치, 감쇠 미터 LED 8칸과 온 LED |
| 바이패스 | 논래칭 릴레이 1개. 전원이 없으면 트루 바이패스, 전원이 있으면 모드로 트루 또는 버퍼드(DSP 드라이 경로) 선택 |
| 케이스 | 1590BB 클론 |
| 전원 | 정전압 9V 센터 마이너스, 500mA 이상 |

## 보드 확정 근거

페달의 요구사항이 이 급(크로스오버 MCU, M7 600MHz 베어메탈)의 기본값이다: 전원 인가 즉시 기동, 튜닝 없이
왕복 지연 수 ms, 전원 차단에 안전. 컴프레서와 이후 체인은 블록 몇 개로 연산이 충분하고, 루퍼만
PSRAM(8MB)을 쓴다.

2026-09-14 재설계에서 아키텍처 세 갈래(완전 디지털에 아날로그 입출력단, 아날로그 VCA와 디지털 사이드체인
하이브리드, 완전 아날로그)를 비교했다. 오디오 알고리즘을 펌웨어로 직접 짜는 것과 1호 뒤 시간계 이펙트
확장을 닫지 않는 것이 조건이라 디지털 코어를 유지했다.

### 보드 선정 (2026-08-18 확정)

탈락 후보:

| 후보 | 탈락 사유 |
|---|---|
| Daisy Seed | 메모리 수급 문제로 생산 일시 중단. 재입고되면 재검토 |
| Blackaddr TGA Pro | 품절 |
| Bela | 프리오더, 고가 |
| ESP32 / RP2350 | 코덱 자작 부담 |

유통 구조: 2025년 3월 이후 Teensy 4.0·4.1은 SparkFun이 제조와 직판을 맡고 다른 유통사에도 공급한다
(PJRC 공지). Adafruit은 2026-01에 취급을 끝냈다.

변종은 둘이다. `TEENSY41`은 이더넷 PHY(DP83825)가 보드에 실려 있고 `TEENSY41_NE`는 그 칩만 뺀 것이다.
이펙터는 이더넷을 안 쓰므로 어느 쪽이든 된다.

### 주문 시 알아둘 것

- DigiKey 카드 입력 iframe(cc.digikey.com)이 digikey.kr과 크로스 사이트라 서드파티 쿠키 차단 시 결제가
  안 된다. 주소창 쿠키 아이콘에서 허용 후 재시도. 시크릿 모드는 기본 차단이라 역효과다.
- DigiKey 코리아 주문은 관세·세금을 수령 시 낸다(CPT).
- 검색 스니펫의 재고 정보는 낡을 수 있다. 주문 직전 상품 페이지에서 확인한다. 상품 URL은 추측하지 말고
  품번 검색을 거친다.

## 단계

| # | 단계 | 판정 기준 (설계서 7절) |
|---|---|---|
| 0 | 보유 베이스 피크 측정 | M1 |
| 1 | 디지털 경로. Teensy와 Shield, 스칼렛 루프 | M2, T5, T7, T8, T9, T15 |
| 2 | 아날로그단 브레드보드. 레일, 버퍼, 패드, 출력단 | T0, T1, T3, T4, T6 |
| 3 | 릴레이와 제어 | T11, T12, T13, T14 |
| 4 | 케이스와 연주 | T2, T10, T16 |

## 그만둘 조건

- 왕복 지연(T8)이 연주에 걸리면(T16) 블록 크기를 줄여 보고, 그래도 안 되면 보드 선정으로 돌아간다.
- 바닥 노이즈(T7)가 기대치보다 나쁘고 코덱 교체로도 해소되지 않으면 아키텍처 비교(보드 확정 근거 절)로
  돌아간다.
- 차지 펌프 잡음이 레일 필터로 잡히지 않으면 레일 방식을 다시 본다.

## 2세대 (PocketBeagle 2)

넘어가는 조건: 신경망 앰프 모델링, 긴 임펄스 응답, 루퍼 대용량처럼 Teensy의 연산·저장 한계에 실제로
부딪히는 것. 플레이어 1세대(거치형)가 McASP·코덱 연결을 먼저 확립하므로, 넘어가는 시점에는 그 결과를
그대로 쓴다. 단계는 pocket-beagle2 저장소 [applications.md](https://github.com/tolelom/pocket-beagle2)의 이펙터 절을 따른다.
