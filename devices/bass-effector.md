# 베이스 이펙터 계획

상세 설계: [bass-effector-design.md](bass-effector-design.md). 회로 값과 결선: [bass-effector-schematic.md](bass-effector-schematic.md)
최종 갱신: 2026-09-16

## 무엇을 만드나

베이스를 입력받아 실시간 처리하는 페달이다. 1호는 컴프레서 페달 하나다(2026-09-08).
이펙트 체인(드라이브·EQ·옥타버·딜레이)과 루퍼는 1호 뒤에 같은 하드웨어에서 펌웨어로 늘린다.

## 상태

Seed3 재설계 완료, 부품 주문 중. Seed3 2개를 daisy.audio에 주문했다(2026-09-15, 네덜란드 발송). DigiKey는
[1단계 계획 Task 1](bass-effector-plan-stage1.md)의 표대로 2대분 장바구니를 채웠고 결제만 남았다(2026-09-16).
케이스는 1590C 클론에 페달파츠 커스텀 타공으로 정했다(설계서 5.1절). 페달파츠는 타공 도면과 문의 뒤에 주문한다.

## 구성 요약

| 항목 | 결정 |
|---|---|
| 디지털 코어 | Daisy Seed3(STM32H750, TAC5242 코덱 내장). 입력 게인은 디지털만 |
| 아날로그 입출력 | LT1054 더블러 레일, OPA2992 버퍼와 출력단, 모듈 앞 고정 패드 -15dB |
| 컨트롤 | 노브 5개(Input, Ratio, Att/Rel, Blend, Output), 풋스위치, 감쇠 미터 LED 8칸과 온 LED |
| 바이패스 | 논래칭 릴레이 1개. 전원이 없으면 트루 바이패스, 전원이 있으면 모드로 트루 또는 버퍼드(DSP 드라이 경로) 선택 |
| 케이스 | 1590C 클론(1590BB와 같은 면적, 높이 56mm). 페달파츠 커스텀 타공 |
| 전원 | 정전압 9V 센터 마이너스, 500mA 이상 |

## 보드 확정 근거

페달의 요구사항이 이 급(크로스오버 MCU, M7 600MHz 베어메탈)의 기본값이다: 전원 인가 즉시 기동, 튜닝 없이
왕복 지연 수 ms, 전원 차단에 안전. 컴프레서와 이후 체인은 블록 몇 개로 연산이 충분하고, 루퍼만
PSRAM(8MB)을 쓴다.

2026-09-14 재설계에서 아키텍처 세 갈래(완전 디지털에 아날로그 입출력단, 아날로그 VCA와 디지털 사이드체인
하이브리드, 완전 아날로그)를 비교했다. 오디오 알고리즘을 펌웨어로 직접 짜는 것과 1호 뒤 시간계 이펙트
확장을 닫지 않는 것이 조건이라 디지털 코어를 유지했다.

### 보드 변경 (2026-09-15)

08-18 선정에서 Daisy Seed는 생산 중단으로 빠졌고 재입고되면 재검토하기로 했다. 2026-07 말 Seed3가 출시돼
재고가 생겨 Seed3로 바꾼다. 수치는 문서 기준.

| 항목 | Teensy 4.1과 Audio Shield Rev D | Daisy Seed3 |
|---|---|---|
| 코덱 | SGTL5000. LINEIN→ADC SNR 90dB, 입력 최대 2.83Vpp (VDDA 3.3V) | TI TAC5242. ADC 다이내믹 레인지 119dB, DAC 120dB, 단일 입력 최대 1Vrms |
| MCU, 메모리 | i.MX RT1062 600MHz. PSRAM은 따로 단다 | STM32H750 480MHz, RAM 65MB |
| 구성 | 모듈 2개, I2S 수작업 배선 | 코덱이 모듈 안에 있다 |
| 구매 | DigiKey 코리아 | daisy.audio 직판, 미국 발송, $29.99. DigiKey 코리아 미취급 |
| 페달 플랫폼 | Aviate Multiverse(상용), TGA Pro(품절) | PedalPCB Terrarium, Hothouse(Seed3 지원), GuitarML FunBox·Soundsketch, bkshepherd 125B(릴레이 바이패스) |

- 이전 Seed Rev7과 Seed2 DFM은 코덱이 PCM3060(ADC 다이내믹 레인지 99dB)이다. Seed3는 MCU와 메모리가 같고
  코덱과 USB-C가 바뀌었으며 핀 호환이다(libDaisy `daisy_seed.h`)
- Daisy는 2026-03~06에 메모리 수급 문제로 생산을 멈췄다가 외주 생산으로 재개했다
- `effector_core`는 Arduino 헤더가 없어 그대로 옮기고, Teensy 전용 층(`effector/src`)을 다시 짠다
- Seed3 데이터시트로 확인한 것(설계서 4.2~4.4절): 오디오 입력 ±1.8V로 모듈 안에서 AC 커플링, 출력 0dBFS 1Vrms,
  VIN 4~17V. TAC5242는 핀 제어라 소프트웨어 입력 게인이 없어 Input 노브는 디지털 게인만 쓴다. 아날로그 앞단은
  +17dBu 체인(더블러 레일)을 유지하고 7805는 뺀다. 케이스는 1590BB 유지(09-16 높이 검토에서 1590C로 바꿈), 펌웨어는 libDaisy Makefile과 USB DFU

이펙터는 이더넷을 안 쓰므로 어느 쪽이든 된다.

### 주문 시 알아둘 것

- DigiKey 카드 입력 iframe(cc.digikey.com)이 digikey.kr과 크로스 사이트라 서드파티 쿠키 차단 시 결제가
  안 된다. 주소창 쿠키 아이콘에서 허용 후 재시도. 시크릿 모드는 기본 차단이라 역효과다.
- DigiKey 코리아 주문은 관세·세금을 수령 시 낸다(CPT).
- 검색 스니펫의 재고 정보는 낡을 수 있다. 주문 직전 상품 페이지에서 확인한다. 상품 URL은 추측하지 말고
  품번 검색을 거친다.

## 그만둘 조건

- 왕복 지연(T8)이 연주에 걸리면(T16) 블록 크기를 줄여 보고, 그래도 안 되면 보드 선정으로 돌아간다.
- 바닥 노이즈(T7)가 기대치보다 나쁘고 배선·접지 정리로도 해소되지 않으면 아키텍처 비교(보드 확정 근거 절)로
  돌아간다.
- 차지 펌프 잡음이 레일 필터로 잡히지 않으면 레일 방식을 다시 본다.

## 2세대 (PocketBeagle 2)

넘어가는 조건: 신경망 앰프 모델링, 긴 임펄스 응답, 루퍼 대용량처럼 Seed3의 연산·저장 한계에 실제로
부딪히는 것. 플레이어 1세대(거치형)가 McASP·코덱 연결을 먼저 확립하므로, 넘어가는 시점에는 그 결과를
그대로 쓴다. 단계는 pocket-beagle2 저장소 [applications.md](https://github.com/tolelom/pocket-beagle2)의 이펙터 절을 따른다.
