# 베이스 이펙터 계획

베이스를 입력받아 실시간 처리해 출력하는 페달을 만든다.
보드는 Teensy 4.1로 확정했다(2026-09-01). 1호는 컴프레서 페달 하나다(2026-09-08).
최종 갱신: 2026-09-08

## 1호: 컴프레서 페달

이펙트 하나를 페달 케이스에 넣어 실제로 쓰는 것이 1호의 완성 기준이다.
이펙트 체인(드라이브·EQ·옥타버·딜레이)과 루퍼는 1호 뒤에 같은 하드웨어 위에서
펌웨어로 늘린다. PSRAM은 루퍼 시점에 단다.

```
베이스 → 입력 버퍼(op-amp) → Audio Shield 라인인 → Teensy 컴프레서 → Shield 라인아웃 → 오디오 인터페이스 → 헤드폰
                                                        ^
                                              노브 4개 (ADC), 풋스위치, LED
```

앰프가 없다. 출력 판정은 전부 오디오 인터페이스 입력으로 한다. 앰프가 생기면
라인 레벨 출력이 앰프 악기 입력에 과할 수 있어 출력 감쇠를 그때 붙인다.

| 항목 | 결정 |
|---|---|
| 이펙트 | 컴프레서. 파라미터는 스레숄드, 레시오, 어택/릴리즈, 메이크업 게인 |
| 조작 | 10k 포텐셔미터 4개를 Teensy ADC에. 풋스위치 1개는 소프트웨어 바이패스. LED 1개 |
| 바이패스 | 소프트웨어. 릴레이 트루 바이패스는 1호에서 안 한다 |
| 전원 | 페달 표준 9V DC 잭(2.1mm, 센터 마이너스). 버퍼는 9V 그대로, Teensy는 5V 레귤레이터로 내린다 |
| 컴프레서 구현 | OpenAudio_ArduinoLibrary(F32)의 `AudioEffectCompressor_F32`. 코어 int16 라이브러리용으로는 MarkzP의 AudioEffectDynamics가 있다. 둘 다 문서 기준(2026-09-08 확인) |

## 상태

미착수. 2026-08-18에 보드와 부품을 확정하고 08-19 DigiKey 결제 단계까지 갔다가 카드
iframe 차단으로 중단됐다. 08-21에 부품 구성이 만들려는 것과 맞지 않는다고 보고
멈췄는데, 그때 부품표는 브레드보드 DSP 개발 구성이었고 페달에 필요한 풋스위치·DC
잭·레귤레이터·노브·케이스가 없었다. 2026-09-08에 1호를 컴프레서 페달로 좁히고
부품표를 페달 기준으로 다시 짰다. 주문 전이다.

## 보드 확정 근거

페달의 요구사항이 이 급(크로스오버 MCU, M7 600MHz 베어메탈)의 기본값이다:
전원 인가 즉시 기동, 튜닝 없이 왕복 지연 수 ms, 전원 차단에 안전. 컴프레서 하나는
Audio Library 블록 하나로 연산이 충분하고, 이후 체인도 기본 블록으로 된다. 루퍼만
PSRAM(8MB)을 쓴다.

PocketBeagle 2는 2세대 후보로 남긴다. 신경망 앰프 모델링처럼 리눅스와 A53급
연산이 필요한 DSP가 실제로 필요해지면 그때 넘어간다. 상세는 pocket-beagle2 저장소
[applications.md](https://github.com/tolelom/pocket-beagle2). 버퍼 회로와
6.35mm 잭은 그때도 그대로 쓴다.

## 보드 선정 (2026-08-18 확정)

Teensy 4.1 + Audio Shield Rev D. 코덱은 SGTL5000. 16bit 44.1kHz 스테레오
입출력, 헤드폰 앰프, microSD 슬롯이 쉴드에 있다.

탈락 후보와 재고 재확인(2026-09-01):

| 후보 | 탈락 사유 (08-18) | 재확인 (09-01) |
|---|---|---|
| Daisy Seed | 생산 중단, 재입고 미정 | 메모리 수급 문제로 생산 일시 중단(2026 초), 4월부터 리셀러 판매 중단. 재입고 공지가 있었으나 직판 페이지 상태는 미확정. 재입고가 확인되면 페달 생태계 우위로 재검토 |
| Blackaddr TGA Pro | 품절 | 재확인 안 함 |
| Bela | 프리오더, 고가 | 재확인 안 함 |
| ESP32 / RP2350 | 코덱 자작 부담 | 사유가 재고가 아니라 변동 없음 |

Teensy 4.1은 SparkFun 재고 있음(2026-09-01 확인), Audio Shield Rev D는 DigiKey
당일 출고. 유통 구조: 2025년 3월 이후 Teensy 4.0·4.1은 SparkFun이 제조와 직판을
맡고 다른 유통사에도 공급한다(PJRC 공지). Adafruit은 2026-01에 취급을 끝냈다.

변종은 둘이다. `TEENSY41`은 이더넷 PHY(DP83825)가 보드에 실려 있고 `TEENSY41_NE`는
그 칩만 뺀 것이다. 이펙터는 이더넷을 안 쓰므로 어느 쪽이든 된다.

| 품목 | 규격 | 수량 | 비고 |

| 포텐셔미터 | 10k 리니어(B), 6.35mm 샤프트 | 4 | Teensy ADC 입력. 3.3V 기준 |
| 풋스위치 | SPST 모멘터리 | 1 | 소프트웨어 바이패스라 모멘터리면 된다 |

| 5V 레귤레이터 | 7805 또는 소형 벅 모듈 | 1 | Teensy 4.1 VIN 5V. 7805는 9V에서 100mA 급이면 발열이 작다 |

| 케이스 | 125B급 알루미늄 | 1 | 노브 4개와 잭 2개가 들어가는 크기 |
| 노브 | 6.35mm | 4 | |

### 주문 시 알아둘 것

- DigiKey 카드 입력 iframe(cc.digikey.com)이 digikey.kr과 크로스 사이트라
  서드파티 쿠키 차단 시 결제가 안 된다. 주소창 쿠키 아이콘에서 허용 후 재시도.
  시크릿 모드는 기본 차단이라 역효과다.
- 배송은 FedEx International Priority. 총액이 면세 범위면 개인통관고유부호만
  준비하면 된다.
- 검색 스니펫의 재고 정보는 낡을 수 있다. 주문 직전 상품 페이지에서 확인한다.
  상품 URL은 추측하지 말고 품번 검색을 거친다.

## 버퍼 회로 (확정)

유니티 게인 비반전 op-amp 버퍼. 9V 단전원, 1M 입력 임피던스, 4.5V 바이어스.
게인 스테이지는 두지 않는다. SGTL5000의 lineInLevel로 풀스케일을 0.24~3.12Vpp
범위에서 조절할 수 있기 때문이다. 브레드보드 단계의 험·잡음은 배선 문제로
분류한다(케이스 단계에서 해소).

## 단계

| # | 단계 | 판정 기준 |
|---|---|---|
| 1 | 브레드보드 컴프레서 | 오디오 인터페이스 라인아웃에서 넣은 신호가 Shield를 거쳐 다시 오디오 인터페이스로 돌아오고, 노브를 돌리면 게인 리덕션이 파형에서 보인다. 부품 도착 당일 예제·USB 오디오까지 확인 |
| 2 | 실입력 | 버퍼를 달고 베이스를 직결해 컴프레서가 걸린 소리가 헤드폰에서 난다. 레벨은 lineInLevel로 조정 |
| 3 | 페달화 | 케이스에 넣고 9V 어댑터로 켜서 풋스위치로 온·오프가 되고, 이 상태로 연습에 쓴다 |

신호 품질 기대치는 보급형 멀티이펙터급. 병목은 코덱이 아니라 입력단 게인
스테이징과 전원이다.
