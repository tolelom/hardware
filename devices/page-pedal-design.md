# 악보 페달 설계서

계획 배경: RP2040 사다리 [rp2040/README.md](../rp2040/README.md), 멀티 이펙터 [bass-multi-platform-design.md](bass-multi-platform-design.md)
최종 갱신: 2026-10-29

## 1. 무엇을 만드나

발판 2개짜리 유선 페달이다. 하나의 페달이 두 역할을 한다.

| 꽂는 곳 | 역할 | 연결 |
|---|---|---|
| 갤럭시 탭, PC | 악보 페이지 넘기기. USB 키보드로 인식돼 드라이버가 필요 없다 | USB-C |
| 멀티 이펙터 EXP 잭 | 이펙터의 외장 풋스위치 2개 | 6.35mm TRS |

이펙터 없이 연습할 때(베이스, 피아노)는 탭에 꽂아 악보를 넘긴다. 이펙터와 연습할 때는 이펙터에 꽂아 발판을 늘리고,
악보 넘기기는 이펙터가 자기 USB로 한다.

## 2. 왜 이렇게 나눴나

| 결정 | 이유 |
|---|---|
| 이펙트 켜고 끄기, 탭에 악보 넘기기, USB MIDI는 이펙터 펌웨어가 맡는다 | 이펙터에 USB-C와 풋스위치 3개가 있어 페달 없이 된다. 스톰프 모드는 상용 멀티 이펙터의 기본 기능이다 |
| 페달은 이펙터 없이 악보를 넘기는 용도가 주다 | 이펙터 기능과 겹치지 않는 페달만의 쓸모 |
| 같은 페달을 이펙터 외장 풋스위치로도 쓴다 | 상용 멀티 이펙터 사용자가 외장 발판을 붙이는 가장 흔한 이유가 발판 부족이다. 이펙터 EXP 잭이 2버튼 풋스위치를 받게 했다 |
| 유선, XIAO RP2040 | 보유 보드에 매일 쓰는 일감을 준다. 사다리에서 배운 입력·USB가 그대로 들어간다. 무선은 써 보고 필요하면 nRF52840 2호기 |
| MIDI 없음 | 이펙터와는 풋스위치 신호(TRS)로만 대화한다. MIDI 회로와 케이블이 빠진다 |
| 발판 LED 없음 | 상태는 탭 화면과 이펙터 화면에 보인다. XIAO 온보드 RGB LED 하나로 키 세트만 알린다 |

## 3. 하드웨어

| 부품 | 정한 것 | 근거 |
|---|---|---|
| 두뇌 | Seeed XIAO RP2040, 완성품용으로 한 장 새로 산다 | 지금 보드는 개발용으로 남긴다 |
| 발판 | Taiwan Alpha SF12011F-0202-20R-M-027 ×2. 모멘터리 DPDT, 소프트터치(저하중, 소리 작음), 12mm 홀, 6핀 | 접점 두 벌이 전기적으로 분리돼 있어 USB 쪽과 이펙터 쪽을 한 선도 공유하지 않고 나눈다 |
| TRS 잭 | 6.35mm 스테레오 패널 잭 1개 | 2버튼 풋스위치 관례: 팁–슬리브 1번, 링–슬리브 2번(Boss FS-6 방식) |
| USB | XIAO의 USB-C를 케이스 옆면 구멍으로 낸다 | 부품이 가장 적다 |
| 케이스 | 기성 다이캐스트 알루미늄, 발판 2개 간격이 나오는 크기(1590BB급). 타공은 주문 | 이펙터와 같은 방식. 모델은 발판 간격을 재고 정한다 |

### 결선

```
발판 1 접점 A ── XIAO D0 (GPIO26, 내부 풀업) / GND
발판 2 접점 A ── XIAO D1 (GPIO27, 내부 풀업) / GND
발판 1 접점 B ── TRS 팁  / TRS 슬리브
발판 2 접점 B ── TRS 링  / TRS 슬리브
```

- 접점 A와 B가 분리돼 있어 생기는 일:
  - 이펙터 쪽은 그냥 스위치라 페달에 전원이 없어도 동작한다(USB를 안 꽂아도 된다).
  - USB 쪽(탭·PC)과 이펙터 쪽 접지가 페달 안에서 만나지 않아 접지 루프로 인한 험이 생기지 않는다.
  - 이펙터 풀업 전압이 전원 없는 XIAO 핀으로 거꾸로 흘러 들어가지 않는다.
- 둘 다 꽂으면 한 번 밟을 때 양쪽에 동시에 신호가 간다. 이펙터와 연습할 때는 악보 넘기기를 이펙터가 하므로 USB를 꽂지 않는다.
- 디버그 UART(GPIO0·1, D6·D7)는 비워 둔다.

## 4. 동작 (USB 쪽)

| 발판 | 짧게 | 길게(0.5초) |
|---|---|---|
| 왼쪽 | 이전 페이지 | 맨 앞으로(Home) |
| 오른쪽 | 다음 페이지 | 키 세트 바꾸기. 온보드 LED 색으로 알리고 전원을 꺼도 기억 |

키 세트: ① Page Up / Page Down(기본) ② 방향키 ← / → ③ Shift+스페이스 / 스페이스. 쓸 악보 앱은 아직 정하지 않았다.
앱이 받는 키가 다르면 세트를 바꾼다.

이펙터 쪽 동작(짧게·길게 판정과 기능 배정)은 이펙터 펌웨어가 정한다. 페달은 스위치만 제공한다.

## 5. 펌웨어

RP2040 사다리에서 직접 짠 베어메탈 펌웨어로 완성한다. 사다리 단계가 곧 페달 펌웨어다.

| 사다리 | 페달에서 |
|---|---|
| 5 타이머·인터럽트 | 길게 누르기 판정 |
| 8 키 입력·디바운스 | 발판 읽기 |
| 10 설정 저장 | 키 세트 기억 |
| 7 PIO | 온보드 RGB LED |
| 11a·b·c USB 연결·열거·HID | 키보드로 인식, 키 보내기 |

사다리 11단계까지 주말 열 번 남짓(어림) 걸린다. 그 전에 쓰고 싶으면 TinyUSB나 CircuitPython으로 임시 펌웨어를 먼저 굽는다.
RP2040은 B 버튼으로 언제든 다시 구울 수 있다. 임시 펌웨어를 쓸지는 아직 정하지 않았다.

## 6. 이펙터 쪽 요구 (멀티 이펙터에 반영함)

- EXP 잭(J12) 링을 ADC로 읽는다. R59 1kΩ + C53 100nF → Seed3 D28(ADC11). 회로 설계 문서 3절.
- 펌웨어 규칙: 링이 98% 아래에서 일정하면 익스프레션 페달, 아니면 팁·링이 0%로 떨어지는 것을 각각 1·2번 발판 밟음으로 본다.
- 외장 발판 기능 배정(예: 이펙트 슬롯 토글, 탭 템포)은 이펙터 펌웨어(서브프로젝트 2)에서 정한다.

## 7. 완성 기준

- 갤럭시 탭과 PC에 꽂자마자 키보드로 인식된다.
- 1000번 밟아 두 번 넘어가거나 안 넘어가는 일이 0번이다.
- 길게 누르기가 짧게 누르기와 헷갈리지 않는다.
- 전원을 껐다 켜도 키 세트가 유지된다.
- 이펙터 EXP 잭에 꽂아 USB 없이 1·2번 발판이 이펙터에서 구분된다.
