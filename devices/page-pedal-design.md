# 악보 페달 설계서

계획 배경: 멀티 이펙터 [bass-multi-platform-design.md](bass-multi-platform-design.md), 보드 [parts/xiao-nrf52840.md](../parts/xiao-nrf52840.md)
최종 갱신: 2026-10-30

## 1. 무엇을 만드나

발판 2개짜리 악보 페달이다. 하나의 페달이 두 역할을 한다.

| 연결 | 역할 | 방식 |
|---|---|---|
| 갤럭시 탭, PC | 악보 페이지 넘기기. 키보드로 인식돼 드라이버가 필요 없다 | 블루투스(BLE HID) 또는 USB-C 유선 |
| 멀티 이펙터 EXP 잭 | 이펙터의 외장 풋스위치 2개 | 6.35mm TRS |

이펙터 없이 연습할 때(베이스, 피아노)는 탭에 블루투스로 붙여 악보를 넘긴다. 이펙터와 연습할 때는 이펙터에 꽂아 발판을 늘리고,
악보 넘기기는 이펙터가 자기 USB로 한다.

## 2. 왜 이렇게 나눴나

| 결정 | 이유 |
|---|---|
| 이펙트 켜고 끄기, 탭에 악보 넘기기, USB MIDI는 이펙터 펌웨어가 맡는다 | 이펙터에 USB-C와 풋스위치 3개가 있어 페달 없이 된다. 스톰프 모드는 상용 멀티 이펙터의 기본 기능이다 |
| 페달은 이펙터 없이 악보를 넘기는 용도가 주다 | 이펙터 기능과 겹치지 않는 페달만의 쓸모 |
| 같은 페달을 이펙터 외장 풋스위치로도 쓴다 | 상용 멀티 이펙터 사용자가 외장 발판을 붙이는 가장 흔한 이유가 발판 부족이다. 이펙터 EXP 잭이 2버튼 풋스위치를 받게 했다 |
| 블루투스 기본, USB 유선 겸용 | 상용 악보 페달이 대부분 블루투스다. 탭 옆에 케이블이 없다. USB는 충전과 블루투스가 안 될 때 쓴다 |
| 보유 XIAO nRF52840(논-Sense) | BLE와 배터리 충전이 보드에 있다. 보유 보드라 사지 않는다. 컨트롤러 프로젝트는 Sense 2개를 전제로 해 겹치지 않는다 |
| 펌웨어는 ZMK | BLE와 USB 전환, 기기 여러 대 등록, 길게 누르기, 깊은 절전, 배터리 잔량 보고가 설정으로 된다. BLE 스택을 직접 짜는 것은 페달 범위를 넘는다 |
| MIDI 없음 | 이펙터와는 풋스위치 신호(TRS)로만 대화한다 |
| 발판 LED 없음 | 상태는 탭 화면과 이펙터 화면에 보인다. 온보드 RGB LED 하나로 키 세트와 연결 상태만 알린다 |

XIAO RP2040은 페달에 쓰지 않는다. 사다리 학습 보드로 남는다([rp2040/README.md](../rp2040/README.md)).

## 3. 하드웨어

| 부품 | 정한 것 | 근거 |
|---|---|---|
| 두뇌 | 보유 Seeed XIAO nRF52840(논-Sense) | 크기 21 × 17.5mm와 USB-C 위치가 XIAO RP2040과 같아 배치가 그대로다 |
| 배터리 | 보호회로 있는 1셀 LiPo, 용량 미정. 국내에서 산다 | 보드 뒷면 BAT 패드에 납땜하고, 같은 USB-C로 충전한다(BQ25101, 50/100mA). 알리 배터리는 품질·배송 제약으로 쓰지 않는다 |
| 전원 스위치 | 없음 | 쓰지 않으면 깊은 절전에 들어가고 발판을 밟으면 깨어난다 |
| 발판 | Taiwan Alpha SF12011F-0202-20R-M-027 ×2. 모멘터리 DPDT, 소프트터치(저하중, 소리 작음), 12mm 홀, 6핀 | 접점 두 벌이 전기적으로 분리돼 있어 페달 회로와 이펙터 쪽을 한 선도 공유하지 않고 나눈다 |
| TRS 잭 | 6.35mm 스테레오 패널 잭 1개 | 2버튼 풋스위치 관례: 팁–슬리브 1번, 링–슬리브 2번(Boss FS-6 방식) |
| USB | XIAO의 USB-C를 케이스 뒷면 구멍으로 낸다 | 충전과 유선 연결을 겸한다 |
| 케이스 | Hammond 1590BB(119.5 × 93.9 × 34mm, 판매점 표기). 타공은 주문 | 발판 2개를 60mm 간격으로 두고 뒤쪽에 잭, XIAO, 배터리가 들어간다 |
| 상태 표시 | 윗면 3mm 창 + 라이트 파이프로 XIAO 온보드 RGB LED를 끌어올린다 | 따로 LED를 달지 않는다 |

### 배치

기준은 `effector/hardware/designs/page_pedal_1590bb.py`. 원점은 면 중심, 단위 mm.

| 요소 | 면 | 좌표 (x, y) |
|---|---|---|
| 발판 왼쪽 / 오른쪽 | 윗면 | (−30, −12) / (30, −12). 중심 간격 60mm, 연주자 쪽 |
| 상태 LED 창 | 윗면 | (24, 34), XIAO 위 |
| USB-C | 뒷면(밖에서 볼 때) | (−24, 0) |
| TRS | 뒷면(밖에서 볼 때) | (22, 0) |

`enclosure.py --draft --design page_pedal_1590bb --dxf` 결과(2026-10-29): 검사 실패 0건, 미측정 19건. 풋스위치·잭은 대표 치수라
실측 전에는 `--final`이 도면을 내지 않는다. 배터리 자리는 아직 배치에 없다. 발판 몸체가 패널 아래 앞쪽 약 25mm를 차지하므로
배터리는 뒤쪽에 두고, 풋스위치 단자와 떨어뜨려 고정한다. 밟을 때 충격이 전해진다.

### 결선

```
발판 1 접점 A ── XIAO D0 (내부 풀업) / GND
발판 2 접점 A ── XIAO D1 (내부 풀업) / GND
발판 1 접점 B ── TRS 팁  / TRS 슬리브
발판 2 접점 B ── TRS 링  / TRS 슬리브
LiPo ── XIAO 뒷면 BAT+ / BAT−
```

- 접점 A와 B가 분리돼 있어 생기는 일:
  - 이펙터 쪽은 그냥 스위치라 배터리가 비어도 동작한다.
  - 페달 회로와 이펙터 쪽 접지가 페달 안에서 만나지 않는다. USB 유선으로 PC에 꽂은 채 이펙터에 연결해도 접지 루프가 생기지 않는다.
  - 이펙터 풀업 전압이 XIAO 핀으로 들어가지 않는다.
- 탭에 블루투스로 붙인 채 이펙터에 꽂으면 한 번 밟을 때 양쪽에 신호가 간다. 이펙터와 연습할 때는 악보 넘기기를 이펙터가 하므로 페달 블루투스를 쓰지 않는다.
- 배터리 전압 측정(P0.14, P0.31)은 노출 GPIO를 쓰지 않는다. P0.14를 HIGH로 두면 P0.31이 상할 수 있다([parts/xiao-nrf52840.md](../parts/xiao-nrf52840.md) 제약 4).

## 4. 동작

| 발판 | 짧게 | 길게(0.5초) |
|---|---|---|
| 왼쪽 | 이전 페이지 | 맨 앞으로(Home) |
| 오른쪽 | 다음 페이지 | 키 세트 바꾸기. 온보드 LED 색으로 알린다 |
| 둘 다 길게 | 연결 대상 바꾸기(USB, 블루투스 기기 1, 2) | |

키 세트: ① Page Up / Page Down(기본) ② 방향키 ← / → ③ Shift+스페이스 / 스페이스. 쓸 악보 앱은 아직 정하지 않았다.
앱이 받는 키가 다르면 세트를 바꾼다.

- 깊은 절전에서 깨어나 다시 연결되는 동안 첫 밟음은 넘어가지 않을 수 있다. 절전 진입 시간을 길게(30분 안팎) 잡아 연주 중에는 잠들지 않게 한다.
- 이펙터 쪽 동작(짧게·길게 판정과 기능 배정)은 이펙터 펌웨어가 정한다. 페달은 스위치만 제공한다.

## 5. 펌웨어

ZMK(`xiao_ble//zmk`, ZMK 공식 하드웨어 목록 기준)로 발판 2개짜리 키보드를 설정한다.

| 기능 | ZMK에서 |
|---|---|
| 발판 읽기 | GPIO 직결 kscan |
| 짧게·길게 | hold-tap |
| 키 세트 | 레이어 |
| 연결 대상 | 출력 선택(USB/BLE)과 BLE 프로필 |
| 절전 | 깊은 절전, 발판으로 깨우기 |
| 배터리 | 배터리 잔량 보고 |

확인할 것(문서로 아직 확인하지 않았다):
- 레이어(키 세트)를 전원을 다시 켜도 기억하게 할 수 있는지
- 온보드 RGB LED로 레이어와 연결 상태를 보여 주는 기능이 기본에 있는지, 모듈이 필요한지

부트로더 진입은 리셋 버튼 두 번이다. 케이스에 넣은 뒤에는 버튼이 안쪽에 있어 뚜껑을 열어야 한다.
SWD 패드에 보유 Debug Probe를 물리면 부트로더를 지워도 복구된다.

## 6. 이펙터 쪽 요구 (멀티 이펙터에 반영함)

- EXP 잭(J12) 링을 ADC로 읽는다. R59 1kΩ + C53 100nF → Seed3 D28(ADC11). 회로 설계 문서 3절.
- 펌웨어 규칙: 링이 98% 아래에서 일정하면 익스프레션 페달, 아니면 팁·링이 0%로 떨어지는 것을 각각 1·2번 발판 밟음으로 본다.
- 외장 발판 기능 배정(예: 이펙트 슬롯 토글, 탭 템포)은 이펙터 펌웨어(서브프로젝트 2)에서 정한다.

## 7. 완성 기준

- 갤럭시 탭과 PC에 블루투스로 페어링되고, 깨운 뒤 다시 연결된다. USB로 꽂아도 키보드로 인식된다.
- 1000번 밟아 두 번 넘어가거나 안 넘어가는 일이 0번이다(연결된 상태 기준).
- 길게 누르기가 짧게 누르기와 헷갈리지 않는다.
- 전원을 껐다 켜도 키 세트가 유지된다.
- 이펙터 EXP 잭에 꽂아 배터리와 상관없이 1·2번 발판이 이펙터에서 구분된다.

## 9. 미정

- 풋스위치·잭 실측 치수, 케이스 벽 두께, XIAO 받침 높이(USB-C 중심이 뒷면 가운데에 오도록)
- 배터리 용량과 자리(배치 파일에 아직 없다)
- ZMK 확인 두 가지(5절)
- 악보 앱
