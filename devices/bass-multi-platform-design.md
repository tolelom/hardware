## 1. 목표와 판정 기준

Daisy Seed3 기반 베이스 멀티 이펙터 페달의 하드웨어 플랫폼을 만든다. 첫 이펙트는 컴프레서이고, 이후 이펙트는 같은
하드웨어에서 펌웨어로 늘린다.

판정 기준은 상용 제품급 완성도다. 성능, 기능, 크기, 전용 PCB, 마감을 판매 제품 수준으로 맞춘다. 기능을 미리 범위로
빼지 않고, 각 후보는 "연주에서 쓰는가"와 레퍼런스 대조로 넣고 뺀다.

| 항목 | 목표 | 근거 |
|---|---|---|
| 바닥 노이즈 | A 가중 다이내믹 레인지 110dB 이상 (T7 통과선은 105) | TLC -95dBu, Keeley -95dBV급 (설계서 2절) |
| 헤드룸 | 입력·출력 +17dBu | 설계서 3.1절, M1 슬랩 피크 +10dBu |
| 크기 | 폭 약 190mm. HX Stomp(178×126×66), Ampero II Stomp(185×145×58)와 같은 급 | 컬러 화면 + 노브 5~6개 제품이 175~185mm 구간에 몰려 있다 |
| 기판 | 전용 PCB. 공장 SMT 조립, 스루홀(잭·풋스위치·인코더·소켓)은 손납땜 | 상용급 기준 |
| 완료 | 케이스를 닫고 컴프레서로 T16(30분 연습 2회)을 통과 | 설계서 7.3절 |

서브프로젝트는 넷으로 나눈다. 이 문서는 1번이다.

| # | 서브프로젝트 | 내용 |
|---|---|---|
| 1 | 하드웨어 플랫폼 | 케이스, 패널 UI, 기판 2장, 전원, 아날로그 입출력, 핀 배정 |
| 2 | 펌웨어 플랫폼 | 화면 UI, 인코더·풋스위치 입력, 프리셋 저장, 이펙트 체인, MIDI, 바이패스·전원 감시 |
| 3 | 컴프레서 이펙트 | `effector_core` 계승. Attack·Release 분리, 가변 사이드체인 HPF, Ratio, Blend, 톤, 입력 레벨 미터 |
| 4 | 이후 이펙트 | 드라이브, EQ, 옥타버, 시간계 등 |

Seed3 모듈의 실제 노이즈·풀스케일·지연(1단계 계획 Task 8·9의 M2, T5, T7, T8)은 어떤 기판에서든 먼저 필요하므로
이 설계와 병행해 잰다.

## 2. 케이스

Hammond 1590R1. 외형 192 × 111.25 × 60.76mm, 벽 2.03mm(판매점 표기, DigiKey). 내부에 1.5mm 기판용 카드 가이드가
주조돼 있다. 내부 높이와 구배는 실측한다.

| 후보 | 외형 | 탈락 사유 |
|---|---|---|
| Hammond 1590E | 187.5 × 119.5 × 82mm | 높이가 커 바닥에서 솟는다 |
| 1590DD (Hammond, Tayda) | 188 × 120 × 37mm | 높이가 낮아 조작부 기판과 Seed3 스택을 겹쳐 쌓지 못한다 |
| 1590XX | 145 × 121 × 39mm | 폭과 높이 모두 부족 |
| 맞춤 케이스(Protocase 등) | 자유 | 시제품 단계에서는 패널 수정마다 견적이 다시 든다. 최종 디자인이 굳은 뒤 다시 본다 |

화면 창이 사각형이라 타공은 CNC 밀링으로 한다. Tayda·페달파츠 타공 서비스는 자사 케이스만 받는다(확인 필요).
가공 도면은 `enclosure.py`가 DXF로 낸다.

## 3. 패널

```
 ┌──────────── 뒷면: DC 9V · USB-C · MIDI IN(TRS) · EXP(TRS) ────────────┐
 │ ┌──────────────┐   (E1)  (E2)  (E3)  (NAV)                            │
OUT│ │ 2.8" IPS     │                                                     │IN
 │ │ 320×240      │   (E4)  (E5)  (E6)                                  │
 │ └──────────────┘                                                       │
 │      ●                    ●                    ●                       │
 │    [FS1]                [FS2]                [FS3]                     │
 └────────────────────────────────────────────────────────────────────────┘
```

| 요소 | 사양 | 역할 |
|---|---|---|
| 화면 | 2.8" IPS TFT 320×240(가로), SPI, ST7789VI. 후보 Newhaven NHD-2.8-240320AF-CSXP-F: 모듈 69.2 × 50 × 3.39mm, 보이는 영역 58.6 × 44.2mm, 1000cd/m², 시야각 80°, 백라이트 160mA@3.1V(수명 20,000h 이상, 반감) | 이펙트·파라미터 이름과 값, 감쇠 미터, 입력 레벨 미터 |
| 파라미터 인코더 E1~E6 | 무한회전, 노브 지름 약 15mm, 간격 21mm. 부품은 누름 스위치 달린 것(EC11급)으로 두되 펌웨어는 돌리기만 쓴다 | 현재 페이지의 파라미터 6개. 프리셋을 바꿔도 노브 위치와 값이 어긋나지 않는다. 천천히 돌리면 촘촘하게, 빨리 돌리면 크게(가속) |
| 내비 인코더 NAV | 무한회전, 누름 포함 | 돌리기: 프리셋 이동. 짧게 누르기: 페이지 전환(노브 6개 전체가 1·2페이지를 오간다). 길게 누르기: 메뉴(EXP·MIDI 할당, 설정) |
| 풋스위치 FS1~FS3 | 모멘터리, 간격 60mm, 위에 상태 LED | FS1 바이패스. FS2·FS3 프리셋 아래·위. 길게 누르면 탭 템포, 튜너 |

화면 종류는 2026-10-28 조사에서 정했다. 3.12" OLED 256×64(Newhaven NHD-3.12-25664UCY2)는 어두운 무대 대비가 좋지만
보이는 높이가 19mm이고 밝기 80cd/m², 데이터시트가 잔상(번인)을 경고한다. 3.5" IPS(Waveshare, 모듈 61 × 92mm)는 1590R1
깊이에서 여유가 남지 않는다. 2.8" IPS는 보이는 영역 59 × 44mm, 1000cd/m²로 밝은 무대에 강하고 번인이 없다. 서서 읽히는지는
모듈 실물로 확인한다.

무한회전 인코더를 쓰는 레퍼런스는 Darkglass Anagram(노브 6), Boss GT-1000CORE다(2026-10-28 조사). 레이아웃은 화면 옆에
인코더 격자를 두고 풋스위치를 앞쪽 한 줄에 두는 배치다.

2026-10-28 어림 배치(3.5" 모듈 86 × 56mm 가정, 가장자리 여유 6mm)에서 간섭은 없고 화면 모듈이 여유선에 닿았다. 2.8" 모듈은
폭 17mm, 높이 6mm가 작아 여유가 늘어난다. 확정 배치는 7절의 기구 검사로 한다.

컴프레서 이펙트의 기본 노브 배정: 1페이지 E1 Input, E2 Attack, E3 Release, E4 HPF(사이드체인), E5 Blend, E6 Output. 2페이지 Ratio, 톤 등.
이펙트는 대부분 파라미터 6개 안팎이라 1페이지로 되고, 프리앰프·파라메트릭 EQ처럼 대역이 많은 것은 2페이지를 쓴다.

## 4. 기판 구성

두 장으로 나눈다.

| 기판 | 위치 | 부품 |
|---|---|---|
| 조작부 기판 | 패널 바로 아래 | 인코더 7개, 화면 커넥터, 풋스위치 3개, LED 3개, MCP23017 ×2, 3.3V 보조 전원 |
| 메인 기판 | 바닥 쪽 | Daisy Seed3(저배기 소켓), 블록 A~F 계승 회로, MIDI IN, EXP 입력, IN·OUT·DC·USB·MIDI·EXP 잭, 스테레오 출력 자리 |

- 층을 나누는 이유: 풋스위치(패널 아래 약 30mm)와 Seed3 스택(약 20mm)이 같은 자리에 겹치지 않게 하고, 아날로그
  입력단을 화면·SPI·인코더 배선에서 떼어 놓는다.
- 두 기판은 보드 투 보드 커넥터 또는 리본 케이블로 잇는다. 신호는 SPI(화면), I2C(MCP23017), 인터럽트, 풋스위치·LED,
  전원과 접지다.
- Seed3는 풋스위치 줄 아래가 아니라 화면·인코더 아래에 둔다. 소켓 높이가 모자라면 직접 납땜으로 바꾼다.
- 조립: 저항·커패시터·IC는 공장 SMT. 잭, 풋스위치, 인코더, Seed3 소켓, LT1054(DIP일 때)는 손납땜.
- 1590R1 카드 가이드와 옆면 잭이 간섭하지 않게 메인 기판 외곽을 정한다.

## 5. 전기 설계

### 5.1 계승하는 회로

설계서·회로 설계의 블록 A(전원 보호), B(LT1054 레일), C(Seed3 VIN 필터·전원 감시), D(입력 버퍼·패드), E(출력단),
F(K1 바이패스)를 메인 기판으로 옮긴다. 값은 BLOCKS 그대로 시작하고, 바꿀 때는 회로 설계 문서와 커밋에 이유와
시뮬레이션·측정 근거를 남긴다. 블록 G(포트 5개, LED 9개)는 인코더와 화면으로 대체해 없앤다.

### 5.2 새 회로

| 블록 | 구성 | 근거 |
|---|---|---|
| 조작부 3.3V | V9에서 별도 3.3V 레귤레이터. 화면 백라이트, MCP23017, LED용 | Seed3 모듈 레귤레이터의 여유 전류가 공개되지 않았다. 9V에서 3.3V로 선형 강하하면 100mA에서 약 0.6W라 강압형을 검토하되, 스위칭 잡음은 조작부 기판 안에서 필터로 막고 아날로그 기판과 접지를 한 점에서 잇는다 |
| 인코더 확장 | MCP23017 ×2 (I2C, 각 16비트). 인코더 7개 × 3선 = 21선 | Seed3 GPIO 절약. 인터럽트 핀으로 변화를 알린다 |
| 화면 | SPI + DC + RST + 백라이트 PWM | DMA SPI로 오디오 콜백과 분리, 프레임 버퍼는 SDRAM. 전체 프레임은 153.6KB(16비트)라 바뀐 영역만 보낸다 |
| MIDI IN | TRS 타입 A, 6N137급 광커플러 → UART RX | MIDI 규격의 절연 입력 |
| EXP | TRS, 링에 3.3V 기준, 팁 와이퍼 → ADC, 꽂힘 감지 | 익스프레션 페달 |
| 스테레오 출력 | 출력단 한 채널 풋프린트, Seed3 Audio Out 2 배선 | 부품은 얹지 않는다 |

### 5.3 핀 배정 (초안)

| 기능 | 핀 수 | Seed3 핀 |
|---|---|---|
| 화면 SPI (SCK, MOSI, CS, DC, RST, 백라이트) | 6 | SPI1(D7~D10) 포함, 나머지 GPIO |
| I2C (MCP23017) | 2 | D11, D12 |
| MCP23017 인터럽트 | 2 | GPIO |
| 풋스위치 3 | 3 | GPIO |
| 풋스위치 LED 3 | 3 | GPIO |
| K1 구동 | 1 | D0 (계승) |
| MIDI IN UART RX | 1 | D14 |
| EXP | 1 | ADC |
| 전원 감시 | 1 | A5 (계승) |

합계 20핀. Seed3 GPIO는 D0~D30 31개이고 그중 A0~A11 12개가 ADC를 겸한다(libDaisy `daisy_seed.h`). D29·D30은
외부 USB 핀이라 USB 호스트 자리로 비워 둔다. 핀 번호 확정은 생성기 `check()`의 중복 검사를 통과한 BLOCKS가 기준이다.

### 5.4 전류 예산

| 부하 | 9V 기준 전류 | 출처 |
|---|---|---|
| 기존 페달 부하 (Seed3, LED, K1, LT1054, 아날로그단) | 약 230mA | 설계서 5.4절 계산 |
| 화면 백라이트와 로직 | 백라이트 160mA@3.1V(최대 밝기), 로직 3~15mA. 9V 기준은 보조 전원 방식(강압형이면 약 70mA, 선형이면 약 175mA)에 따른다 | NHD-2.8 데이터시트 |
| MCP23017 ×2, LED 3 | 수 mA~10mA | 데이터시트로 확정 |

합계가 9V 500mA 어댑터의 80%를 넘으면 요구 어댑터를 1A로 올린다.

## 6. 기구 높이

외형 60.76mm에서 바닥 두께와 패널 두께를 뺀 내부 높이는 실측 전이다(55mm 안팎 추정). 확인할 겹침은 둘이다.

- 풋스위치 줄: 풋스위치 패널 아래 약 30mm. 이 아래에는 메인 기판의 낮은 부품만 둔다.
- 화면·인코더 영역: 조작부 기판(인코더 몸체 약 10~15mm, 화면 모듈 약 5mm) 아래에 메인 기판과 Seed3 스택(약 20mm).

`enclosure.py --final`은 내부 높이와 부품 높이가 실측될 때까지 최종 도면을 내지 않는다.

## 7. 검증

| 대상 | 방법 |
|---|---|
| 패널 배치 | `enclosure.py`에 사각형 부품(화면 창, 화면 모듈)과 1590R1 치수를 더하고 간섭·가장자리·높이 검사 |
| CNC 도면 | `enclosure.py`가 면별 DXF와 좌표 표를 낸다 |
| 회로 | `gen_spice.py`와 테스트벤치. 새 블록(3.3V 보조 전원 입력 필터, EXP 분압)은 테스트벤치를 더한다 |
| 핀 배정 | `gen_schematic.py` `check()`에 Seed3 핀 중복과 미배정 검사 |
| 실측 | 1단계 M2·T5·T7·T8, 이후 기판 Rev A에서 설계서 7.3절 시험 항목 전체 |

PCB 레이아웃 도구 경로(KiCad를 M4에서 스크립트로 다룰 수 있는지, 배치 좌표를 `enclosure.py`에서 넘길 수 있는지)는
구현 계획의 첫 스파이크로 확인한다.

## 8. 리스크

| 리스크 | 영향 | 대응 |
|---|---|---|
| 1590R1 내부 높이 부족 | 기판 2장 적층 실패 | 실측 뒤 `--final`. 안 되면 Seed3 직접 납땜, 그래도 안 되면 1590E 또는 맞춤 케이스 |
| 화면 SPI·백라이트 PWM 잡음이 오디오에 섞임(백라이트 160mA를 PWM으로 끊는다) | T7 악화 | 기판 분리, 한 점 접지, 백라이트 PWM 주파수를 오디오 대역 밖으로, T7을 화면 켬·끔 두 조건으로 |
| 화면 프레임 갱신이 오디오 콜백을 방해 | 끊김 | DMA SPI, 부분 갱신, 블록 처리 시간 측정 |
| 깊이 111mm에 화면·인코더·풋스위치가 빠듯 | 배치 실패 | 기구 검사. 실패하면 노브 지름·간격 또는 화면 크기 조정 |
| CNC 가공 비용·납기 미상 | 일정 | 도면을 일찍 내 견적(JLC, PCBWay 등) |
| 펌웨어 범위가 커짐(UI, 프리셋, 체인) | 완료 지연 | 서브프로젝트 2·3을 분리하고 컴프레서 하나로 T16을 먼저 통과 |
