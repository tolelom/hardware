# TKL 87키 커스텀 키보드 계획

얇은 계획서다. 상세 설계는 [design.md](design.md)에 있다. Rev 0.2.
부품 기준 문서: [parts/xiao-rp2040.md](../../parts/xiao-rp2040.md)
최종 갱신: 2026-09-14

## 무엇을 만드나

ANSI TKL 87키 유선 기계식 키보드를 만든다. PCB를 KiCad로 직접 설계한다.

## 상태

멈춰 있다. 설계서는 2026-08-18에 Rev 0.1로 완성됐고 2026-09-08에 외형 경로를 바꿔 Rev 0.2다. 검수 대기 상태다. 남은 것은 둘이다.

| 막힌 것 | 내용 |
|---|---|
| 설계서 §13 | 7개 중 4개는 08-30에 닫았고 3개는 답할 시점이 정해져 있다. 아래 표 |
| 설계서 §3 | 케이스 선정. 09-07 조사로 외형이 공개 파일에서 나와 설계는 케이스 없이 진행된다. 케이스와 플레이트 실물은 PCB 발주(단계 6)의 게이트다. 아래 "케이스 후보" 절 |

이 프로젝트는 새로 계획할 것이 아니라 멈춘 것을 다시 굴리는 것이다.

### 케이스 후보 (2026-09-07 조사)

문서 기준이다. 실물은 안 봤고 판매처 페이지는 2026-09-08에 확인했다.

TKL PCB에는 사실상 표준 외형이 있다. Hineybush H87c의 외형과 USB 위치, 스테빌 배치를
따르는 PCB를 여러 케이스가 공통으로 받는다. 이 규격을 따르는 오픈소스 PCB가 있어
설계서 §3의 "대안 경로"(공개 PCB의 외형선과 마운팅만 가져오고 회로는 직접)가 성립한다.

권고는 Frog TKL에 풀 플레이트다. 핫스왑 소켓이 스위치를 혼자 잡는 구역을 없애고,
플레이트 파일이 공개돼 있어 외형 검증 재료가 둘(PCB 외형, 플레이트 컷아웃)이 된다. Geonworks는 부천 소재 국내
업체다(2026-09-07 확인). 네이버 스마트스토어도 있어 통관과 해외 배송이 빠진다.

파일을 받아 직접 잰 값이다(2026-09-07, KiCad 파일의 Edge.Cuts와 풋프린트를 스크립트로 집계).

| 항목 | Apollo87H PCB | Frog TKL ANSI 하프 플레이트 |
|---|---|---|
| 외형 | 344.66 × 123.06 mm | 352.00 × 125.00 mm |
| 스위치 풋프린트 | 87개. 1u 72, 1.25u 7, 1.5u 2, 1.75u 1, 2u 1, 2.25u 2, 2.75u 1, 6.25u 1 | 컷아웃은 그래픽이라 개수 미집계 |
| USB-C 중심 | 왼쪽 가장자리에서 58.0 mm, 위 가장자리에서 6.9 mm | 해당 없음 |
| 마운팅 홀 | 2.5 mm 1개 | M3 12개. 위아래 가장자리 |
| 파일 형식 | KiCad 6 (`version 20211014`) | KiCad. 버전 미확인 |

설계서 §5.8의 "약 355 × 128"은 이 값으로 바뀐다. 플레이트가 PCB보다 가로 7.3 mm,
세로 1.9 mm 크다. 탑 마운트라 PCB에는 케이스 나사 홀이 없고, 2.5 mm 홀 하나는
용도 미확인이다.

이 경로가 설계서에 주는 변화.

- §3 선정 기준 2(트레이 마운트 선호)를 포기한다. 표준 외형을 따르는 대신 얻는 것이
  "여러 PCB로 검증된 외형"이라 트레이 마운트가 주던 공차 관용을 대신한다.
- §5.8과 §7의 PCB 치수 [검증필요]는 Apollo87H 외형선을 임포트하는 순간 닫힌다.
- §11 R1(치수 추정)이 "공개 외형을 그대로 쓴다"로 대응된다. R5(USB 위치)는 Apollo87H의
  USB 위치를 옮기지 않으면 Apollo87H 호환이 확인된 케이스에서만 같이 닫힌다. 외형이 같아도
  커넥터 돌출로 안 맞는 케이스가 있다(KBD8X MKII 사례).
- §13-4 스테빌은 H87c 규격이 PCB 마운트이므로 나사식으로 간다. 하프 플레이트면 플레이트 밖
  구역의 스테빌은 PCB 마운트가 필수이고, 풀 플레이트면 컷아웃이 결정한다. 추정이며 플레이트
  파일에서 스테빌 자리 컷아웃을 보면 판정된다.
- 회로는 그대로 RP2040이다. Apollo87H는 STM32 계열이라 회로도는 참고하지 않는다.
  외형선, 스위치 좌표, USB 위치, 스테빌 자리만 가져온다.

남는 확인. Apollo87H 파일이 KiCad 8 이상에서 열리는지(6 형식이라 열릴 것으로 본다),
Frog TKL 변종별 현재 가격과 재고. 위 표는 하프 플레이트 파일을 잰 것이라 풀 플레이트
파일도 같은 방법으로 열어 컷아웃과 스테빌 자리를 본다.

#### 보류 항목의 판단 재료

2번. 설계서 §6 단계4는 Rev0를 "저가 프로모션 구간, 약 1주"로 적었는데 이 서술이 의심스럽다.
Rev0에도 RP2040 QFN-56이 들어가므로 Rev0 자체에 PCBA가 필요하다.
JLC PCBA는 셋업비가 붙고 Economic 기준으로도 extended part는 부품 종류마다 피더 셋업 비용이 추가된다.
설계서가 PCB 5장 값만 보고 PCBA를 안 셌을 가능성이 있다.
판단은 Rev0와 본 보드 견적을 둘 다 내서 비교한다.

3번. Vial에는 실제 제약이 있다. 레이어 4개 이하 제한, Autocorrect와 Leader Key,
OS Detection, Swap Hands, Unicode 입력, 키별 tap-hold 설정이 없다.
출처는 getreuer의 Vial 가이드, 2026-04 기준(2026-09-07 재확인).
다만 이 제약은 키가 물리적으로 다 있는 TKL에서 거의 걸리지 않는다.
반대로 VIA는 부분 클로즈드 소스이고 같은 가이드가 "2020년 이후 업데이트 없음"으로 적는다.
이 서술은 데스크톱 앱 릴리스 기준으로 보이고 웹앱(usevia.app)은 별도다. 판단에는 영향 없다.

4번. 실제 종속은 나사식이냐가 아니라 플레이트 마운트냐 PCB 마운트냐다.
플레이트 마운트 전용 케이스면 PCB에 스테빌 컷아웃 자체가 필요 없어진다.
나사식과 클립인이 같은 PCB 풋프린트를 쓰는지는 확인하지 못했다.
ai03 라이브러리의 PCB 마운트 풋프린트가 나사 홀을 포함할 것으로 보이나 단정할 수 없다.
라이브러리는 MX_Alps_Hybrid가 아니라 후속인 MX_V2를 쓴다. 구 라이브러리는 갱신이 멈췄다(2026-09-07 확인).
케이스 선정 체크리스트에 "플레이트가 PCB 마운트를 허용하는가"를 넣는다.

## 왜 RP2040인가

- 매트릭스 6행 17열이라 GPIO 23핀이 필요하다. RP2040은 30핀이라 여유가 있다
- QFN-56 베어칩을 JLCPCB 조립에 위임할 수 있어 손납땜 리스크를 피한다
- QMK가 공식 지원하는 플랫폼이다

## 보유한 XIAO RP2040의 역할

최종품은 베어 RP2040 QFN-56 칩이다. XIAO 모듈은 완성품에 들어가지 않는다.
발주 전 펌웨어를 미리 검증하는 용도인데 여기에 확인된 제약이 있다.

XIAO RP2040은 노출 GPIO가 11개뿐이라 23핀이 필요한 87키 전체 매트릭스를 못 만든다.
11핀으로 가능한 최대 매트릭스는 5×6, 30키다.

따라서 검증되는 것과 안 되는 것이 갈린다.

| 검증 가능 | 검증 불가 |
|---|---|
| QMK/Vial 빌드와 플래시 흐름 | 87키 전체 핀 배정표 |
| 매트릭스 스캔 로직 | 실제 PCB 배선 |
| 다이오드 방향 | 스테빌라이저와 케이스 간섭 |
| 키맵과 레이어 동작 | |

발주 리스크를 줄이지만 없애지는 못한다. 설계서 §6 단계4의 Rev0 검증보드가 여전히 필요하다.

XIAO는 RP2040 베어메탈 사다리([learning/rp2040-baremetal/README.md](../../learning/rp2040-baremetal/README.md))의 보드이기도 하다. 사다리의 최종 과제가
1000Hz 키보드 펌웨어를 직접 짜는 것이라(2026-10-29), 단계 2의 부분 매트릭스는 QMK 검증과 직접 짠 펌웨어 시험에
같이 쓴다. 이 키보드의 기본 펌웨어는 QMK + Vial을 유지하고, 직접 짠 펌웨어는 완성되면 이 보드에 구워 지연을 비교한다.

## 배우는 것과 쓰는 것

배우는 것: KiCad 회로도에서 레이아웃, 거버까지의 전 과정. JLCPCB PCBA 발주.
QMK/Vial 펌웨어. 핫스왑 소켓 87개소 납땜.

쓰는 것: 매일 쓰는 키보드다. 이 묶음에서 실사용 가치가 가장 확실하다.

## 그만둘 조건
