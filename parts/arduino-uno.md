# Arduino Uno (클론)

부품 기준 문서. 프로젝트 배정이 없다. 왜 안 쓰는지를 적어두는 것이 이 파일의 목적이다.
최종 갱신: 2026-08-30

## 스펙

정품 Uno R3 기준이다. 클론이라 실물이 이 사양과 같은지는 확인하지 않았다.

| 항목 | 값 |
|---|---|
| MCU | ATmega328P, 8bit AVR, 16 MHz |
| Flash | 32 KB. 부트로더가 0.5 KB 사용 |
| SRAM | 2 KB |
| EEPROM | 1 KB |
| 디지털 I/O | 14. PWM 6 |
| 아날로그 입력 | 6 |
| 로직 레벨 | 5V |
| USB | Type-B |

USB 시리얼 변환 칩은 모름. 클론은 CH340 계열인 경우가 많으나 실물 확인은 안 했다.
드라이버 문제가 생기면 여기부터 본다.

## 프로젝트를 배정하지 않는 이유

보유한 다른 보드와 비교해서 이 보드가 이기는 항목이 하나도 없다.

| | Uno (ATmega328P) | XIAO RP2040 | XIAO nRF52840 |
|---|---|---|---|
| 코어 | 8bit AVR 16 MHz | 32bit 듀얼 M0+ 133 MHz | 32bit M4F 64 MHz |
| SRAM | 2 KB | 264 KB | 256 KB |
| Flash | 32 KB | 2 MB | 1 MB + 2 MB |
| USB | 시리얼 변환 칩 경유 | 네이티브 | 네이티브 |
| 무선 | 없음 | 없음 | BLE |
| 디버깅 | debugWIRE. 전용 장비 필요 | SWD | SWD |

특히 두 가지가 결정적이다.

1. USB HID를 직접 못 한다. ATmega328P에는 USB 장치 기능이 없고 USB 시리얼 변환 칩을 거친다.
   키보드나 게임패드처럼 HID 장치로 인식돼야 하는 프로젝트에 쓸 수 없다.
   HID가 되는 것은 ATmega32U4를 쓰는 Leonardo와 Micro다.
2. 보유한 Debug Probe로 디버깅할 수 없다. AVR은 SWD가 아니라 debugWIRE를 쓴다.
   Raspberry Pi Debug Probe는 CMSIS-DAP SWD 장비라 붙지 않는다.

유일한 우위는 5V 로직이다. 5V 부품을 직결해야 하는 상황이 오면 그때 꺼낸다.

## 남겨두는 용도

- 5V 로직이 필요한 부품의 임시 테스트
- 센서나 모듈이 도착했을 때 값이 나오는지 확인하는 잡용 보드

프로젝트로 승격할 일이 생기면 이 파일에 이유를 적고 `devices/`를 만든다.
