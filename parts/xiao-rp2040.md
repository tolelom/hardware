# Seeed XIAO RP2040

부품 기준 문서. 확인된 것만 적는다. 모르는 것은 "모름"으로 남긴다.
최종 갱신: 2026-08-30

## 스펙

출처: [Seeed Studio Wiki, XIAO RP2040](https://wiki.seeedstudio.com/XIAO-RP2040/)

| 항목 | 값 |
|---|---|
| MCU | Raspberry Pi RP2040, Cortex-M0+ 듀얼코어, 최대 133 MHz |
| RAM | 264 KB SRAM |
| Flash | 온보드 2 MB |
| 노출 GPIO | 11 (전부 PWM 가능) |
| 아날로그 입력 | 4 |
| 인터페이스 | I2C ×1, UART ×1, SPI ×1 |
| USB | Type-C |
| 배터리 충전 | 없음. Plus 변종에만 있다 |
| 온보드 | 유저 LED, 전원 LED, RGB LED, 리셋 버튼, 부트 버튼 |
| SWD | 패드 노출됨 |

Plus 변종(미보유): 디지털 I/O 26(메인 11 + 납땜 패드 15), I2C ×2, 배터리 관리 내장.

## 제약

확인된 것만 적는다.

1. 노출 GPIO가 11개뿐이다. 이것이 이 보드의 결정적 제약이다.
   TKL 키보드 매트릭스는 6행 17열이라 23핀이 필요하다.
   따라서 이 보드로는 87키 전체 매트릭스를 프로토타입할 수 없다.
   11핀으로 만들 수 있는 최대 매트릭스는 5×6, 30키 규모다.
   펌웨어와 스캔 로직 검증에는 충분하지만 핀 배정표 전수 검증은 불가능하다.
2. WiFi와 Bluetooth가 없다. RP2040 칩 자체에 무선이 없다.
   Pico W의 무선은 CYW43439라는 별도 칩이며 XIAO RP2040에는 없다.
3. 온보드 배터리 충전 회로가 없다. 배터리 구동에는 외부 회로가 필요하다.
4. 아날로그 입력이 4개다. nRF52840의 6개보다 적다.

"검증됨"이 없는 것은 아직 안 켜봤기 때문이다.

## 디버깅 경로

- SWD 패드가 노출돼 있다. 출처는 Seeed 위키.
- Raspberry Pi Debug Probe는 RP2040 디버깅용으로 만들어진 장비라 가장 잘 맞는 조합이다. 실제 연결은 안 해봤다.
- 부트 버튼을 누른 채 USB를 연결하면 `RPI-RP2` 대용량 저장장치 모드로 들어간다.
  RP2040 공통 동작이지만 이 보드에서 직접 확인하지는 않았다.
- UART 1채널이 있다. 핀 위치는 확인 안 함.

## PIO

RP2040에는 PIO(Programmable I/O) 스테이트머신이 있다.
임의 프로토콜을 CPU 개입 없이 사이클 정확하게 구현하는 블록이다.
아직 이것을 써야 할 용도가 정해지지 않았다.
용도 없이 배우는 것은 "공부하면서 쓸 것 만들기"라는 목적에 맞지 않으므로 필요가 생길 때까지 보류한다.
