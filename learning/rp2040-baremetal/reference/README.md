# 참고 자료

읽기용 사본이다. 빌드에 쓰지 않는다.

## boot2_w25q080.S

RP2040 의 2단계 부트로더 소스다. 이 칩은 안에 플래시가 없어서 부트롬이 외부
QSPI 플래시의 맨 앞 256바이트를 SRAM 으로 퍼와 실행한다. 그 256바이트가 XIP 를
켜서 이후로 플래시가 메모리처럼 읽히게 만든다. 이 파일이 그 원본이다.

| 항목 | 값 |
| --- | --- |
| 원본 경로 | `src/rp2040/boot_stage2/boot2_w25q080.S` |
| 저장소 | https://github.com/raspberrypi/pico-sdk |
| 버전 | 2.3.0 |
| 커밋 | `98a542c1a62fb549ffb5d66a3e5892b06276b670` (2026-07-03) |
| 라이선스 | BSD-3-Clause. 전문은 `LICENSE.pico-sdk.txt` |

이 소스를 빌드한 256바이트는 `backups/xiao-rp2040/factory-flash.bin` 의 첫
256바이트와 바이트 단위로 일치한다.

같은 폴더에 다른 플래시 칩용 변종이 여럿 있다. `boot2_is25lp080.S`,
`boot2_at25sf128a.S`, `boot2_w25x10cl.S`, 그리고 어느 칩에나 되는 대신 단선
03h 읽기라 느린 `boot2_generic_03h.S` 다. 플래시 칩이 바뀌면 새로 쓰는 것이
아니라 이 중에서 고른다.

SDK 저장소의 `src/rp2350/` 아래에 같은 이름의 파일이 또 있다. 그쪽은 RP2350
용이라 이 보드와 무관하다.

## 사본이라는 것

원본은 위 저장소에 있고 이것은 사본이다. SDK 를 갱신하면 어긋날 수 있으므로
내용을 근거로 쓸 때 버전을 함께 확인한다.
